プログラミング応用A（コンピューティング応用G）最終実技試験問題¶

本ファイルは、1学期間で学んだ「データ加工・統計解析・GIS（地理空間情報）・AI（機械学習）・Webアプリ開発」の実力をフラットに測定するための**最終実技試験問題（全10問）**です。

🧭 受験者（学生）への案内¶

  1. すべての問題は、Google Colab上でプログラムを実行しながら解答してください。

  2. 外部からCSVファイルをアップロードする必要はありません。各問題のセルを実行すると、自動的にテスト用のデータフレームやGeoDataFrameが生成されます。

  3. コード内の # TODO: と書かれた部分を適切に書き換え、指示された通りの結果を出力するプログラムを完成させてください。

  4. インターネット、講義資料、自作のColabノートブック、および生成AI（ChatGPT等）を活用したデバッグ・相談を許可します（※授業の実施方針に従ってください）。ただし、出力される結果が要件を満たしているか、必ず自分で最終確認を行ってください。

📊 採点者（教員）への案内・配点基準¶

各問10点満点、合計100点満点で採点します。各問題には「採点基準」と「減点ポイント」を記載しています。 部分点（コードが未完成でも、ロジックが合っている場合は部分点を与えるなど）の基準も設けてありますので、採点時の参考にしてください。

⏱️ 試験時間¶

推奨される試験時間：60分〜90分（AI併用（Vibe Coding）を前提とする場合は60分、自力での手書きコーディングを前提とする場合は90分が目安です）。

%%writefile app.py
import streamlit as st
import pandas as pd
import numpy as np
import matplotlib.pyplot as plt
import japanize_matplotlib
from sklearn.linear_model import LinearRegression

# 1. 過去データの自動生成（100日分）
np.random.seed(42)
visitors = np.random.randint(50, 220, (100, 1))
sales = visitors * 2500 + np.random.normal(0, 20000, 100) # 単価2500円

df_sales = pd.DataFrame({"客数": visitors.flatten(), "売上": sales})

# 2. アプリ画面ヘッダー
st.title("📈 AI売上予測シミュレーター")
st.write("過去実績データからAI（線形回帰）が売上予測モデルを作成。明日の客数を入力してシミュレーションできます。")

# 3. UIの配置（サイドバー）
st.sidebar.header("⚙️ シミュレーション設定")
next_visitors = st.sidebar.slider("明日の予想客数（人）", min_value=50, max_value=250, value=150)

# 4. AIのその場学習
X = df_sales[["客数"]].values
y = df_sales["売上"].values
model = LinearRegression()
model.fit(X, y)

# 明日の売上予測
predicted_sales = model.predict([[next_visitors]])[0]

# 5. 予測結果のKPI表示
st.subheader("🔮 AI予測結果")
st.metric(
    label=f"明日の売上予測額 (予想客数: {next_visitors}人)",
    value=f"{int(predicted_sales):,} 円"
)

# 6. グラフの描画
fig, ax = plt.subplots(figsize=(8, 5))
# 過去データの散布図
ax.scatter(X, y, color="skyblue", label="過去の実績（100日間）", alpha=0.7)

# AIの予測直線（回帰直線）
X_line = np.linspace(50, 250, 100).reshape(-1, 1)
y_line = model.predict(X_line)
ax.plot(X_line, y_line, color="red", linestyle="--", label="AI売上予測ライン")

# 明日のシミュレーション予測点（オレンジの星）
ax.scatter(next_visitors, predicted_sales, color="orange", marker="*", s=250, zorder=5, label="明日のシミュレーション（予測）")

ax.set_title("客数と売上高の関係およびAI予測", fontsize=14)
ax.set_xlabel("客数（人）")
ax.set_ylabel("売上高（円）")
ax.legend()
ax.grid(True, linestyle=":")

# Streamlitにグラフをプロット
st.pyplot(fig)
