第6回 Webサービスの活用2：Streamlitによるインタラクティブなデータダッシュボード（講義100分版）¶

皆さん、こんにちは！プログラミング応用A（コンピューティング応用G）、第6回の講義です。担当の教員です。 前回（第5回）は、PythonだけでWebアプリを構築できる画期的なライブラリ Streamlit（ストリームリット） の基本を学び、ボタンやスライダーなどの部品（ウィジェット）を画面に配置して、ユーザーの入力に応じて動的に画面が変化する基本的なおまじないを習得しました。また、Google Colabから手元のブラウザへ通信を通す「トンネリング（localtunnel）」という黄金の起動儀式も無事にクリアできましたね！

第6回となる本日のテーマは、これまでに学んだすべてのスキルの「大合体」です！ 具体的には、第3回・第4回で格闘してきた 「Pandasによるデータ前処理・フィルタリング」 と 「Matplotlibによるグラフ可視化」 の技術を、StreamlitのUIとガッチャンコさせ、企業や店舗の経営者が意思決定を行う際に用いる 「インタラクティブ・データダッシュボード」 を自分の手で完成させます！

「エクセルの表をただ見せるだけ」「静止画のグラフをメールで送るだけ」のデータ分析は、今日で卒業です。 ユーザーがサイドバーで「江古田店」をクリックした瞬間に、画面中央の売上推移グラフが再描画され、平均客単価や総売上といった重要指標（KPI）が一瞬で再計算されるプロ級のシステムを構築していきます。

6.1 ダッシュボードの画面設計：サイドバーとカラム分割 (約20分)¶

優れたデータダッシュボードとは、**「見たい情報（KPIやグラフ）が1つの画面にスッキリ整理され、直感的に操作できる画面」**を指します。 Streamlitには、HTMLやCSSの知識がなくても、コード数行でプロ級のレイアウトが作れる強力な機能が標準装備されています。

6.1.1 操作盤は左側に格納する：st.sidebar¶

前回のアプリでは、スライダーやセレクトボックスを画面中央に配置したため、増えてくると縦に長くなり、データやグラフが下に追いやられてしまいました。 これを解決するのが サイドバー（st.sidebar） です。

通常のコマンドの頭に、ドット（.）を挟んで st.sidebar.〇〇 と書くだけで、画面の左端にグレーのオシャレな「折りたたみ式の操作サイドバー」が自動生成されます。

# 通常の配置（画面中央に表示される）
selected_shop = st.selectbox("店舗名:", ["江古田店", "白山店"])

# サイドバーへの配置（画面の左端に格納される！）
selected_shop = st.sidebar.selectbox("分析する店舗を選択してください:", ["江古田店", "白山店"])

6.1.2 指標やグラフを横に並べる：st.columns()¶

Streamlitは標準ではパーツを「上から下へ縦一列」にしか並べられません。しかし、売上の金額や客数のような 主要指標（KPI: Key Performance Indicator） は、横並びで一目で確認できるようにしたいですよね。

これを実現するのが st.columns(個数) です。この関数を使うと、画面の幅を縦に等分割（カラム化）して、パーツを横並びに配置できます。

【ダッシュボードの理想的なレイアウト（アスキーアート）】

  ┌────────────────────────────────────────────────────────┐
  │  [ ☕ 武蔵カフェ運営ダッシュボード ]                     │ 💻 画面中央（メイン領域）
  ├──────────────┬─────────────────────────────────────────┤
  │ ⚙️ 操作盤   │  [ KPI 1: 総売上 ]   [ KPI 2: 来客数 ]     │ ・ st.columns で横並び配置
  │ (sidebar)    │  1,200,000 円        2,500 人           │
  │              ├─────────────────────────────────────────┤
  │ ・店舗を選ぶ │  [ 📈 リアルタイム売上推移グラフ ]      │ ・ st.pyplot で
  │ ・日付を選ぶ │                                         │   動的なグラフを描画
  │              │    ───○───────○──                      │
  └──────────────┴─────────────────────────────────────────┘

Columnsの基本文法（アンパッキングと with 構文）¶

st.columns(3) を実行すると、3つの「カラムオブジェクト」がリスト形式で返ってきます。これをPythonの変数展開（アンパッキング）を使って受け取り、with 構文を用いて「どのカラムに何を表示するか」を指定します。

  • ※このコードセルを実行して、Colab上に app.py を書き出してみましょう。

%%writefile app.py
import streamlit as st

# 1. サイドバーの設定（ st.sidebar.〇〇 と書くのがポイント！）
st.sidebar.title("⚙️ 操作メニュー")
st.sidebar.write("分析の設定をここで変更します。")
selected_branch = st.sidebar.selectbox("店舗を選択してください:", ["江古田店", "白山店", "池袋店"])

# 2. メイン画面の設定
st.title("📊 武蔵カフェ 経営分析ポータル")
st.write(f"現在、**{selected_branch}** の最新営業データを表示しています。")

# 3. 画面を横に3等分（3つのカラムを作成）
col1, col2, col3 = st.columns(3)

# with カラム名: を使うことで、それぞれの枠の中に部品を流し込みます！
with col1:
    # st.metric は、ラベル・数値・変化量を美しく表示する専用部品です
    st.metric(label="期間内の総売上", value="354,000 円", delta="+12,000円")
with col2:
    st.metric(label="期間内の総客数", value="720 人", delta="+45人")
with col3:
    st.metric(label="平均客単価", value="491 円", delta="-15円", delta_color="inverse") # delta_color="inverse"でマイナスを青に（経費削減等の評価用）

  • ※前回導入した起動コマンドをColabの別のセルで実行し、ブラウザでレイアウトを確認してみましょう。

# （準備：もし前回の実行でポートが塞がっている場合は、一度リセットします）
!pkill streamlit
!pkill lt

# あなたのColab環境のIPアドレス（パスワード）を表示します
!wget -qO- ipv4.icanhazip.com

# アプリをバックグラウンドで起動

6.2 Pandas ✕ UI：連動データのフィルタリング (約20分)¶

画面のレイアウトが整ったら、次はいよいよ 「データとUIのガッチャンコ（連動）」 に挑みます！ 「ドロップダウンメニュー（UI）で選ばれた値」を使って、「Pandasのデータフレーム（データ）」を即座に絞り込み、画面に出力します。

6.2.1 仕組み：変数の連動¶

Streamlitの優れた特徴は、**「ユーザーが操作した瞬間、そのUIが持つ値が変数に自動代入され、コード全体が上から下まで超高速で再実行（Rerun）される」**点にあります。

これを利用して、Pandasの条件抽出の「抽出条件（右辺）」の部分に、UIの戻り値を代入した変数を指定してあげます。

# ----------------------------------------------------
# 従来のPandas（静的）: 
# 「白山店」という特定の文字列でしか絞り込めない。
# ----------------------------------------------------
df_filtered = df[df["店舗名"] == "白山店"]

# ----------------------------------------------------
# Streamlitとの連動（動的）:
# ユーザーが画面上で選んだ文字列が shop という変数に入り、
# その変数を使ってデータフレームがリアルタイムに絞り込まれる！
# ----------------------------------------------------
shop = st.sidebar.selectbox("店舗選択", ["江古田店", "白山店"])

df_filtered = df[df["店舗名"] == shop] # 🌟 運命の連動！

実際にこの動きをするコードを app.py に書き出し、ブラウザをリロードしてみましょう。左側の店舗を選ぶと、画面中央のデータフレームの中身と、上のKPIメーターの数字が瞬時に再計算されて変化するはずです！

%%writefile app.py
import streamlit as st
import pandas as pd

# 1. 模擬の売上データフレームを作成（本当はCSVを読み込みますが、まずはコード内でダミー作成）
df_sales = pd.DataFrame({
    "日付": ["7/1", "7/1", "7/2", "7/2", "7/3", "7/3", "7/4", "7/4"],
    "店舗名": ["江古田店", "白山店", "江古田店", "白山店", "江古田店", "白山店", "江古田店", "白山店"],
    "売上額 (円)": [120000, 80000, 150000, 95000, 110000, 75000, 130000, 85000],
    "来客数 (人)": [240, 180, 300, 210, 220, 160, 260, 170]
})

st.sidebar.title("⚙️ 操作メニュー")
# ユーザーが店舗を選ぶ（選んだ文字が shop 変数に代入される）
shop = st.sidebar.selectbox("分析対象の店舗を選択してください:", ["江古田店", "白山店"])

st.title("📊 店舗別・リアルタイム売上ダッシュボード")
st.write(f"現在、**{shop}** の抽出データを営業分析しています。")

# 🌟 フィルタリング処理（選ばれた shop に応じて Pandas が瞬時にスライス！）
df_filtered = df_sales[df_sales["店舗名"] == shop]

# 2. 画面を2分割して、絞り込まれたデータの統計量を表示
col1, col2 = st.columns(2)
with col1:
    total_sales = df_filtered["売上額 (円)"].sum()
    st.metric(label="期間内の総売上額", value=f"{total_sales:,} 円") # :, で3桁カンマ区切り
with col2:
    total_customers = df_filtered["来客数 (人)"].sum()
    st.metric(label="期間内の総来客数", value=f"{total_customers:,} 人")

# 3. 画面の下部に、絞り込まれた表そのものを美しく表示
st.subheader(f"📋 {shop} の生データ一覧")
st.dataframe(df_filtered) # st.dataframe はスクロール可能なエクセル風の表を表示します

6.3 グラフ ✕ UI ✕ アップローダー：リアルタイム可視化と汎用ツール化 (約25分)¶

データとKPIメーターの連動ができたら、次はビジュアル（グラフ）の連動、そして「手持ちのデータをその場で放り込んで分析できるアップローダー機能」を搭載しましょう。

6.3.1 リアルタイムグラフの描画（Matplotlibの埋め込み）¶

第4回で学んだMatplotlibによるグラフ作成コードを、Streamlitに埋め込むのは非常に簡単です。 普段、グラフを描く際に作成している fig（Figureオブジェクト）を、最後に st.pyplot(fig) というコマンドに渡すだけで、Web画面上に美しい高解像度のグラフがリアルタイムにプロットされます。

# （グラフ連動のイメージ）
# 1. Pandasで絞り込んだデータを使って、いつも通りMatplotlibでグラフを描く
fig, ax = plt.subplots()
ax.plot(df_filtered["日付"], df_filtered["売上額 (円)"], marker="o")

# 2. 最後に st.pyplot() にそのグラフを渡すだけで、Webに自動で埋め込まれる！
st.pyplot(fig)

6.3.2 📁 究極の汎用化：st.file_uploader¶

ここまでは、プログラムコードの中に直接売上データを書き込んでいました。 しかし、本物のデータ分析アプリなら、「ユーザーが自分で持っている店舗の売上CSVファイルをブラウザにドラッグ＆ドロップしたら、自動でその場で集計してグラフ化してくれる」ようにしたいですよね。

Streamlitを使えば、ファイルを読み込むためのカッコいいアップローダー画面を、わずか1行で設置できます！

# ファイルアップローダーを画面に設置
uploaded_file = st.file_uploader("ここに店舗売上のCSVファイルをドラッグ＆ドロップしてください", type="csv")

if uploaded_file is not None:
    # アップロードされたファイルを、Pandasで即座に読み込み可能！
    df_user = pd.read_csv(uploaded_file)
    st.success("ファイルの読み込みに成功しました！")
    st.dataframe(df_user.head(3))

それでは、これらを統合した 「売上グラフ連動＋全自動CSV読み込み」の完全なプログラム を app.py に書き出してみましょう。

  • ※このコードセルを実行してブラウザの動作を確認してください。

%%writefile app.py
import streamlit as st
import pandas as pd
import matplotlib.pyplot as plt
import japanize_matplotlib # 日本語文字化け防止用ライブラリ

# タイトル
st.title("📁 汎用店舗売上分析ダッシュボード")
st.write("お手持ちの売上CSVファイルをアップロードすると、自動でKPIメーターと折れ線グラフを生成します。")

# 1. ファイルアップローダーの設置（CSVファイルのみを受け取ります）
uploaded_file = st.file_uploader("売上CSVファイルをアップロードしてください", type="csv")

# 2. もしファイルがアップロードされたら（Noneではない場合）
if uploaded_file is not None:
    # アップロードされたバイトデータを直接Pandasに読み込ませます！
    df = pd.read_csv(uploaded_file)
    st.success("🎉 ファイルの展開に成功しました！データを分析します。")
    
    # 読み込んだデータの店舗一覧を取得して、サイドバーの選択肢にする
    shop_list = df["店舗名"].unique()
    selected_shop = st.sidebar.selectbox("分析対象の店舗を選択:", shop_list)
    
    # 選ばれた店舗でデータをフィルタリング
    df_filtered = df[df["店舗名"] == selected_shop]
    
    # メイン画面にKPIを表示
    st.subheader(f"🏠 {selected_shop} の重要指標")
    col1, col2 = st.columns(2)
    with col1:
        total_sales = df_filtered["売上額 (円)"].sum()
        st.metric(label="総売上額", value=f"{total_sales:,} 円")
    with col2:
        total_customers = df_filtered["来客数 (人)"].sum()
        st.metric(label="総客数", value=f"{total_customers:,} 人")

練習問題 5: 操作のたびに起きる「Rerun（再実行）」と st.button の罠（理論・最重要）¶

Streamlitは、スライダーを動かしたりドロップダウンを選んだりするたびに、裏側で「Pythonコードが1行目から最後まで全部自動で再実行（Rerun）される」という仕組みを持っています。

このとき、**「st.button('計算実行') をクリックした中の処理で、さらにセレクトボックスを操作すると、さっきクリックして実行したはずの計算結果が画面から一瞬で消えてしまう」**というバグが初心者の間で100%発生します。 なぜ計算結果が消えてしまうのか、再実行（Rerun）時の「ボタンの状態の判定」に触れながら、その理由を説明してください。

👉 練習問題 5 の解答と解説を見る

  • 正解:

    • ユーザーがボタンをクリックした「その瞬間」の実行時のみ、st.button の判定は True になります。

    • しかし、その後、ユーザーが別のセレクトボックスを操作すると、Streamlitは再びコードを1行目から実行し直します（Rerun）。

    • この再実行の際、「ボタンはたった今クリックされたわけではない（別の場所が操作された）」と判定されるため、st.button の戻り値は自動的に False（押されていない状態） に戻ってしまいます。

    • 結果として、if st.button(...): の中に書いていた計算処理や表示処理が丸ごとスキップされてしまうため、画面から計算結果が一瞬で消え去ってしまうのです。

  • 解説:

    • これがStreamlitの「再実行システム」の最も重要なクセです。

    • ボタンを押した結果をずっと残したり、複数の操作をまたいでデータを保持したい場合は、次回以降で学ぶ「状態保持（st.session_state）」というプロの技術を使う必要があります。

✨ 今日の重要キーワード¶

  • st.sidebar：画面中央を広く使うために、操作ドロップダウンなどのウィジェットを画面の左端にスッキリ格納する。

  • st.columns：画面を縦に複数分割し、総売上や来客数などの主要指標（KPI）を横並びに美しく並べる。

  • st.metric：経営指標の「現在の値」と、前日比・前月比などの「変化（delta：矢印）」を自動色付きでオシャレに表示する。

  • Pandas ✕ UI連動：ユーザーが画面で選択した値（変数）を、Pandasの条件抽出の条件式に流し込むことで、瞬時に全データと連動してグラフや集計値が再実行される。

  • st.file_uploader：ドラッグ＆ドロップで任意のCSVファイルを取り込み、データ構造を即座にダッシュボードに反映させる。

❓ よくある質問と回答 (FAQ)¶

  • Q. st.file_uploader にエクセル（.xlsx）のファイルを投げるとエラーになります。

    • A. 非常によくある疑問です！今回のコードは pd.read_csv() を使ってCSV（カンマ区切りテキスト）を読み込むように設計しています。エクセルファイルをそのまま読み込ませたい場合は、ライブラリのインストール（!pip install openpyxl）を済ませた上で、コード部分を pd.read_excel(uploaded_file) に変更してあげれば、エクセルファイルもその場でドラッグ＆ドロップして全く同じようにダッシュボードに展開することができますよ！

  • Q. 毎回サイドバーを切り替えるたびに画面がリロードされて、グラフが再描画されるのは重くないですか？

    • A. その通りです！現在はデータ量が少ないため一瞬で再計算（Rerun）されますが、実務で何百万行もの巨大なデータを扱う場合、毎回上から下までコードを走らせるとアプリの動きが重くなってしまいます。これを解決するために、Streamlitには st.cache_data という「一度読み込んだ巨大なデータフレームを一時記憶して使い回す、プロ用の高速化おまじない」が用意されています。興味がある方は、ぜひ「Streamlit キャッシュ」で調べてみてくださいね。
