4.1 記述統計の基本：平均値の「甘い罠」とデータの「ばらつき」 (約40分)¶

データを入手した際、まず最初に行うのが「データ全体のざっくりとした特徴（要約統計量）」を計算することです。これを統計学では**「記述統計（Descriptive Statistics）」**と呼びます。 しかし、ここで「とりあえず平均値を出しておけば大丈夫」と考えていると、データに騙されることになります。

4.1.1 平均客単価の罠：ビル・ゲイツ氏が来店した日¶

例えば、あなたが江古田でオシャレな学生カフェを経営しているとします。 ある日、来店したお客様10人の「購入金額」は、普段は 300円〜500円 の範囲でした。しかし、そのうちの1人がたまたま超大富豪（ビル・ゲイツ氏）で、お店に飾ってあった2億円のオブジェをキャッシュで購入していきました。

この日の客単価データは以下のようになります。 [350円, 400円, 380円, 450円, 300円, 420円, 390円, 360円, 410円, 200,000,000円（ゲイツ氏）]

このデータをPandasに入力し、「平均値（Mean）」と「中央値（Median）」を計算して比較してみましょう。

# ------------------------------------------------------------------
# コードセル：平均値と中央値の比較
# ------------------------------------------------------------------
import pandas as pd

# 10人のお客様の購入金額データ
sales_data = pd.Series([350, 400, 380, 450, 300, 420, 390, 360, 410, 200000000])

# 平均値（Mean）の計算
mean_val = sales_data.mean()

# 中央値（Median）の計算
median_val = sales_data.median()

print(f"💰 平均客単価: {mean_val:,.1f} 円 (えっ！？全員が2000万円も使ったの！？)")
print(f"🎯 中央客単価: {median_val:,.1f} 円 (なるほど、普段通り約395円だね！)")

【解説】

  • **平均値（.mean()）**は、「全員の合計金額を人数で割る」という計算をするため、1件でも異常に巨大な値（外れ値：Outlier）が混ざると、強烈にその数値に引っ張られてしまい、実態を全く表さなくなります。

  • **中央値（.median()）は、データを小さい順に並べ替えたときに「ちょうど真ん中の順位（50%目）にくる値」**です。どれほど極端な外れ値が混ざっていても、順位自体は1つしかズレないため、外れ値の影響を完全にシャットアウトし、「普段の一般的なお客様の姿」をきれいに映し出すことができます。

⚠️ データリテラシー: ニュースで「日本の平均年収は450万円です」と言われた際、多くの人が「自分は平均以下だ…」と落ち込みます。しかし、実際は一部の超高所得層（大企業の社長やスポーツ選手など）が平均値を強烈に引き上げています。実態に近い年収（日本人のちょうど真ん中の人の年収＝中央値）を調べると、約360万円〜380万円付近になり、平均値より約100万円近く低くなります。データを見るときは、常に「平均値の罠」を疑い、中央値も同時に確認する癖をつけましょう！

4.1.2 データのばらつきを測る「標準偏差（Standard Deviation）」¶

平均値や中央値といった「真ん中の値」が分かったら、次に知りたいのは**「データはどのくらい散らばっているのか？（個人差が大きいのか、全員同じくらいなのか）」**という情報です。

ここに、1日の総売上高がどちらも「ぴったり30万円」である2つの店舗があります。

  • A店（安定型）：来店するお客様全員が、ほぼ均一に「300円〜400円」のコーヒーとパンを頼んでいく。

  • B店（波乱万丈型）：100円のガム1個だけを買う極端な学生もいれば、一度に2万円分のギフト用コーヒー豆をまとめ買いする近所のマダムもいる。

この2つの店の「個人差（ばらつき）」を数値化したものが**「標準偏差（Standard Deviation）」**です。 数式は難しそうに見えますが、直感的な意味は極めてシンプルです。

💡 標準偏差の直感的な定義： 「全員のデータが、平均値から平均して『どれくらいの距離（金額）』離れているかを表す指標」

【標準偏差（ばらつき）のビジュアル図解】

  【 A店 (標準偏差が小さい) 】             【 B店 (標準偏差が大きい) 】
      
       |      ●●●                      |   ●
       |    ●●●●●                     |   ●      ●       ●
  ─────┼──────●───────▶             ─────┼──────●───────▶
       |    (平均350円)                |    (平均350円)
    (全員が平均のすぐ近くにいる)            (平均から遠く離れた人が多い)

Pandasでこの「ばらつき」を計算してみましょう。

# ------------------------------------------------------------------
# コードセル：標準偏差（ばらつき）の計算
# ------------------------------------------------------------------
# A店とB店の顧客ごとの購入額データ（各10人）
shop_A = pd.Series([350, 360, 340, 350, 370, 330, 350, 360, 340, 350]) # 平均350円
shop_B = pd.Series([100, 500,  50, 800, 150, 100, 350,  50, 400, 1000]) # 平均350円

print(f"🏪 A店の平均値: {shop_A.mean():.1f} 円 / 標準偏差(std): {shop_A.std():.1f}")
print(f"🏪 B店の平均値: {shop_B.mean():.1f} 円 / 標準偏差(std): {shop_B.std():.1f}")

【解説】

  • A店の標準偏差は 11.5 です。これは「顧客全員の金額が、平均350円からプラスマイナス11.5円程度の非常に狭い範囲にギュッと集まっている（ばらつきが極めて小さい）」ことを示しています。

  • B店の標準偏差は 333.3 です。これは「顧客全員 of 金額が、平均350円から平均して約333円も遠く離れた、非常に激しいバラバラな状態にある（ばらつきが極めて大きい）」ことを意味します。

  • ビジネスにおいて、標準偏差を知ることは「仕入れや在庫の安定性」を予測する上で、平均値と同じくらい極めて重要な意味を持ちます。

4.2 データ評価の新概念：「定量的評価」と「定性的評価」の融合 (約40分)¶

データ分析から実社会に役立つ知見（意思決定）を導き出すとき、私たちは**「データ評価（Data Evaluation）」**というステップを踏みます。 この評価には、全く異なる2つのアプローチが存在します。

       【 📊 データ評価の2大アプローチ 】
        ├── ① 定量的評価 (Quantitative): 「数値」で測る。客観的、全体像の把握。
        └── ② 定性的評価 (Qualitative): 「背景・文脈」を探る。主観、理由・動機の探索。

4.2.1 定量的評価（Quantitative Evaluation）¶

  • 特徴：すべてのデータを「数値（数量）」に変換し、統計量やグラフを用いて客観的に評価します。

  • メリット：主観を排除し、誰が見ても同じ結論に至ります。大規模なデータの「全体像」を捉えるのが大得意です。

  • よく使う道具：平均値、中央値、標準偏差、相関係数、売上高、パーセント比率など。

  • 限界：「なぜその数値になったのか」という、人間の感情や偶発的な現場のトラブルなどの**「裏の理由」**を説明することはできません。

4.2.2 定性的評価（Qualitative Evaluation）¶

  • 特徴：数値にできない「言語、状況、背景、感情、歴史的コンテキスト」に注目し、深く評価します。

  • メリット：「なぜそうなったのか」という根本的な原因やプロセス、データの収集過程における現場の制約などを解き明かします。

  • よく使う道具：インタビュー、行動観察、歴史的背景の調査、エラーや欠損データの発生原因の推測など。

  • 限界：客観的な比較や、大規模なデータ全体に対して「本当にそれが代表的な意見か」を一般化することが難しく、評価者の主観が入りやすいです。

4.2.3 実践データの導入：「南極パルマー半島のペンギン調査データ」¶

この「定量的」「定性的」な2つのアプローチを融合させて評価する極上のお手本として、2007年〜2009年にかけて南極半島で観測された**「ペンギンの体格調査データ（Palmer Penguins）」**を導入します。

このデータは、アデリー（Adelie）、ヒゲ（Chinstrap）、ジェンツー（Gentoo）という3種類のペンギンの体格を測定した、世界中のデータサイエンス教材で絶大な人気を誇る実データです。

まずはGoogle Colab上にデータをインポートし、データ構造を定量的・定性的に確認しましょう。 ※ネットワーク環境が不安定な場合を考慮し、自動でバックアップデータを作成する「セーフティネットコード」を搭載しています。

# ------------------------------------------------------------------
# コードセル：ペンギンデータのインポートとお掃除
# ------------------------------------------------------------------
import pandas as pd
import numpy as np

# インターネットからパルマーペンギンデータを読み込みます
try:
    url = "https://raw.githubusercontent.com/mwaskom/seaborn-data/master/penguins.csv"
    df_penguins = pd.read_csv(url)
    print("🐧 オンラインのSeabornリポジトリからペンギンデータを読み込みました！")
except Exception as e:
    # 読み込めない場合は、Colabローカルで本物とほぼ同じダミーデータをその場で構築します
    print("⚠️ 接続エラーのため、ローカルで模擬ペンギンデータを生成します。")
    np.random.seed(42)
    n = 344
    species_choice = np.random.choice(["Adelie", "Chinstrap", "Gentoo"], n, p=[0.44, 0.20, 0.36])
    island_choice = np.where(species_choice == "Adelie", 
                             np.random.choice(["Torgersen", "Biscoe", "Dream"], n),
                             np.where(species_choice == "Gentoo", "Biscoe", "Dream"))
    
    bill_len = np.where(species_choice == "Adelie", np.random.normal(38.8, 2.6, n),
               np.where(species_choice == "Chinstrap", np.random.normal(48.8, 3.3, n), np.random.normal(47.5, 3.1, n)))
    bill_depth = np.where(species_choice == "Adelie", np.random.normal(18.3, 1.2, n),
                 np.where(species_choice == "Chinstrap", np.random.normal(18.4, 1.1, n), np.random.normal(15.0, 1.0, n)))
    flipper_len = np.where(species_choice == "Adelie", np.random.normal(190, 6.5, n),
                  np.where(species_choice == "Chinstrap", np.random.normal(195, 7.1, n), np.random.normal(217, 6.5, n)))
    mass = np.where(species_choice == "Adelie", np.random.normal(3700, 450, n),
           np.where(species_choice == "Chinstrap", np.random.normal(3730, 380, n), np.random.normal(5070, 500, n)))
    
    df_penguins = pd.DataFrame({
        "species": species_choice,
        "island": island_choice,
        "bill_length_mm": np.round(bill_len, 1),
        "bill_depth_mm": np.round(bill_depth, 1),
        "flipper_length_mm": np.round(flipper_len, 0),
        "body_mass_g": np.round(mass, 0),
        "sex": np.random.choice(["MALE", "FEMALE", np.nan], n, p=[0.48, 0.48, 0.04])
    })
    # 意図的にいくつかの測定値を欠損（NaN）にする
    for col in ["bill_length_mm", "bill_depth_mm", "flipper_length_mm", "body_mass_g"]:
        df_penguins.loc[df_penguins.sample(frac=0.01).index, col] = np.nan

# データの基本情報の表示
print(f"データの行数: {df_penguins.shape[0]}行, 列数: {df_penguins.shape[1]}列")
display(df_penguins.head(5))

4.2.4 ペンギンデータの定性的評価：欠損値「NaN」に隠された現場の真実¶

このデータフレームを眺めると、いくつかのデータが NaN（欠損値：データが入っていない状態） になっていることが分かります。

ここで、「定性的評価」の出番です。 単に「データが欠損しているからプログラムで削除（クレンジング）しよう」と機械的に処理する前に、「なぜ2007年〜2009年の南極の現場で、このデータが欠損したのか？」という背景を定性的に想像・考察してみましょう。

【欠損が発生した南極の調査現場の定性的考察（仮説）】

  1. 野生ペンギンが暴れた可能性： ペンギンの「体重（body_mass_g）」を量るには、ペンギンをネット（網）に入れて吊り下げる必要があります。その際、野生のペンギン（特に大型のジェンツーペンギンなど）が激しく暴れて暴動状態になり、安全のために測定を断念したのかもしれません。

  2. 極寒と吹雪による気象条件の悪化： 測定が行われたパルマー半島は、時に強烈なブリザード（吹雪）が吹き荒れます。気温がマイナス数十度になり、測定用の電子機器がフリーズしてしまったり、研究者の指がかじかんでノギス（くちばしの長さを測る道具）が動かせなくなり、泣く泣く測定をスキップしてテントに避難した光景が目に浮かびます。

  3. 「性別（sex）」の判定の難しさ： ペンギンは外見からオスとメスを区別することが極めて困難な動物です（外見的な性差がほとんどありません）。性別を確定させるためには、血液を採取してDNA検査を行う必要がありますが、すべてのペンギンから血液を採取できる時間や医療資材の余裕が現場になかったため、「性別：欠損（NaN）」として記録せざるを得なかった可能性があります。

このように、データが生まれた「背景（定性的な物語）」に目を向けることで、欠損値はただのゴミではなく、**「過酷な南極で命がけで調査した研究者たちの戦いの歴史」**として見えてくるようになります。

4.3 クロス集計とピボットテーブル：データをグループで評価する (約30分)¶

それでは、データを属性（ペンギンの「種別」や「生息する島」）ごとに細かく切り分けて評価していきましょう。

4.3.1 pd.crosstab による生息地の分布評価¶

どの島（island）に、どの種別（species）のペンギンが何羽生息しているかをクロス集計してみましょう。

# ------------------------------------------------------------------
# コードセル：島と種別のクロス集計（度数）
# ------------------------------------------------------------------
# 島（行）と種別（列）のクロス集計
island_species = pd.crosstab(df_penguins["island"], df_penguins["species"])

print("▼ 島別 ✕ ペンギン種別 の生息羽数（クロス集計）")
display(island_species)

【解説と定性的評価への接続】 クロス集計を実行すると、非常に面白い「定性的な事実」が浮かび上がります。

  • アデリーペンギン（Adelie）：Torgersen, Biscoe, Dream という3つの島すべてに広く均等に分布して生息しています。

  • ヒゲペンギン（Chinstrap）：Dream島にしか生息していません。

  • ジェンツーペンギン（Gentoo）：Biscoe島にしか生息していません。

ここから、定性的な仮説として「アデリーペンギンは環境適応力や食性が広く、どこでも生きていけるタフな性質があるが、ジェンツーペンギンやヒゲペンギンは、その島にしかない特殊なエサ（特定のオキアミ）や地形（巣作りに必要な石の種類や傾斜）に依存した繊細な生態を持っているのではないか？」という評価を導くことができます。

4.3.2 pd.pivot_table による体格の定量的評価¶

次に、ピボットテーブルを使って「種別ごと・性別ごとの平均体重（body_mass_g）」をマトリクス集計してみましょう。

# ------------------------------------------------------------------
# コードセル：ピボットテーブルによる平均体重集計
# ------------------------------------------------------------------
# 縦軸に「species（種別）」、横軸に「sex（性別）」、値に「body_mass_g（体重）」の平均を配置
pivot_mass = pd.pivot_table(
    df_penguins,
    values="body_mass_g",
    index="species",
    columns="sex",
    aggfunc="mean"
)

print("▼ ペンギン種別 ✕ 性別 の平均体重（グラム）ピボットテーブル")
display(pivot_mass)

【解説と定量的評価の結論】

  • すべての種において、**「メス（FEMALE）よりもオス（MALE）の方が一回り体重が重い（体格が大きい）」**ということが、具体的な数値として客観的に証明（定量的評価）されました。

  • また、種別ごとに見ると、アデリー（約3,700g）とヒゲ（約3,730g）はほぼ同じ体格ですが、ジェンツーペンギン（Gentoo）はオス・メスともに5,000g（5kg）を超える圧倒的な大型種であることがはっきりと分かります。

4.4 相関分析とデータの「甘い罠」 (約30分)¶

ペンギンの体格データ（くちばしの長さ、深さ、フリッパー（翼）の長さ、体重）には、お互いにどのような関係性（相関）があるでしょうか？ Pandasの .corr() を使って、相関係数マトリクス（相関行列）を算出してみましょう。

# ------------------------------------------------------------------
# コードセル：ペンギンデータの相関行列
# ------------------------------------------------------------------
# 数値列だけを選択して相関行列を計算
corr_matrix = df_penguins.corr(numeric_only=True)

print("▼ ペンギン体格データの相関係数マトリクス")
display(corr_matrix.style.background_gradient(cmap="bwr", vmin=-1, vmax=1))

【定量的評価の解釈】

  • 「フリッパーの長さ（flipper_length_mm）」と「体重（body_mass_g）」の相関係数は約 0.87。極めて強い正の相関関係があります。「翼（フリッパー）が長いペンギンほど、体重も重い（体格が比例して大きい）」という、生物学的な法則がクリアな数値として評価できました。

⚠️ 【超重要】データ分析の高度な罠：シンプソンのパラドックス¶

相関行列を注意深く見ると、不思議な数値に気づきます。

  • **「くくちばしの長さ（bill_length_mm）」と「くちばしの深さ（bill_depth_mm）」の相関係数が、約 -0.23（弱い負の相関）**になっているのです。

「くちばしが長いペンギンほど、くちばしが薄く（浅く）なる」ということでしょうか？直感的には、体格が大きくなれば、くくちばしは「長く、かつ分厚く（深く）」なるはずです。

ここに、データ分析者全員が気をつけなければならない大罠**「シンプソンのパラドックス（Simpson's Paradox）」**が潜んでいます。

💡 シンプソンのパラドックスとは： 「全体のデータをまとめて相関を計算したときの関係性が、データをグループ（種別など）に細かく切り分けて計算したときに、真逆の関係性に反転してしまう現象」

百聞は一見に如かず。ペンギンの「種別（species）」ごとにグループ化して、種ごとの相関係数を再計算してみましょう！

# ------------------------------------------------------------------
# コードセル：種別ごとの相関関係の計算
# ------------------------------------------------------------------
print("--- 種別を分けない全体での相関 ---")
overall_corr = df_penguins["bill_length_mm"].corr(df_penguins["bill_depth_mm"])
print(f"全体での『長さ』と『深さ』の相関係数: {overall_corr:.3f} (負の相関！？)\n")

print("--- ペンギンの『種別ごと』に切り分けた相関 ---")
for spec in df_penguins["species"].unique():
    # 各種ごとにデータを絞り込んで相関を計算
    sub_df = df_penguins[df_penguins["species"] == spec]
    spec_corr = sub_df["bill_length_mm"].corr(sub_df["bill_depth_mm"])
    print(f"🐧 {spec}種内での『長さ』と『深さ』の相関係数: {spec_corr:.3f} (ええっ！？強い正の相関に大反転！)")

【解説とデータ評価としての教訓（定量的 ✕ 定性的）】

  • 全体のデータをまとめて計算した定量的評価では、**「-0.23（負の相関）」**に見えた関係が、種別という定性的なカテゴリでデータを切り分けて再集計すると、それぞれの種内では 「+0.5 〜 +0.7（強い正の相関＝くちばしが長くなれば、深さも分厚くなる）」という真逆の関係に大反転しました！

  • なぜこんなことが起きるかというと、アデリーペンギンは「くちばしが短くて分厚い」、ジェンツーペンギンは「くちばしが長くて薄い」という、種ごとの「生物学的な特徴（定性情報）」が、全体の平均位置をズラしてしまっていたからです。

  • 全体をまとめて「定量的」に計算しただけの数値がいかに嘘をつきやすいか、そして「種別ごとの特徴」という「定性的」な視点を持ってデータを切り分けて精緻に再評価することがいかに大切かを教えてくれる、極上のお手本です。

    • なぜジェンツーペンギンだけがこれほど巨大に進化したのでしょうか？ 定性的な調査によると、ジェンツーペンギンは、他の2種よりも**「より深く、遠い海まで潜水して魚を捕獲する」という生態を持っています。冷たい海の深海まで潜るためには、体温を保つための「大きな体（厚い皮下脂肪）」と、強い水圧に負けずに深海まで一気に推進力を生み出す「長く強力な翼（フリッパー）」が必要不可欠だった、という、過酷な南極海を生き抜くための美しい生存戦略（ストーリー）**が見えてきます。

このように、**「定量的（数字とグラフで客観的事実を固める）」と「定性的（生物学的な背景や生存戦略というストーリーで理由を説明する）」**の2つの車輪を回すことで、初めてデータの裏にある「真の評価」に到達することができます。

練習問題 3: 相関係数 \(r = -0.85\) の解釈¶

  1. 気温が上がると、おでんの売上も強烈に上昇する関係（強い正の相関）。

  2. 気温と、おでんの売上には全く何の関係も見られない（無相関）。

  3. 気温が上がると、おでんの売上が強烈に低下する関係（強い負の相関）。

👉 練習問題 3 の解答と解説を見る

  • 正解: 3

  • 解説:\n * 相関係数はマイナスの値のとき「負の相関（一方が上がれば、もう一方は下がる関係）」になります。

    • 数値が -0.85 と、極めて -1.0 に近いため、「強い負の相関（気温が低くなるほど、温かいおでんがよく売れる）」と正確に評価できます。

練習問題 4: シンプソンのパラドックスの恐ろしさ¶

👉 練習問題 4 の解答と解説を見る

  • 正解: シンプソンのパラドックス (Simpson's Paradox)

練習問題 5: 定性的評価と定量的評価のベストな関係¶

データ分析における「定量的評価（Quantitative）」と「定性的評価（Qualitative）」の関わり方として、最も適切なものはどれでしょうか？

  1. AIが発達した現代では、数値で表せる定量的評価だけを信じるべきであり、定性的評価は不要である。

  2. 定量的評価で「何が起きているか（客観的な数値）」を固め、定性的評価で「なぜそれが起きたのか（現場の背景や理由）」を説明する、両輪の組み合わせが最強である。

  3. 主観が入る定性的評価の方が常に正しいため、定量的な計算は時間潰しに過ぎない。

👉 練習問題 5 の解答と解説を見る

  • 正解: 2

  • 解説:\n * どちらか一方だけでは、本当のデータ評価はできません。

    • 「ジェンツーペンギンは体重が5kg以上（定量事実）」だけでは、単なる数字の羅列です。「なぜ深海に潜るためにその体重が必要だったか（定性背景）」が組み合わさることで、初めて説得力のある本物の意思決定や評価書が完成します。
