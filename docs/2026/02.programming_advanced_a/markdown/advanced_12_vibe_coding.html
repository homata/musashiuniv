第12回 Pythonとバイブコーディング（Vibe Coding）¶

皆さん、こんにちは！プログラミング応用A、第12回の講義です。担当の教員です。 これまでに、Pandasでのデータ加工、記述統計、GIS（動く地図アプリfolium）、Streamlit（Webアプリ開発）、そして前回と前々回のscikit-learnを用いた「AI・機械学習モデルの構築」まで、ものすごいスピードで高度な技術を習得してきました。本当に素晴らしい学習態度です。

さて、今日学ぶテーマは、今プログラミング界隈で最もホットで、未来の働き方をガラリと変える最新の開発パラダイム**「バイブコーディング（Vibe Coding）」**です！

「バイブコーディング」とは、一言で言えば**「コードの細かな文法は1文字も書かず、生成AIと会話しながら、作りたいアプリの『雰囲気（Vibe）』や『大まかな設計図』だけを伝えて、一瞬で高度なシステムを組み上げる開発スタイル」**のことです。

「自分が書けないはずの難しいコード」も、AIと呼吸（バイブ）を合わせることで、驚くほど動くシステムになって現れます。 今回は、これまでに学んだ「Pandasデータ処理 ✕ Matplotlibグラフ ✕ scikit-learn売上予測AI ✕ Streamlit WebUI」という、まともに書けば数日はかかる**「AI売上予測Webダッシュボード」を、AIの力を借りてわずか15分で完成させる実習**を行います。

文法暗記の苦しみから解放され、プログラミングが「最高に楽しいクリエイティブ活動」に変わる瞬間を、100分間かけて体感していきましょう！

🎯 到達目標 (約5分)¶

この授業が終わるころには、以下のことができるようになります。

  1. **バイブコーディング（Vibe Coding）**の定義と、開発における役割（指示者としての人間、実装者としてのAI）を説明できる。

  2. 生成AIから一発で動く完璧なコードを引き出すための**「プロンプトエンジニアリング（指示の書き方）」**の基本パターンを習得する。

  3. AIが生成したコードにエラーやバグがあった際、**エラーメッセージをAIに正しくフィードバックして自己解決（デバッグ）**できる。

  4. これまでに学んだ技術（Pandas, ML, Streamlit）をAIに指示して「合体」させ、実用的なWebダッシュボードを構築できる。

12.1 バイブコーディングとは何か？（プログラミングのパラダイムシフト） (約15分)¶

これまでのプログラミング学習は、「スペルミスをしないように、コロン（:）やインデントを1マスずつ気にして、文法を丸暗記して書く」のが普通でした。 しかし、ChatGPTやClaudeなどの優秀な生成AIの登場により、その常識がひっくり返りました。

「コードを書く人（実装者）」から「システムを設計する人（ディレクター）」へ¶

現代のプログラミングでは、役割分担が以下のように変わっています。

  • AI（プログラマー・実装者）： 指示されたコードを、一瞬で正確に書く。バグの修正も得意。ただし、「何を作れば人間が喜ぶか」「社会のどんな課題を解決するか」は自分で考えられない。

  • 人間（設計者・ディレクター）： 🌟あなたの役割！ 「どんな画面にしたいか」「何のデータを読み込ませたいか」「どういう人がこのアプリを使うか」という、全体の雰囲気（Vibe）と設計図を考え、AIを指揮する。

【バイブコーディングの開発ループ（イメージ図）】

  [ 🧠 人間：アイデアとVibe ]
         │  (「こんな売上予測アプリをStreamlitで作って！」)
         ▼
  [ 🤖 AI：爆速コーディング ]
         │  (一瞬で200行の完璧なコードを吐き出す)
         ▼
  [ 💻 実行＆テスト ] ──▶ [ 🐛 エラー発生！ ] ──▶ [ 🤖 AIにエラー文を貼る ]
         │                                               │
         │                                               ▼
         │                                       [ 🛠️ AIが即座に修正 ]
         ▼
  [ 🎉 わずか15分で完成！ ]

文法を覚えることよりも、**「何を作りたいかをAIに分かりやすく伝える力」と、「AIが書いたコードが本当に正しく動いているかを見破る検証力」**が、これからの時代に最も求められるプログラミングスキルなのです。

12.2 AIから完璧なコードを引き出す「プロンプトの極意」 (約20分)¶

AIに「売上予測アプリのコードを書いて」とだけ頼むと、高確率で「自分が使っている環境（Colabなど）では動かないコード」や「中身がスカスカの適当なコード」が返ってきます。 AIを最高の部下（ペアプログラマー）として動かすための、プロンプトの4大要素を覚えましょう。

  1. 役割（ペルソナ）の指定：「あなたは世界最高峰のPythonデータサイエンティストです。」

  2. 前提条件（環境）の指定：「Google Colab上で、Streamlitとlocaltunnelを使って開発しています。」

  3. 具体的な要件（インプットとアウトプット）：「説明変数に客数(X)、目的変数に売上(y)を使い、決定係数(R²)も画面に表示してください。」

  4. 出力フォーマットの指定：「コピペするだけで動く、1つの Python ファイル（app.py）にまとめて出力してください。」

12.3 実践デモ：15分で「AI売上予測Webアプリ」をバイブコーディング！ (約30分)¶

それでは、実際にAIに指示を出して、前々回（Streamlit）と前回（scikit-learn 機械学習）の技術が全て合体した「AI売上予測Webダッシュボード」を一撃で構築するデモを行います。

今回は、授業用の「特製プロンプト」を用意しました。これをAIに投げると、以下のようなプロ級のコードが自動生成されます。

🌟 AIに投げたプロンプト（Vibe）¶

あなたは優秀なデータサイエンティストです。
Google Colab上で、Streamlitとlocaltunnelを使って起動する「売上予測AIダッシュボードアプリ」のコードを Python で書いてください。
【要件】
1. サイドバーで「客数（スライダー）」を動かせるようにしてください。
2. スライダーの客数から、線形回帰モデルを使って「予測売上高」を計算し、画面にデカデカとメーター（Metric）で表示してください。
3. メイン画面には、過去の模擬データ（客数と売上）の点々と、AIが引いた「予測直線」を Matplotlib で描画して表示してください。
4. コピペするだけで動く、1つの「app.py」ファイルとして完結するコードにしてください。

上記をAIに投げ、返ってきたコードを Colab の /workspace/scratch/app.py に保存し、localtunnelで起動します。

<!-- コードセル -->
# （準備）AIが生成したコード（app.py）を書き込みます。
# 通常の授業では、学生が生成AI（ChatGPTなど）にプロンプトを投げて返ってきたコードをここにコピペします。
# 今回は、100%一撃で動く「AIが生成した最高水準のダッシュボードコード」を事前に用意して書き込みます。

app_code = """
import streamlit as st
import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
from sklearn.linear_model import LinearRegression

st.set_page_config(page_title="AI売上予測システム", layout="wide")

# タイトル
st.title("📊 カフェ売上予測 AIダッシュボード")
st.write("過去の客数データからAIが自動で学習し、客数スライダーの動きに連動して『未来の売上高』を一瞬で予測します。")

# 1. 模擬データの作成（客数と売上）
np.random.seed(42)
customers = np.random.randint(50, 300, 50)
sales = customers * 350 + np.random.normal(0, 10000, 50) # 1人あたり350円 + ノイズ

df = pd.DataFrame({"客数": customers, "売上高": sales})

# AIモデル（線形回帰）の学習（このアプリが起動した瞬間に一瞬で学習します！）
X = df[["客数"]]
y = df["売上高"]
model = LinearRegression()
model.fit(X, y)

# 2. サイドバーでの入力（UI）
st.sidebar.header("🔮 未来の客数をシミュレーション")
input_customers = st.sidebar.slider("予測したい明日の客数（人）", min_value=10, max_value=400, value=150)

# 3. AIによる予測
pred_sales = model.predict(np.array([[input_customers]]))[0]

# 4. KPIメーターの表示
col1, col2 = st.columns(2)
with col1:
    st.metric(label="明日の予測客数", value=f"{input_customers} 人")
with col2:
    st.metric(label="💰 AI予測売上高", value=f"{int(pred_sales):,} 円", delta=f"客単価換算: {int(pred_sales/input_customers)}円")

# 5. グラフの描画（Matplotlib）
fig, ax = plt.subplots(figsize=(10, 5))
ax.scatter(df["客数"], df["売上高"], color="blue", alpha=0.6, label="過去の営業データ")
# 予測直線の描画
line_X = np.linspace(10, 400, 100).reshape(-1, 1)
line_y = model.predict(line_X)
ax.plot(line_X, line_y, color="red", linestyle="--", linewidth=2, label="AIが学習した売上予測ライン")
# 現在のスライダーの位置を黄色い星でプロット！
ax.scatter([[input_customers]], [pred_sales], color="yellow", edgecolor="black", s=300, marker="*", zorder=5, label="明日の予測位置")

ax.set_xlabel("客数（人）")
ax.set_ylabel("売上高（円）")
ax.legend()
ax.grid(True)

# Streamlitにグラフを配置
st.pyplot(fig)
"""

# ファイルに書き出す
with open("app.py", "w", encoding="utf-8") as f:
    f.write(app_code)

print("AIが生成した app.py をローカル環境に書き出しました！")

それでは、第5回で学んだ 「localtunnel」 を使って、このAIアプリを起動してみましょう！ （以下のコードセルを実行し、表示されるIPアドレスをコピーして、青いリンクをクリックして貼り付けます。）

  2. 選択された商品の「価格」を、st.write を使って「〇〇の価格は 〇〇円です」と画面に分かりやすく表示するコードにしてください。 コピペだけで動くコードにしてください。

演習3（エラーデバッグ）の解答例

提供されたコードを実行したところ、以下のエラーが発生しました。

NameError: name 'plt' is not defined

おそらく、matplotlib.pyplot を plt としてインポートするコード（import matplotlib.pyplot as plt）がファイルの上部で抜けていることが原因だと思います。このバグを修正した、完全なコードを再出力してください。

演習4（GIS ✕ Streamlit）の解答例

あなたはGIS（地理情報システム）に強いデータサイエンティストです。 Streamlit と folium（もしくは streamlit_folium）を使って、Google Colab上で起動する地図アプリのコードを書いてください。 【仕様】

  1. セレクトボックス（st.selectbox）で「東京駅」と「大阪駅」を選択できるようにしてください。

  2. 東京駅が選ばれたら 緯度 35.6812, 経度 139.7671、大阪駅が選ばれたら 緯度 34.7024, 経度 135.4959 を中心にした folium の地図を描画し、画面に表示してください。

  3. 地図上には、その場所に赤いピンを1つ立ててください。

  4. コピペするだけで動く、1つの Python コードにしてください。

❓ よくある質問と回答 (FAQ)¶

  • Q. AIが全部コードを書いてくれるなら、私たちはもうプログラミングの勉強をしなくていいのでは？

    • A. いいえ、実は逆です！ AIが吐き出したコードの中に「致命的な計算ミス」や「データの解釈間違い（バグ）」があったとき、プログラミングの基礎知識（変数、リスト、Pandasの仕組み、決定係数の意味など）がない人は、そのバグにすら気づけず、間違ったデータ分析結果を世の中に垂れ流してしまいます。

    • 「1文字ずつ手で書く」必要はなくなりましたが、**「AIが書いたコードの中身を読み解き、正しさを保証（レビュー）する力」**を持つために、私たちがこの全13回で学んできた「プログラミング基礎」と「応用」の知識が、絶対に不可欠なのです。
