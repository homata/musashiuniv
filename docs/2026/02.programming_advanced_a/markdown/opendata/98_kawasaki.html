3. オープンデータ関連一覧 (by オープン川崎)¶

主に公的機関の情報やオープンデータのサイトのリンク集です。 このリンク集に無いデータで、他に欲しいデータがあれば問い合せください。

また、他にオススメのサイトがあればお知らせください。

3.3. 日本¶

日本の国や公的機関が出しているデータ

  • RESAS（地域経済分析システム）

    • 産業構造や人口動態、人の流れなどを視覚化した地域経済分析システム

  • 政府統計の総合窓口(e-stat)

    • 日本の統計が閲覧できる政府統計ポータルサイト

  • 統計ダッシュボード

    • e-statの代表的なデータをダッシュボード化したもの

  • Data.go.jp データカタログサイト

    • 国のオープンデータのデータカタログサイト

  • 政府CIOポータル

    • 内閣官房 情報通信技術（IT）総合戦略室が公開しているオープンデータサイト

  • ITダッシュボード

    • 政府のIT投資等の状況を誰でも確認できるサイト

  • IMI 共通語彙基盤

    • データに用いる文字や用語を共通化し、情報の共有や活用を円滑に行うための基盤の情報サイト

  • 地方公共団体のオープンデータの推進

    • 総務省の地方公共団体のオープンデータの推進サイト

  • オープンデータ研修ポータル

    • 総務省のオープンデータ研修ポータルサイト

  • 気象庁

    • 最新の気象データ

      • 気象観測データ

  • 国土数値情報ダウンロードサービス(

    • 国土に関する基礎的な情報をGISデータとして整備したデータ

  • 農業データ連携基盤（WAGRI）

    • 気象や土地、地図情報等に関するAPI

  • 内閣府の今週の指標
