第9回 地理空間データの活用2：leafmap / folium による動的ウェブ地図構築（講義100分版）¶

皆さん、こんにちは！プログラミング応用A（コンピューティング応用G）、第9回の講義です。担当の教員です。

これまで2回にわたり、地理空間情報（GIS）の理論から座標系（EPSG）の変換、バッファ演算、そして物理的な重なりでマージする「空間結合（gpd.sjoin）」といった高度なデータ加工を学んできました。 今回はそのGISシリーズの集大成として、**「Webブラウザ上で拡大・縮小・ドラッグしてグリグリ動かせ、クリックすると店舗情報がポップアップする、超かっこいい『動的インタラクティブマップ』」**を自分の手で完成させます！

これまでは、描画した地図をMatplotlibを使って「静止画（画像ファイル）」として画面に出力していました。しかし、現代のビジネスの現場や防災・シビックテックの現場では、静止画では使い物になりません。「地図をズームして道路網を確認したい」「ピンをクリックして店舗の売上や避難所の備蓄数を確認したい」というニーズが当たり前だからです。

今日は、Pythonの最新・最強の動的地図ライブラリである folium（フォリウム） や leafmap（リーフマップ） を使用します。 難解なHTML、CSS、JavaScript（Leaflet.js）の知識は一切不要です。Pythonのコードをわずか3〜4行記述するだけで、あなたの画面にGoogle Mapsと全く同じ「動くデジタルツイン」が誕生します。

今日綺麗に前処理されたデータに「動く命」を吹き込む感動を、ぜひ100分間の大講義で体験してください！それでは、エキサイティングな動的地図の世界へ出発しましょう！

🎯 本日の到達目標¶

  1. 静的マップ（Matplotlib）と動的マップ（folium/leafmap）の決定的な違いを理解し、実務における用途の使い分けを説明できる。

  2. PythonからWeb標準地図ライブラリ（Leaflet.js）へ自動コンパイル（変換）される仕組みを直感的に理解する。

  3. folium / leafmap の基本オブジェクトを定義し、目的の緯度経度を中心とするインタラクティブ地図を表示できる。

  4. **for ループ（iterrows()）**を駆使し、Pandasのデータフレームから数百店舗や避難所を地図上に「全自動マッピング」するコードを記述できる。

  5. HTMLを組み込んだオシャレなポップアップを実装し、店舗名・客数・画像リンクなどをクリック時に表示するUIを設計できる。

  6. **階級区分図（コーロプレス図）**のデータ連結ロジック（GeoJSONポリゴン ✕ Pandas数値）を解読し、Streamlitダッシュボードへ動的マップを埋め込む手法を説明できる。

9.1 動的地図の革命：folium と leafmap の仕組み（約25分）¶

9.1.1 なぜPythonだけでGoogle Mapsのような動く地図が作れるのか？¶

皆さんが普段ブラウザで閲覧している「Google Maps」や「Yahoo!地図」は、裏側で HTML（画面の骨組み）、CSS（デザイン）、そして JavaScript（JS） というプログラミング言語が複雑に連携して動いています。特に、地図をヌルヌルとドラッグしたりダブルクリックでズームしたりする動きは、JavaScriptの地図描画ライブラリ（世界標準である Leaflet.js や Mapbox）が制御しています。

文系初学者がこれらを1から学ぼうとすると、「Webサイト制作の知識」と「Pythonの知識」のダブルパンチでほぼ確実に挫折してしまいます。

そこで開発されたのが、本日使用する folium（フォリウム） です。 foliumは、いわば**「超優秀な自動翻訳機（コンパイラー）」です。 あなたが数行のPythonコードを書くと、foliumが裏側でその意図を読み取り、数千行の「HTML + CSS + JavaScript（Leaflet.js）」コードを一瞬で自動生成（出力）**してくれます。

このおかげで、私たちはWeb制作の難しいお勉強を完全にパスして、「データから面白い価値を見つけ出すこと」だけに100%集中できるようになりました。

9.1.2 folium と leafmap：どちらを使うべき？¶

本講義では、実務のGISプロジェクトで双璧をなす2つの動的ライブラリを扱います。それぞれのキャラクターを整理しておきましょう。

  [ 🗺️ 動的地図ライブラリの双璧 ]
   ├── ① folium (老舗・安定・シンプル) ────▶ 日本語の情報が最も多く、マーカーを数件立てるような
   │                                          防災マップ・店舗マップの基本に最適。
   │
   └── ② leafmap (次世代・多機能・爆速) ──▶ データフレームとの親和性が極めて高く、数万行のデータや
                                              人工衛星画像、Streamlitアプリへの埋め込みに最強。

  • folium は、2010年代から愛されている大ベストセラーライブラリです。シンプルなピン立てやサークル描画、エリアの塗り分けに強く、エラーが起きた際もネットで調べれば1秒で解決策が見つかる「絶対的な安心感」があります。

  • leafmap は、2020年代に開発された新鋭ライブラリです。実は内部で folium や ipyleaflet という別の地図エンジンを使い分けて動いています。Pandasのデータフレームから一撃でピンを立てる関数（add_gdf や add_points_from_xy）を持っており、**「コードの記述量がfoliumの半分以下で済む」**という特徴があります。

本日はまず、動的マッピングの論理的構造が一番よく理解できる「王道」の folium から学んでいきましょう！

9.2 ピン（Marker）の全自動配置とポップアップデザイン（約30分）¶

9.2.1 動的地図を表示する「最小のコード」¶

まずは、私たちのキャンパスである「武蔵大学（江古田）」を中心にした動的地図を1枚、表示させてみましょう。 必要なのは、中心位置に指定する 「[緯度, 経度]」 のリストと、初期の拡大率（zoom_start）だけです。

# （準備）動的マップ用のライブラリをインポート
import folium

# location に [緯度, 経度]、zoom_start に 1〜20（数値が大きいほど拡大）を指定します。
my_map = folium.Map(location=[35.7368, 139.6705], zoom_start=16)

# 2. 地図を表示（Colab上では、オブジェクトが格納された変数名を書くだけ！）
my_map

セルを実行した瞬間、Colabの実行結果エリアにGoogle Mapsと同じような「世界と繋がった動く地図」が現れます！ マウスで掴んでドラッグしたり、ホイールで日本中、世界中へズームアウトしてみてください。これが動的地図のパワーです。

9.2.2 複数店舗をforループで「一撃全自動マッピング」する¶

実務では、登録されている店舗や避難所は1件や2件ではありません。何百、何千という店舗の緯度経度を、1行ずつ手作業で folium.Marker と書いていたら日が暮れてしまいます。

そこで、第3回・第4回で学んだ Pandasのループ処理 for idx, row in df.iterrows(): と合体させます！ データフレームに登録されている全行を自動で走査し、それぞれの行にある「緯度」「経度」「店舗名」を抜き出して、地図オブジェクトに次々とピンを突き刺していくプロの技術を実装しましょう。

【全自動ループマッピングの処理構造】

  [ 📋 Pandasデータフレーム ]
   ├── 0行目: 江古田店 [35.737, 139.671] ──(ループ1)──▶ folium.Marker([35.737, 139.671]).add_to(map)
   ├── 1行目: 桜台店   [35.738, 139.663] ──(ループ2)──▶ folium.Marker([35.738, 139.663]).add_to(map)
   └── 2行目: 練馬店   [35.735, 139.654] ──(ループ3)──▶ folium.Marker([35.735, 139.654]).add_to(map)

実際に、以下のコードを実行して「複数店舗の自動プロット」を体感してください。

import pandas as pd
import folium

# 1. 3つの店舗を表すデータフレームを作成（実務ではCSVやオープンデータになります）
df_shops = pd.DataFrame({
    \"店舗名\": [\"江古田店\", \"桜台店\", \"練馬店\"],
    \"緯度\": [35.7370, 35.7380, 35.7350],
    \"経度\": [139.6710, 139.6630, 139.6540],
    \"店舗タイプ\": [\"本店\", \"支店\", \"支店\"],
    \"1日平均売上\": [150000, 80000, 95000]
})

# 2. 練馬区周辺を中心に据えたベースマップを生成
map_nerima = folium.Map(location=[35.736, 139.663], zoom_start=14)

# 3. iterrows() で1行ずつ店舗データを取り出してループ処理
for index, row in df_shops.iterrows():
    # 緯度・経度を row から抽出
    lat = row[\"緯度\"]
    lng = row[\"経度\"]
    name = row[\"店舗名\"]
    sales = row[\"1日平均売上\"]
    
    # 💡 応用：本店なら「赤色」、支店なら「青色」にピンの色を自動で分ける！
    if row[\"店舗タイプ\"] == \"本店\":
        color_choice = \"red\"
    else:
        color_choice = \"blue\"
    
    # ピンを生成して地図（map_nerima）に追加
    folium.Marker(
        location=[lat, lng],
        popup=f\"{name} (日次売上: {sales:,}円)\",
        icon=folium.Icon(color=color_choice, icon=\"shopping-cart\", prefix=\"fa\")
    ).add_to(map_nerima)

# 地図を表示
map_nerima

見事に、店舗タイプに応じて自動でピンの色が塗り分けられ、アイコンが可愛い「ショッピングカート」になった地図が表示されたはずです。

9.2.3 ポップアップをオシャレにする：HTMLタグの埋め込み¶

通常、ピンをクリックした時に出る吹き出し（popup）には単なる「テキスト（文字）」を渡しますが、実はfoliumの popup の中身は HTMLコードがそのまま動作します。 つまり、改行（<br>）や太字（<b>）、文字色の変更、さらには「写真（<img>）」や「ホームページへのリンク（<a>）」まで自由にレイアウトできるのです。

# HTMLタグを使った豪華なポップアップの作成例
html_content = \"\"\"
<div style="font-family: 'Hiragino Kaku Gothic Pro', sans-serif; width: 200px;">
    <h4 style="color: #2e7d32; margin-bottom: 5px;">☕ 江古田の森カフェ</h4>
    <p style="margin: 0; font-size: 12px; color: #555;"><b>おすすめ:</b> 有機栽培コーヒー</p>
    <p style="margin: 0; font-size: 12px; color: #555;"><b>平均予算:</b> 600円〜</p>
    <hr style="margin: 8px 0; border: 0; border-top: 1px solid #ccc;">
    <a href="https://www.musashi.ac.jp" target="_blank" style="font-size: 11px; color: #1565c0; text-decoration: none;">👉 公式サイトを見る</a>
</div>
\"\"\"

# 地図を作成
map_html = folium.Map(location=[35.737, 139.671], zoom_start=16)

# HTMLをfoliumが読み込めるようにラップ（包む）してマーカーに追加
folium.Marker(
    location=[35.737, 139.671],
    popup=folium.Popup(html_content, max_width=250), # max_widthで吹き出しの最大幅を指定
    icon=folium.Icon(color=\"green\", icon=\"leaf\", prefix=\"fa\")
).add_to(map_html)

map_html

ピンをクリックした際、まるで本物のグルメアプリのようなリッチで美しい吹き出しが表示されたでしょうか？ これだけで、あなたの作る地図アプリの品質がプロレベルに跳ね上がります。

9.3 階級区分図（コーロプレス図）と動的ダッシュボード連携（約25分）¶

9.3.1 階級区分図（コーロプレス図）のデータ構造¶

エリアマーケティングや行政のデータポータルで最も多用されるのが、地域ごとの数値データの大きさを「塗りつぶしの色の濃淡」で表す**階級区分図（コーロプレス図）**です。

これをプログラムで実現するためには、以下の全く異なる2つのデータをメモリ上で寸分の狂いもなく合致させる必要があります。

  1. 地図の形データ（境界ポリゴン：GeoJSONやShapefile）

    • 市区町村などの「境界線（多角形）」を定義したデータ。

    • 内部には、それぞれの区画を特定するための「区コード」や「区名」というキー情報が含まれています。

  2. 統計数値データ（売上や人口：PandasのDataFrame）

    • 「練馬区：売上200万円」「杉並区：売上150万円」のように、エリア名と数値が記録された通常の表。

【データ結合（key_on）の仕組み】

  [ 🗺️ GeoJSON側：地図データ ]               [ 📊 Pandas側：売上表 ]
  "features": [                              df_sales =
    { "properties": { "name": "練馬区" } }  ──▶  "区名": ["練馬区", "杉並区", "豊島区"]
                                 │               "売上": [ 250,    180,    300 ]
                                 ▼
                     🔑 紐付けるキーが完全一致！
                       (これを key_on で指定)

foliumでこれを描画する際は、folium.Choropleth オブジェクトを使用します。 最大のコツは、GeoJSONデータ内のどこにキー（「区名」など）があるかを示す key_on という引数の書き方です。 JSONは階層構造（辞書の入れ子）になっているため、key_on="feature.properties.name" のように「点（ドット）」で階層を辿ってキーを指定します。

# 階級区分図の記述イメージ（授業用解説コード）
import folium

# m_choropleth = folium.Map(location=[35.73, 139.70], zoom_start=12)

# folium.Choropleth(
#     geo_data=tokyo_geojson,          # 1. 境界線ポリゴンデータ
#     data=df_sales_by_district,       # 2. Pandasの数値データ
#     columns=["区名", "総売上金額"],    # 3. Pandas側の [キーの列名, 色にする数値の列名]
#     key_on="feature.properties.name",# 4. GeoJSON側のキー（propertiesの中のnameキー）
#     fill_color="YlOrRd",             # 5. グラデーション色（黄〜橙〜赤：Yellow Orange Red）
#     fill_opacity=0.7,                # 6. 塗りつぶしの不透明度（0.0〜1.0）
#     line_opacity=0.2,                # 7. 境界線の不透明度

練習問題 4: 階級区分図の key_on 引数の役割¶

👉 練習問題 4 の解答と解説を見る

🛠️ 【教員用：採点基準・減点ガイド】¶

  • 満点 (10点): if-elif-else の3つの境界線（0.8, 0.5）が正しく判定され、江古田（赤）、千川（オレンジ）、小竹（緑）、羽沢（赤）と正確に色分けプロットされており、ポップアップに％計算された混雑度が美しく表示されている。

  • 減点3点: 条件式の境界判定ミス（例：rate >= 80 のように、元の数値が0.8という小数であることを見落とし、全員が緑色の安全扱いになってしまっている）。

  • 減点2点: ポップアップ内の文字列フォーマットの記述ミスによるエラー、またはマーカー追加メソッド add_to の書き忘れ。

import pandas as pd
import folium

df_evac = pd.DataFrame({
    "避難所名": ["江古田体育館", "千川小学校", "小竹図書館", "羽沢集会所"],
    "緯度": [35.7380, 35.7420, 35.7440, 35.7350],
    "経度": [139.6710, 139.6880, 139.6760, 139.6800],
    "Congestion_Rate": [0.85, 0.62, 0.30, 0.95]
})

map_realtime_bousai = folium.Map(location=[35.739, 139.678], zoom_start=14)

for index, row in df_evac.iterrows():
    rate = row["Congestion_Rate"]
    percent = int(rate * 100) # パーセント表示に変換
    
    # 混雑度による色分け判定
    if rate >= 0.8:
        color_choice = "red"
        icon_choice = "exclamation-triangle"
    elif rate >= 0.5:
        color_choice = "orange"
        icon_choice = "info-sign"
    else:
        color_choice = "green"
        icon_choice = "ok-sign"
        
    folium.Marker(
        location=[row["緯度"], row["経度"]],
        popup=f"{row['避難所名']} (混雑率: {percent}%)",
        icon=folium.Icon(color=color_choice, icon=icon_choice)
    ).add_to(map_realtime_bousai)
