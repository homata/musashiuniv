第5回 Webサービスの活用1：StreamlitによるWebアプリ開発の基礎¶

皆さん、こんにちは！プログラミング応用A、第5回の講義です。担当の教員です。 前回（第4回）は、Pandasを使って「平均値の罠」を見破り、データのばらつき（標準偏差）や関係性の強さ（相関係数）を可視化する「データ解析」の基本を学びました。

今回からは、データ分析をさらに一歩進めて、**「Webサービスの活用」**という新しい領域に突入します！ 具体的には、Pythonだけで本格的なWebアプリケーションを構築できる魔法のライブラリ Streamlit（ストリームリット） を使って、あなた専用の「データダッシュボード」を作っていきます。

「HTMLやCSSは難しそう…」「Webサーバーって何？」と思うかもしれませんが、大丈夫です！ Streamlitを使えば、そうした難しいデザインのコードは一切書く必要がありません。Pythonのコードを数行書くだけで、オシャレなボタンやスライダー、グラフが画面に自動的に配置されます。

今日は、Google Colab上でWebアプリを起動するための特別な手順（トンネリング）から、基本的なボタンや入力欄（ウィジェット）の配置方法まで、丁寧に学んでいきます。自分で作ったプログラムがWebブラウザ上で「アプリ」として動く感動を、ぜひ味わってください！

🎯 到達目標 (約5分)¶

この授業が終わるころには、以下のことができるようになります。

  1. Webアプリ化（ダッシュボード化）の目的と意義（なぜデータをアプリとして公開するのか）を説明できる。

  2. Google Colab上でStreamlitを安全に起動し、ローカルトンネル（localtunnel）を使ってスマホやブラウザからアクセスできる。

  3. Streamlitの基本コマンド（タイトル、テキスト出力、マークダウン）を使い分けてWeb画面を構成できる。

  4. 入力用ウィジェット（ボタン、スライダー、テキスト入力、セレクトボックス）を配置し、ユーザーの操作に応じて画面が変わるインタラクティブ（対話型）なアプリが作れる。

5.1 なぜデータを「アプリ」にするのか？ (約15分)¶

データ分析を「社会に届ける」最後のステップ¶

これまでの授業で、私たちはデータを収集し、Pandasで集計し、Matplotlibでグラフを描くことができるようになりました。 しかし、その分析結果を「プログラミングを知らない会社の上司や、一般のお客様」に見せたいとき、どうしますか？

  • 「Pythonのコードと、グラフの画像ファイルをメールで送ります」 ➡ 相手はPythonを実行できませんし、画像は「静止画」なので、自分の見たい部分（例：特定の店舗だけ、特定の日付だけ）を拡大したり絞り込んだりできません。

  • 「Excelファイルを共有します」 ➡ 相手が関数を壊してしまったり、スマートフォンからだと操作しづらかったりします。

一番良い解決策は、**「誰でもスマホやパソコンのブラウザからアクセスして、ボタン一つでデータを絞り込める『Webアプリ』にして渡すこと」です。これを「データダッシュボード」**と呼びます。

【ダッシュボード開発の今と昔（イメージ図）】

▼ 昔の開発方法（学習コスト：極大 😱）
  Python(分析) ＋ HTML/CSS(画面デザイン) ＋ JavaScript(動き) ＋ サーバー構築
  ➡ 覚えることが多すぎて、文系学生やデータ分析者は挫折してしまいます。

▼ Streamlitを使った開発（学習コスト：極小 😍）
  [ 🐍 Pythonコード数行 ] ──▶  [ 🎨 Streamlitが自動変換 ] ──▶ [ 💻 プロ級のWebアプリ ]
  ➡ HTMLもサーバーの知識も不要！分析コードがそのまま綺麗なアプリに生まれ変わります。

5.2 Google Colab上でStreamlitを動かす魔法（環境構築） (約25分)¶

通常、Streamlitは自分のパソコン（ローカル環境）の黒い画面（ターミナル）で起動します。 しかし、この授業では誰もが同じ環境で学べるよう Google Colab を使っています。Colabは「Googleのクラウド上にあるパソコン」なので、そこで動かしたWebアプリを、手元のパソコンやスマホのブラウザで見るためには、**一時的な通り道（トンネル）**を作ってあげる必要があります。

このトンネリングツールとして localtunnel（ローカルトンネル） という無料の仕組みを使います。 まずは、Colabのセルに以下の「おまじない」を貼り付けて、環境を構築しましょう！

# ------------------------------------------------------------------
# ステップ 1: 必要なライブラリのインストール（Colabのセルで実行してください）
# ------------------------------------------------------------------
!pip install -q streamlit
!npm install -g localtunnel

【超重要】ColabでStreamlitを起動する「3つの手順」¶

Colab上でアプリを開発する時は、以下のセットを常に使います。

手順A: アプリのソースコードを書き出す（%%writefile）¶

セルの1行目に %%writefile app.py と書くと、そのセルの中身がそのまま app.py という名前のPythonファイルとしてColabの中に保存されます。

%%writefile app.py
# ここにStreamlitのコードを書きます
import streamlit as st

st.title("Musashi Cafe アプリ ☕")
st.write("プログラミング応用Aの授業で作成したWebアプリです！")

手順B: トンネルの鍵（あなたのIPアドレス）を確認する¶

localtunnelを使って外部からアプリにアクセスする際、セキュリティ確認のために「Colabの仮想パソコンのIPアドレス（4つの数字）」を求められます。以下のコマンドを実行して、出てきた数字をメモ（コピー）しておきましょう。

# あなたのColab環境のIPアドレスを表示します（パスワードのようなものです）
!wget -qO- ipv4.icanhazip.com

手順C: アプリをバックグラウンドで起動し、トンネルを開通する！¶

以下のコマンドを実行すると、Streamlitが裏側（バックグラウンド）で起動し、localtunnelが世界中からアクセスできる一時的なURLを発行してくれます。

# Streamlitを裏で起動
!streamlit run app.py &>/dev/null &

# ポート8501番（Streamlitの標準ポート）を外部に公開する
!npx localtunnel --port 8501

  • 使い方:

    1. 上のセルを実行すると、url: https://xxxx.loca.lt というリンクが表示されます。

    2. そのリンクをクリックすると、「Tunnel Password」という入力画面が開きます。

    3. そこに 手順Bで確認したIPアドレス（例：34.125.12.34） を貼り付けて「Submit」ボタンを押します。

    4. 画面が切り替わり、あなたが作った「Musashi Cafe アプリ」が表示されます！

5.3 Streamlitの基本操作とウィジェット (約25分)¶

無事にアプリが起動したら、今度はアプリの中身を豪華にしていきましょう！ Streamlitは、ユーザーがボタンを押したりスライダーを動かしたりするたびに、**「コードが上から下まで自動的に再実行され、画面が即座に書き換わる」**という超画期的な仕組み（リアクティブ・フレームワーク）を持っています。

代表的なコマンドとウィジェット（入力部品）を体験してみましょう。

%%writefile app.py
import streamlit as st

# ==========================================
# 1. テキスト・見出しの表示
# ==========================================
st.title("カフェ自動レジアプリ ☕")
st.header("お会計シミュレーター")
st.write("商品の選択と数量を入力すると、自動でお会計を計算します。")

# ==========================================
# 2. セレクトボックス（ドロップダウンメニュー）
# ==========================================
# st.selectbox("案内メッセージ", 選択肢のリスト)
# ユーザーが選んだ値が、そのまま変数 selected_item に入ります！
selected_item = st.selectbox(
    "ご注文の商品を選んでください:",
    ["コーヒー (450円)", "紅茶 (400円)", "チョコレートケーキ (550円)"]
)

# 商品名と価格の切り分け処理
if "コーヒー" in selected_item:
    price = 450
elif "紅茶" in selected_item:
    price = 400
else:
    price = 550

# ==========================================
# 3. スライダー（数値の調整）
# ==========================================
# st.slider("案内メッセージ", 最小値, 最大値, 初期値)
quantity = st.slider("数量を選んでください:", 1, 10, 1)

# ==========================================
# 4. ボタン（実行のトリガー）
# ==========================================
# st.button("ボタンの文字") は、ボタンが押された瞬間だけ True になります！
if st.button("お会計を計算する"):
    total = price * quantity
    st.success(f"計算が完了しました！") # 緑色の綺麗なボックスで表示します
    st.write(f"ご注文: {selected_item} × {quantity}個")
    st.metric(label="合計金額 (税込)", value=f"{total} 円") # プロっぽい数値インジケータ

💡 開発を10倍楽にする「常時リロード（Always Rerun）」¶

  1. localtunnelで開いたWebアプリ画面の右上に「︙（設定メニュー）」があります。

  2. そこをクリックし、**「Settings」➡「Run on save」**にチェックを入れます。

  3. これにより、Colab側で app.py のセルを実行（ファイルを上書き保存）するだけで、ブラウザのタブを手動でリロードしなくても、Webアプリ画面が自動で一瞬で最新に更新されるようになります。非常に快適に開発ができるので、ぜひ設定しましょう！

📚 第5回のまとめ¶

お疲れ様でした！今日は、PythonでWebアプリを構築する世界最強のツール「Streamlit」の基礎を学びました。

✨ 今日の重要ポイントまとめ¶

  • Streamlit: HTMLやサーバー構築の知識がゼロでも、Pythonだけで美しいWebアプリを作れるライブラリ。

  • localtunnel: Colabのクラウド環境で動くアプリを、手元のブラウザから安全に閲覧可能にするための「トンネル（通り道）」。

  • リアクティブ処理: スライダーやボタンを操作するたびに、Streamlitはコードを上から下まで瞬時に再実行して、画面を常に最新に書き換える。

  • 入力ウィジェット: st.selectbox (ドロップダウン)、st.slider (スライドバー)、st.checkbox (二択) などの戻り値をそのままPythonの変数に代入して条件分岐に使える。

❓ よくある質問と回答 (FAQ)¶

  • Q. localtunnelのURLを開いたら「Friendly Reminder...」という青い警告画面が出て、アプリが表示されません。

    • A. 大丈夫です、それはlocaltunnelの仕様です。画面中央にある 「Click to Submit」 または 「Visit Site」 というボタンをクリックすれば、作成したアプリ画面に問題なく進むことができます。

  • Q. コードを書き換えてセルを実行したのに、Webアプリ側の画面が変わりません。

    • A. アプリ画面の右上にある「︙」メニューから、**「Always Rerun（常時リロード）」**が有効になっているか確認してください。もし無効になっている場合は、手動でWebブラウザの再読み込みボタン（F5キーなど）を押すか、Colab側で Streamlit の起動セルを再度実行し直してみてください。

  • Q. localtunnelへのアクセス時に「Tunnel xxxx not found」やエラーが出ます。

    • A. Google Colabのネットワーク状況により、時折トンネル接続が切断されることがあります。その場合は、Colabの実行セルの停止（■）ボタンを押し、!streamlit run app.py & から始まる起動セルをもう一度実行して、新しいURLを発行してみてください。

🌟 Colabで試すおすすめコード（次回のワクワクの扉）¶

今日学んだ Streamlit は、実は Pandasの表データや、Matplotlib/Seabornのグラフを画面に一発で表示する機能 も持っています！ 以下のコードを Colab に貼り付け、Webアプリの画面がどう進化するか覗いてみましょう。

%%writefile app.py
import streamlit as st
import pandas as pd
import numpy as np
import matplotlib.pyplot as plt

st.title("📊 カフェ売上ダッシュボード 📊")

# 模擬データ（1週間分の売上）
data = pd.DataFrame({
    "曜日": ["月", "火", "水", "木", "金", "土", "日"],
    "売上額 (千円)": [45, 52, 48, 60, 75, 110, 120]
})

# 1. データの表をそのままアプリ上に表示！
st.subheader("曜日別売上表")
st.dataframe(data) # インタラクティブなスプレッドシートとして表示されます

# 2. グラフをアプリ上にプロット！
st.subheader("売上推移グラフ")
fig, ax = plt.subplots()
ax.bar(data["曜日"], data["売上額 (千円)"], color="skyblue")
st.pyplot(fig) # 描画した matplotlib のグラフを一発でWeb画面に埋め込み！
