4.1 平均値の罠と記述統計の基本 (約20分)¶

データを分析する際、最初にデータの全体像（代表値とばらつき）を把握します。これを**記述統計（Descriptive Statistics）**と呼びます。

① 代表値（平均値、中央値、最頻値）の使い分け¶

  • 平均値 (Mean)：すべてのデータの合計を件数で割ったもの。最も一般的ですが、「極端な値（外れ値）」にめちゃくちゃ引っ張られるという最大の弱点があります。

  • 中央値 (Median)：データを順番に並べたときに、ちょうど真ん中にくる値。外れ値の影響を受けません。

  • 最頻値 (Mode)：データの中で最も多く登場する値（人気投票の1位のようなもの）。アンケートの回答などに使います。

【大富豪来店！平均値の罠（イメージ）】

  [ カフェのお客さん5人の所持金 ]
   佐藤さん: 3000円  │
   鈴木さん: 5000円  │  この4人の「平均所持金」は、約 4,750円。 (納得のいく数字)
   田中さん: 6000円  │
   高橋さん: 5000円  │
      ＋
   💰【大富豪】ビル・ゲイツ氏：1兆円！
  
  [ 5人集まった結果 ]
   平均所持金 ──▶  約 2000億円！ (「このカフェの平均顧客はみんな超大金持ち！」となってしまい、現実と激しく乖離する)
   中央値     ──▶  5000円！ (ちょうど真ん中の佐藤・高橋さんの金額。これが現実の実態を正しく示している)


<!-- コードセル -->
import pandas as pd
import numpy as np

# カフェのお客さんの滞在時間（分）のデータ
# 4人は普通にゆっくりしていますが、1人だけ「朝から夕方まで居座った人（480分）」が混ざっています（外れ値）。
stay_times = [30, 45, 60, 40, 480]

df_stay = pd.DataFrame(stay_times, columns=["滞在時間"])

# 平均値と中央値を計算して比較してみましょう！
print("平均値 (Mean):", df_stay["滞在時間"].mean(), "分")
print("中央値 (Median):", df_stay["滞在時間"].median(), "分")

# 平均だと「1人あたり131分」となり、みんな2時間以上いるように見えますが、
# 中央値の「45分」の方が、大部分のお客さんの実感値（代表値）に近いですね！

② データの「ばらつき」を表す「標準偏差（Standard Deviation）」¶

「平均滞在時間は45分です」と言われても、「全員が40〜50分の間に収まっている」のか、「5分で帰る人と90分いる人が半分ずつ」なのか分かりません。 この**「データのばらつき（散らばり具合）」を数値化したものが、標準偏差（Std）**です。

  • 標準偏差が小さい ➡ みんな平均値の近くに集まっている（安定している）。

  • 標準偏差が大きい ➡ データがバラバラに散らばっている。

4.2 クロス集計とピボットテーブル (約15分)¶

データの中に複数のカテゴリがある場合、それらを掛け合わせて集計すると「意外な組み合わせ」が見えてきます。これをクロス集計と呼びます。 Pandasでは、エクセルの機能でおなじみの ピボットテーブル（pivot_table） が使えます。

【ピボットテーブルのイメージ】

  [ 生データ ] ──▶ [ ピボットテーブル集計 ] ──▶ [ 二次元のクロス表 ]
  顧客区分, 注文商品                              
  学生,   コーヒー                                     学生    社会人
  一般,   ケーキ                               コーヒー  12杯     5杯
  学生,   コーヒー                               ケーキ    2個    15個
  一般,   コーヒー                               (学生はコーヒー、社会人はケーキを好むと一目でわかる)


<!-- コードセル -->
# カフェの顧客タイプ別の売上履歴データ
df_cafe_sales = pd.DataFrame([
    ["学生", "コーヒー", 450],
    ["一般", "コーヒー", 450],
    ["学生", "ケーキ", 500],
    ["一般", "ケーキ", 500],
    ["学生", "コーヒー", 450],
    ["一般", "ケーキ", 500],
    ["一般", "ケーキ", 500],
], columns=["顧客区分", "商品名", "売上"])

# ピボットテーブルを使って「顧客区分」を横（列）に、「商品名」を縦（行）にして、売上の「個数（count）」を集計します！
df_pivot = df_cafe_sales.pivot_table(
    values="売上",            # 集計したい数値の列
    index="商品名",           # 縦軸（行）に置く項目
    columns="顧客区分",       # 横軸（列）に置く項目
    aggfunc="count"           # 集計方法（今回はデータの個数を数える count。合計なら sum、平均なら mean）
)

print("▼ クロス集計（ピボットテーブル）の結果")
display(df_pivot)

4.3 相関分析：データ同士の関係性を数値化する (約15分)¶

データ分析の最もエキサイティングな瞬間、それは「2つのデータがどう関係しているか（相関）」を見つけるときです。

① 相関係数（Correlation Coefficient: \(r\)）¶

2つのデータの関係性を -1.0 〜 +1.0 の間の数字で表したものです。

  • 正の相関（0 から 1.0）：一方が増えると、もう一方も増える関係。

    • 例：気温が高くなると、アイスコーヒーの売上が増える（相関係数は +0.8 など強い正の相関）。

  • 負の相関（-1.0 から 0）：一方が増えると、もう一方は減る関係。

    • 例：気温が高くなると、ホットコーヒーの売上が減る（相関係数は -0.7 など強い負の相関）。

  • 無相関（0付近）：お互いに関係がない。

    • 例：店長の体重と、コーヒーの売上（相関係数は 0.05 など、無関係）。

【相関係数（\(r\)）の基準値】

  • 0.7 〜 1.0（または -0.7 〜 -1.0）：強い相関がある。信頼できる強い関係。

  • 0.4 〜 0.7（または -0.4 〜 -0.7）：中程度の相関がある。

  • 0.0 〜 0.2：ほとんど相関がない。


<!-- コードセル -->
# 「その日の最高気温」と「冷たい飲み物の売上数」「温かい飲み物の売上数」のデータ
df_weather_sales = pd.DataFrame([
    [15, 10, 80],
    [20, 25, 60],
    [25, 45, 40],
    [30, 70, 20],
    [35, 95, 5]
], columns=["最高気温", "冷たい飲料", "温かい飲料"])

# 相関行列（すべてのペアの相関係数を一瞬で計算する .corr()）
correlation_matrix = df_weather_sales.corr()

print("▼ 相関行列（自分自身との相関は 1.0 になります）")
display(correlation_matrix)

# 気温と冷たい飲料の相関係数は「0.99」➡ ほぼ完璧な「強い正の相関」
# 気温と温かい飲料の相関係数は「-0.99」➡ ほぼ完璧な「強い負の相関」であることがわかります！

🚨 注意！「相関関係」と「因果関係」は違う！¶

データ分析者が一生忘れてはならない超重要な鉄則があります。 「相関関係があるからといって、原因と結果（因果関係）があるとは限らない」

  • 有名な例：「交番の数が多い地域ほど、犯罪発生数が多い」というデータがあります。

    • これを「交番を建てたから、おまわりさんが犯罪を増やしたんだ！交番を壊そう！」と判断するのは間違いですよね。

    • 実際には「人口が非常に多い大都市だから、交番も多く、必然的に犯罪も多い」という**「人口」という隠れた原因（交絡因子）**が裏に潜んでいるだけです。

データ分析の数字を見る際は、常に「本当にこれが原因なのか？」を論理的に疑う癖をつけましょう。

お疲れ様でした！今日は、ただのデータ加工から、データの裏に眠るストーリー（真実）を暴き出す「データ解析」の基礎を学びました。

✨ 今日の重要ポイントまとめ¶

  • 記述統計: 平均値は外れ値（大富豪）に弱いため、実態を正しく掴むには中央値も併せて確認する。データのばらつきは標準偏差で測る。

  • クロス集計 (crosstab / pivot_table): カテゴリ同士を掛け合わせる（例：性別×好み）ことで、特定の層に人気のある商品や、店舗ごとの得意・不得意の傾向をあぶり出せる。

  • 相関分析 (.corr): 2つのデータの一方が増えればもう一方も増える（正の相関）、あるいは減る（負の相関）という関係を -1.0 〜 +1.0 の数値で表す。

  • 相関 vs 因果の鉄則: 「相関があるからといって、因果関係（原因と結果）があるとは限らない」を常に意識する。

❓ よくある質問と回答 (FAQ)¶

  • Q. 相関係数が「0.3」でした。これは関係がないということですか？

    • A. 統計学的には「非常に弱い相関（あるいはほとんど無相関）」と判断されることが多いです。ただし、「本当は2つのデータに関係があるのに、データ件数が少なすぎるために、たまたま低い相関係数になってしまっている（サンプルサイズの問題）」ということもあります。分析をする際は、データ件数（サンプル数）が十分に足りているかも意識しましょう。

  • Q. df.corr() を実行したらエラー（ValueError: could not convert string to float）が出ました。

    • A. 相関係数は「数値データ」同士でしか計算できません。データフレームの中に「店舗名」や「日付」などの文字列（テキスト）の列が含まれていませんか？最新のPandasでは、自動的に数値列だけを選んで計算してくれますが、古いバージョンではエラーになるため、df[["客数", "総売上"]].corr() のように、あらかじめ数値列だけを絞り込んでから .corr() を呼ぶとエラーを確実に回避できます。

ピボットテーブルと並ぶPandasの超強力なクロス集計メソッド pd.crosstab に normalize="index" を指定することで、人数ではなく「割合（％）」で男女の好みの差を一撃で比較するプロのテクニックです。


<!-- コードセル -->
# 100人のお客様のアンケート（ダミーデータ）
df_survey_large = pd.DataFrame({
    "年代": ["20代", "30代", "20代", "40代", "30代", "20代", "40代", "20代"] * 10,
    "利用満足度": ["満足", "不満", "満足", "普通", "満足", "不満", "普通", "満足"] * 10
})

# normalize="index" を指定すると、各年代ごとに合計が 1.0 (100%) になる割合で集計してくれます！
ratio_crosstab = pd.crosstab(df_survey_large["年代"], df_survey_large["利用満足度"], normalize="index")

print("▼ 年代別の満足度割合（%）")
display(ratio_crosstab * 100) # 100を掛けて％表記にします

<!-- Markdownセル -->
年代別の満足度割合がきれいに％で算出されたでしょうか？これで「どの年代が最も不満を抱えているか」が割合で一目でわかり、具体的な対策が立てられます。
