## 4.2 数値演算：計算をマスターしよう (約20分)

### 算術演算子のまとめ
Pythonでは、電卓のように様々な計算ができます。よく使う記号（演算子）を表にまとめました。

| 演算子 | 意味 | コード例 | 結果 | データ分析での使い道 |
| :---: | :--- | :--- | :--- | :--- |
| `+` | 足し算 | `500 + 50` | 550 | 売上の合計を出す |
| `-` | 引き算 | `1000 - 450`| 550 | お釣りの計算、利益の計算 |
| `*` | 掛け算 | `400 * 3` | 1200 | 単価 × 個数 |
| `/` | 割り算 | `10 / 4` | 2.5 | 平均値の計算（結果は実数になる）|
| `//`| 割り算の商 | `10 // 4` | 2 | 「10個のケーキを4人で分けると1人何個？」 |
| `%` | 割り算の余り| `10 % 4` | 2 | 「余るケーキはいくつ？」、偶数・奇数の判定 |
| `**`| べき乗 | `2 ** 3` | 8 | 複利計算（2の3乗＝2×2×2） |

### 演算子の優先順位と括弧、そして空白
数学と同じように、掛け算・割り算は、足し算・引き算より先に計算されます。
順番を変えたい時は `( )` 括弧を使います。
また、計算式を見やすくするために、記号の前後には**空白（半角スペース）**を入れるのが美しい書き方（コーディング規約）とされています。

4.3 文字列：文字データを自由自在に操ろう (約25分)¶

ここからは「文字列（文字のデータ）」です。SNSのコメント分析など、文系学生がデータ分析で大活躍する分野の基礎になります！

文字列とインデックス（超重要！）¶

Pythonの世界では、文字列は「文字が順番に並んだ列車の車両」のように扱われます。 それぞれの文字には**「インデックス（番号）」**が振られていますが、ここで最大の注意点！ コンピュータは「0」から数字を数え始めます！

【インデックスの図解】 「ＣＡＦＥ」という文字があった場合…

  先頭から数える ──▶   0    1    2    3
                    [ C ][ A ][ F ][ E ]
  後ろから数える ◀──  -4   -3   -2   -1

最初の「C」を取り出したければ、0番目を指定します。一番後ろの「E」は -1 で取り出せます。

文字列とスライス¶

文字の「一部を切り取る」ことをスライスと呼びます。 文字列[開始 : 終了] と書きますが、**「終了の番号は含まれない（その手前まで）」**というルールがあります。

【スライスの図解】

  [ C ][ A ][ F ][ E ]
  0    1    2    3    4  (文字の隙間に番号があるイメージを持つと分かりやすいです)
  ↑         ↑
  ここから、ここまで（2は含まない） ＝ [0:2] ＝ "CA"

実際にコードで見てみましょう！


<!-- コードセル -->
shop_name = "ムサシ・カフェ"

# インデックス（1文字だけ取り出す）
# 0から数えるので、3番目は「・」ではなく「カ」になります！
print("0番目の文字:", shop_name)  
print("3番目の文字:", shop_name)  
print("最後の文字:", shop_name[-1]) 

# スライス（範囲を切り出す）
# 0番目から4番目の「手前（3番目）」まで切り出す
print("0から4番目の手前まで:", shop_name[0:4]) 

# 開始や終了を省略すると、「一番最初から」「一番最後まで」という意味になります
print("最初から3番目の手前まで:", shop_name[:3]) 
print("4番目から最後まで:", shop_name[4:])

🚨 初心者によくある誤解 — 「変数」と「文字列」の混乱 (超重要！)¶

文系初心者の皆さんが最初によくやってしまう、そしてパニックになりやすい間違いがこれです。

  • "coffee" ＝ クォーテーションで囲まれている。これは**「文字列（ただの文字）」**です。

  • coffee ＝ クォーテーションがない。これは**「変数（データが入った箱の名前）」**です。

drink = "コーヒー"  # 変数 drink に 文字列 "コーヒー" を入れた

print("drink")    # ← 画面には「drink」という文字がそのまま出る！
print(drink)      # ← 画面には箱の中身の「コーヒー」が出る！

エラー（NameError: name 'xxx' is not defined）が出た時は、「文字として書きたかったのに、クォーテーションを付け忘れて『変数』として扱われていないか？」を必ずチェックしてください！

  2. 変数と文字列の混同への対策: 多くの文系プログラミング入門者が躓く NameError（未定義の変数）の根本原因である「クォーテーションの有無による変数と文字列の違い」について、独立したセクションを設けて解説し、演習問題（演習5）で意図的に修正させることで体感的な理解を促しています。

  3. データ分析への接続: 文字列操作（replace や strip、空文字列）を単なる文法として教えるのではなく、「アンケート結果などのデータクレンジング（綺麗なデータに整形する作業）で必須になる」という実践的な意義（データ分析との繋がり）を強調し、学習モチベーションを高めました。

  4. 時間配分とペルソナの維持: 講義（約55分）と演習（約50分）の半々という時間配分を守りつつ、「大丈夫です」「エラーが出ても一緒に考えましょう」といった教員として寄り添うトーン（ペルソナ）を文末やFAQに散りばめ、心理的ハードルを下げています。

  5. input()の排除: 指示通り、キー入力を行う input() は用いず、変数への直接代入によるコードに統一しています。
