第13回 総合演習¶

皆さんの手でゼロからプログラムを作り上げる**「ミニプロジェクト（総合演習）」**に挑戦していただきます。 完成させることが目的ではなく、エラーと格闘しながら「試行錯誤するプロセス」を体験してください

🎯 到達目標¶

  1. プロジェクト設計・実装 の流れを理解し、自力で簡単なプログラムを組み立てることができる。

  2. 他の人が読んでも分かりやすいよう、コードの整理とコメント を書くことができる。

  3. エラーが出ても、これまで学んだテストとデバッグの知識を使って自己解決（AIの活用含む）ができる。

  4. 全13回の学習の振り返りを行い、「プログラミング応用A」への次の一歩を踏み出せる。

練習問題のGoogle Colab起動¶

  1. 上記の「Open In Colab」をクリックして、Google Colabを起動させてください

  2. [ファイル] → [ドライブにコピーを保存] を選択して、Googleドライブにコピーを保存してください

  3. 保存が成功すると，Googleドライブの「マイドライブ」 →「Colab Notebooks」にコピーしたファイルが保存されます。

  4. GoogleドライブにコピーしたGoogle ColabのNotebooksを開いてください

  5. 開いたGoogle ColabのNotebooksで作業をしてください

データは「21世紀の新しい石油」¶

皆さんが文系であっても、将来どんな仕事（営業、企画、マーケティング、公務員など）に就くとしても、今は「エビデンス（根拠）に基づく意思決定」が求められる時代です。 「なんとなく最近この商品が売れている気がする」ではなく、「データ分析の結果、20代女性のリピート率が先月比で15%上昇しているため、ここに予算を投じましょう」と言える人材が、どこの組織でも喉から手が出るほど欲しがられています。

プロジェクト設計・実装のステップ¶

いきなりコードを書き始めるのは失敗のもとです。プロは必ず「設計」から始めます。 ミニプロジェクトを進めるときは、以下の3ステップを意識しましょう。

  1. 設計（要件定義）: 「どんなデータ（変数）を扱うか？」「どんな結果を出力したいか？」を日本語でメモします。

  2. 実装（コーディング）: メモをもとに、1行ずつコードを書いていきます。一気に全部書かず、少し書いたら実行して print() で中身を確認するのがコツです。

  3. テスト・デバッグ: わざと変なデータ（マイナスの金額など）を入れてみて、エラーで止まらないか（例外処理ができているか）を確認します。

# （例）カフェの割引計算システムの「設計から実装」

# 1. 設計（コメントで書く）
# - 価格(price)と割引率(rate)を受け取る関数を作る
# - 割引後の価格を計算して返す
# - もし割引率が0未満ならエラーを防ぐ

# 2. 実装（コードを書く）
def calculate_discount(price, rate):
    # 3. テスト・デバッグ（安全装置を入れる）
    if rate < 0:
        print("エラー：割引率は0以上にしてください")
        return price
    
    final_price = price * (1 - rate)
    return final_price

# テスト実行
print(calculate_discount(1000, 0.2)) # 正常
print(calculate_discount(1000, -0.1)) # 異常値への対応

コードの整理とコメント¶

「動けばいい」から卒業し、「美しいコード」を目指しましょう。

  • コメントは「何をしているか（Why）」を書く: a = a + 1 の上に # aに1を足す と書くのは不要です（見ればわかるため）。# 来客カウンターを更新する のように、なぜその処理をしているかを書きましょう。

  • マジックナンバーを避ける: コードの中に突然 0.1 などの数字を書かず、TAX_RATE = 0.1 のように変数にして意味を持たせます。

# ❌ 悪い例（意味がわからない）
p = 1000
r = p * 1.1

# ⭕ 良い例（コードの整理とコメントができている）
TAX_RATE = 1.1
coffee_price = 1000

# 税込み価格を計算し、レジに表示するため変数に保存する
final_price = coffee_price * TAX_RATE

「ニュース記事一覧のタイトルとリンクの抽出」を想定したサンプルコード

import time
import requests
from bs4 import BeautifulSoup

# 1. 取得したいWebページのURL
url = "https://news.ycombinator.com/"  # 例: Hacker News（シンプルな構造の英語サイト）

# Webサーバーへの配慮（User-Agentの設定）
headers = {
    "User-Agent": "Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/120.0.0.0 Safari/537.36"
}

try:
    # 2. HTTPリクエストを送信してHTMLを取得
    response = requests.get(url, headers=headers, timeout=10)

    # ステータスコードのチェック（200 OK でなければ例外を発生させる）
    response.raise_for_status()

    # 3. BeautifulSoupでHTMLを解析（パーサーには html.parser を使用）
    soup = BeautifulSoup(response.text, "html.parser")

    # 4. 要素の抽出（例: 記事タイトルとリンクを取得）
    # .find_all() で該当するタグをすべて取得
    articles = soup.select(".titleline > a")

    print(f"--- 取得結果 ({len(articles)}件) ---")

    for index, article in enumerate(articles[:10], 1):  # 上位10件を表示
        title = article.text  # テキスト（タイトル）を取り出す
        link = article.get("href")  # href 属性（URL）を取り出す

        print(f"{index}. {title}")
        print(f"   URL: {link}\n")

        # サーバー負荷軽減のため、複数ページを巡回する場合は必ず待機時間を入れる
        # time.sleep(1)

except requests.exceptions.RequestException as e:
    print(f"リクエストエラーが発生しました: {e}")

BeautifulSoupで要素を検索・抽出する手段は主に2パターンあります。

CSSセレクターで探す（.select() / .select_one()）

CSSと同じ書き方が使えるため、一番直感的で汎用性が高い方法です。

# class="title" の要素をすべて取得
title = soup.select(".title")
print(title)

# id="main" の中の <a> タグをすべて取得
main_atag = soup.select("#main a")
print(main_atag)

# 最初に見つかった1件だけを取得
h1 = soup.select_one("h1")
print(h1)

タグ名や属性で探す（.find() / .find_all()）

シンプルに「すべての タグを取りたい」時などに便利です。

# 最初の <h1> タグを取得
h1 = soup.find("h1")
print(h1)

# <a class="link"> タグをすべて取得
class_a = soup.find_all("a", class_="link")
print(class_a)

⚠️ Webスクレイピングのマナーと注意点¶

  • time.sleep(1) を入れる: 連続リクエストを送ると相手のサーバーに負荷がかかります。ループ処理の際は必ず1秒以上の間隔を開けましょう。

  • 利用規約（robots.txt）を確認する: サイトによってはスクレイピングを禁止している場合があります（https://example.com/robots.txt で確認可能）。
