第13回 総合演習¶

皆さんの手でゼロからプログラムを作り上げる**「ミニプロジェクト（総合演習）」**に挑戦していただきます。 完成させることが目的ではなく、エラーと格闘しながら「試行錯誤するプロセス」を体験してください

🎯 到達目標¶

  1. プロジェクト設計・実装 の流れを理解し、自力で簡単なプログラムを組み立てることができる。

  2. 他の人が読んでも分かりやすいよう、コードの整理とコメント を書くことができる。

  3. エラーが出ても、これまで学んだテストとデバッグの知識を使って自己解決（AIの活用含む）ができる。

  4. 全13回の学習の振り返りを行い、「プログラミング応用A」への次の一歩を踏み出せる。

練習問題のGoogle Colab起動¶

  1. 上記の「Open In Colab」をクリックして、Google Colabを起動させてください

  2. [ファイル] → [ドライブにコピーを保存] を選択して、Googleドライブにコピーを保存してください

  3. 保存が成功すると，Googleドライブの「マイドライブ」 →「Colab Notebooks」にコピーしたファイルが保存されます。

  4. GoogleドライブにコピーしたGoogle ColabのNotebooksを開いてください

  5. 開いたGoogle ColabのNotebooksで作業をしてください

イントロダクション：なぜデータ分析を学ぶのか？¶

演習に入る前に、私たちがこの全13回で学んできた「データ分析」が、これからの社会でいかに重要かをお話しします。

データは「21世紀の新しい石油」¶

皆さんが文系であっても、将来どんな仕事（営業、企画、マーケティング、公務員など）に就くとしても、今は「エビデンス（根拠）に基づく意思決定」が求められる時代です。 「なんとなく最近この商品が売れている気がする」ではなく、「データ分析の結果、20代女性のリピート率が先月比で15%上昇しているため、ここに予算を投じましょう」と言える人材が、どこの組織でも喉から手が出るほど欲しがられています。

プロジェクト設計・実装のステップ¶

いきなりコードを書き始めるのは失敗のもとです。プロは必ず「設計」から始めます。 ミニプロジェクトを進めるときは、以下の3ステップを意識しましょう。

  1. 設計（要件定義）: 「どんなデータ（変数）を扱うか？」「どんな結果を出力したいか？」を日本語でメモします。

  2. 実装（コーディング）: メモをもとに、1行ずつコードを書いていきます。一気に全部書かず、少し書いたら実行して print() で中身を確認するのがコツです。

  3. テスト・デバッグ: わざと変なデータ（マイナスの金額など）を入れてみて、エラーで止まらないか（例外処理ができているか）を確認します。

# （例）カフェの割引計算システムの「設計から実装」

# 1. 設計（コメントで書く）
# - 価格(price)と割引率(rate)を受け取る関数を作る
# - 割引後の価格を計算して返す
# - もし割引率が0未満ならエラーを防ぐ

# 2. 実装（コードを書く）
def calculate_discount(price, rate):
    # 3. テスト・デバッグ（安全装置を入れる）
    if rate < 0:
        print("エラー：割引率は0以上にしてください")
        return price
    
    final_price = price * (1 - rate)
    return final_price

# テスト実行
print(calculate_discount(1000, 0.2)) # 正常
print(calculate_discount(1000, -0.1)) # 異常値への対応

コードの整理とコメント¶

「動けばいい」から卒業し、「美しいコード」を目指しましょう。

  • コメントは「何をしているか（Why）」を書く: a = a + 1 の上に # aに1を足す と書くのは不要です（見ればわかるため）。# 来客カウンターを更新する のように、なぜその処理をしているかを書きましょう。

  • マジックナンバーを避ける: コードの中に突然 0.1 などの数字を書かず、TAX_RATE = 0.1 のように変数にして意味を持たせます。

# ❌ 悪い例（意味がわからない）
p = 1000
r = p * 1.1

# ⭕ 良い例（コードの整理とコメントができている）
TAX_RATE = 1.1
coffee_price = 1000

# 税込み価格を計算し、レジに表示するため変数に保存する
final_price = coffee_price * TAX_RATE

演習課題の説明と評価について¶

これから、皆さんに難易度別のミニプロジェクト（演習1〜5）に取り組んでいただきます。

難易度と採点について¶

  • 初級（基本文法中心）: 変数、リスト、関数などの基礎。

  • 中級（データ処理中心）: pandasやmatplotlibを使った、実務に近いデータ分析。

  • 上級（応用）: クラス（オブジェクト指向）や例外処理を使った本格的なシステム。

【重要】難易度によって成績（採点）は変わりません！ 上級が解けなかったからといって減点されることはありません。初級を丁寧に完璧に仕上げるのも、上級に果敢に挑んでエラーと格闘するのも、どちらも素晴らしい「学習のプロセス」として高く評価します。自分のレベルに合わせて、自由に選んで（もちろん全部やってもOK！）挑戦してください。
