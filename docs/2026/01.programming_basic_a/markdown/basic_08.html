第8回 制御フロー（条件分岐、繰り返し、イテレータ、内包表記）¶

データ分析の「最強の武器」とも言える**「繰り返し処理（ループ）」**を本格的に学びます。

100人のお客様のデータも、1万日分の売上データも、今日学ぶ「for文」を使えば、たった数行のコードで一瞬で計算できるようになります！
今回は「イテレータ」や「内包表記」といった、ちょっと難しそうな専門用語がたくさん出てきます。 「順番待ちの整理券」や「ベルトコンベア」など、カフェの日常に例えて一緒に考えていきましょう。

🎯 到達目標¶

  1. for文やwhile文 を使って、大量のデータを自動で繰り返し処理できる。

  2. break や continue を使って、繰り返しの流れ（制御フロー）を自由に操れる。

  3. イテラブルとイテレータ の違いを理解し、Pythonの繰り返しの裏側の仕組みを説明できる。

  4. 内包表記 を使って、データ分析の下準備（リストの作成）を短く美しく書ける。

イントロダクション：制御フローとは？¶

プログラムがどの順番で動くか、その流れのことを**制御フロー（制御構文）と呼びます。
これまでに一直線に進む「順次処理」と、if文による「条件分岐」を学びました。今日は3つ目の矢である「繰り返し」**を学びます。

【繰り返しのイメージ図（ベルトコンベア）】

  [ 📦注文データ ] ──▶  [ 🤖 処理ロボット(for文) ] ──▶ [ 📊 分析結果 ]
  (何百個あっても)      「順番に取り出して計算！」     (一瞬で終わる！)

データ分析では、「すべての行のデータに対して同じ処理（税込み計算や、特定の文字を消すなど）をする」ことが非常に多いため、この繰り返し処理が欠かせません。

for文とrange()関数：回数が決まっている繰り返し¶

for文による繰り返しと in¶

for文は、「リストや文字列などの箱から、データを1つずつ取り出して処理する」魔法の言葉です。in の右側に箱を書き、左側に取り出したデータを入れる一時的な変数名を書きます。

for文による処理の繰り返し

for 文の処理の流れ

# for文によるリストの繰り返し
sales_list =  [100, 200, 300]  # コーヒー、ケーキ、紅茶の売上

# リストから1つずつ取り出して、変数 price に入れながら繰り返す！
for price in sales_list:
    print("売上データ:", price, "円")
    
# for文による文字列の繰り返し（文字も1文字ずつ取り出せます！）
for char in "CAFE":
    print("文字:", char)

range()関数による回数指定¶

「10回繰り返したい！」という時に、わざわざ [1, 2, 3...10] とリストを作るのは大変です。そこで便利なのが、整理券を発行してくれる range() 関数です。range(開始, 終了) で作ります（※終了の数字は含まれません！）。これをリスト化することもできます。

enumerate()：番号札付きで取り出す¶

「いま何番目のデータか？」というインデックス番号も一緒に欲しい時は、enumerate()（エニュメレイト）を使います。データ分析で「3行目のデータでおかしくなったぞ？」と探す時に大活躍します。

# range() 関数（0から4までの整理券を発行する）
for i in range(5): 
    print("整理券番号:", i)

# rangeとリストの組み合わせ
num_list = list(range(1, 4))
print("作成されたリスト:", num_list)

# enumerate() で番号札とデータを両方取り出す！
menu = ["コーヒー", "紅茶", "ケーキ"]
for index, item in enumerate(menu):
    print(index, "番目のメニューは", item, "です。")

for文による繰り返しと辞書¶

辞書もfor文で回せます。.keys(), .values(), .items() を使い分けましょう。

使い分けのポイント

メソッド

取り出せるデータ

主な用途

menu.keys()

キーのみ（"コーヒー", ...）

商品名や登録データの一覧を出力したいとき

menu.values()

値のみ（400, ...）

合計金額の計算（sum(menu.values())）や平均値を出したいとき

menu.items()

キーと値のペア

画面に「名前: 値」の形式でセット表示したいとき

 
# メニュー表の辞書（キー: 商品名, 値: 価格）
menu = {"コーヒー": 400, "紅茶": 450, "カフェラテ": 500, "ケーキ": 600}

# キー（商品名）だけを取り出す: .keys()
print("--- [メニュー一覧] ---")
# ※ .keys() は省略して `for item in menu:` と書いても同じ動作になります
for item in menu.keys():
    print(f"・{item}")

# 値（価格）だけを取り出す: .values()
print("\n--- [価格リスト] ---")
for price in menu.values():
    print(f"{price}円")

# キーと値（商品名と価格）を同時に取り出す: .items()  ★一番よく使います！
print("\n--- [メニュー表（全データ）] ---")
# 2つの変数（item, price）で同時に受け取るのがポイントです
for item, price in menu.items():
    print(f"{item}: {price}円")

for文の入れ子と計算量¶

for文の中にさらにfor文を書く（入れ子）こともできます。ただし注意点があります！ 例えば、1000人の顧客リストと、1000個の商品リストを入れ子で回すと、「1000 × 1000 = 100万回」の処理が行われます。データが増えると急激に時間がかかるようになるため、これは**「計算量が大きい（O(N^2)の計算量）」**と言って警戒します。

ループ処理のネスト

# 辞書の繰り返し
prices = {"コーヒー": 400, "紅茶": 400}
# .items() を使うと、キーと値を両方一気に取り出せます
for key, value in prices.items():
    print(key, "の値段は", value, "円です。")

# for文の入れ子（九九の計算のようなイメージ）
for i in range(1, 3):
    for j in range(1, 3):
        print("i=", i, ", j=", j)

while文と制御の流れを変える魔法¶

while文による繰り返し¶

for 文が「回数や個数が決まっている」時に使うのに対し、**while 文は「条件を満たしている間はずっと繰り返す」**時に使います。

for文とwhile文における else¶

Python特有の機能として、ループが**「breakされずに最後まで無事に完走した時だけ実行される else」**を書くことができます。

for / while (繰り返し処理)
   │
   ├── [条件合致] ──> break (途中脱出) ──> ［elseブロックを飛ばして終了］
   │
   └── [完走] ───────> 繰り返し終了  ──> ［elseブロックを実行！］

「break ＝ else をキャンセルするコマンド」 と捉えるともいえる。

for文の例

numbers = [1, 3, 5, 7, 9]
target = 4

# 偶数が含まれているか探す
for num in numbers:
    if num % 2 == 0:
        print(f"偶数 {num} を見つけました！")
        break
else:
    # break されずにループが最後まで到達した場合のみ実行される
    print("リスト内に偶数は見つかりませんでした。")

# 出力結果:
# リスト内に偶数は見つかりませんでした。

while文の例

import random

attempts = 0
max_attempts = 3
success = False

# 最大3回までチャレンジするループ
while attempts < max_attempts:
    attempts += 1
    print(f"{attempts} 回目の接続試行中...")

    # 50%の確率で成功させるダミー処理
    if random.choice([True, False]):
        print(" -> 接続に成功しました！")
        success = True
        break  # 成功したのでループを抜ける（elseは実行されない）

    print(" -> 失敗しました。")
else:
    # 3回とも失敗して while の条件式（attempts < max_attempts）が False になり完走した場合
    print("エラー: 規定回数内に接続できませんでした。")

制御構造とreturn文¶

関数（def）の中で return が実行されると、その時点でfor文やwhile文もすべて強制終了して結果を返します。

# while文 と break, continue の働き
stock = 3 # 在庫

while stock > 0:
    print("いらっしゃいませ！在庫は残り", stock, "個です。")
    stock = stock - 1
    
    if stock == 1:
        print("残り1個なので、特別なお客様用にとっておきます！（スキップ）")
        continue # ここで下の処理を飛ばして、次のループの先頭に戻る
        
    if stock == 0:
        print("売り切れました！本日は閉店します。（強制終了）")
        break # ループを完全に抜け出す

# ループの else（無事に完走したかどうかの確認）
for i in range(3):
    print("処理中...", i)
    # ここに break があると、下の else は実行されません
else:
    print("ループがエラーや中断なく、無事に最後まで完了しました！")

イテラブルとイテレータ（繰り返しの裏側）¶

ここは少しだけ高度な、Pythonの裏側の仕組みのお話です。「for文ってどうして中身を順番に取り出せるの？」という疑問の答えです。

  • イテラブル (Iterable): 「順番に取り出せる箱」のこと。（例：リスト、文字列、辞書）

  • イテレータ (Iterator): 「現在地を覚えていて、次を取り出してくれる人」のこと。 ※ 「イテラブルはイテレータではない」 というのが重要です。箱そのものは動けません。

【仕組み（for文の正体）】

  1. for文はまず、対象のイテラブルに iter() という関数を使って、イテレータ（取り出し担当の人）を生み出します。

  2. 次に、next() という関数を使って「次ちょうだい！」と要求します。

  3. 中身がなくなる（StopIterationエラーが出る）まで、それを自動で繰り返しているのがfor文の正体です。

ファイルオブジェクトもイテレータであり、enumerate も実はイテレータを返しています。

# イテラブルとイテレータの違いを体験してみましょう！
my_list = ["コーヒー", "紅茶", "ケーキ"] # これはイテラブル（箱）です

# iter() で、この箱専用の「取り出し係（イテレータ）」を作ります
my_iterator = iter(my_list)

# next() を呼ぶたびに、現在地を記憶しながら1つずつ出してくれます
print("1回目:", next(my_iterator))
print("2回目:", next(my_iterator))
print("3回目:", next(my_iterator))
# 4回目を呼ぶと、空っぽなので StopIteration というエラーが出ます！

内包表記（リストや辞書を美しく作る）¶

データ分析では、「古いリストに処理をして、新しいリストを作る」ことが頻繁にあります。 これを1行でスッキリ書けるのが**「内包表記（ないほうひょうき）」**です。少し暗号みたいに見えますが、慣れると手放せなくなりますよ！

リスト内包表記¶

[ 計算式 for 変数 in イテラブル ] という書き方をします。

条件付き内包表記¶

[ 計算式 for 変数 in イテラブル if 条件 ] と書くと、条件に合ったものだけを抽出できます！

セット・辞書内包表記 / ジェネレータ式¶

カッコを { } に変えるとセットや辞書が作れます。丸カッコ ( ) にすると、メモリを節約できる「ジェネレータ式（イテレータの一種）」というものが作れます。

# 通常のfor文で税込み価格のリストを作る場合
prices = 
tax_in_prices = []
for p in prices:
    tax_in_prices.append(p * 1.1)
print("通常のfor文:", tax_in_prices)

# 🌟 リスト内包表記を使うと、これがたった1行で書けます！
# 読み方：「pricesの中の p を一つずつ取り出し、p * 1.1 をした結果をリストにまとめる」
tax_in_prices_fast = [p * 1.1 for p in prices]
print("リスト内包表記:", tax_in_prices_fast)

# 条件付き内包表記（200円以上のものだけ税込みにする）
expensive_only = [p * 1.1 for p in prices if p >= 200]
print("条件付き（200円以上）:", expensive_only)

# 辞書内包表記の例（メニュー名をキー、値段を値にする）
menu_names = ["コーヒー", "紅茶", "ケーキ"]
# zip は2つのリストを同時に取り出す便利ツールです
menu_dict = {name: price for name, price in zip(menu_names, prices)}
print("辞書内包表記:", menu_dict)

📚 第8回のまとめ¶

「データを一気に処理する」ための強力な道具です。データ分析の現場で必ず役立ちます。

✨ 今日の重要ポイントまとめ¶

  • for文とrange: 何度も同じことを繰り返す時の基本。enumerate で番号札も取れる。

  • break と continue: 繰り返しを「強制終了」するか、「今回はスキップ」するか自由に操れる。

  • イテレータの仕組み: for文の裏側では、iter() で取り出し係が作られ、next() で1つずつデータが運ばれている。

  • 内包表記: リストなどの作成と条件抽出を、たった1行でスッキリ高速に行うプロの技！

❓ よくある質問と回答 (FAQ)¶

  • Q. 内包表記がどうしても読みにくくて覚えられません。普通のfor文で書いてもいいですか？

    • A. もちろん大丈夫です！普通のfor文とif文の組み合わせで書いた方が、後から見返した時に分かりやすい場合もあります。「スッキリ書ける便利な書き方があるんだな」と知っておくだけでも素晴らしい進歩です。生成AIに「これを内包表記にして」と頼むこともできますよ。

  • Q. O(N^2) の計算量って、どれくらいヤバいんですか？

    • A. データが少ないうちは問題ありませんが、データ分析で扱う「10万件」のデータを入れ子にすると、10万×10万＝100億回もの計算になり、パソコンがフリーズしてしまいます。ループの中にループを書くときは「これ、時間がかかりすぎないかな？」と少し警戒するクセをつけましょう！

🌟 Colabで試すおすすめコード¶

ファイルからデータを読み込みながら、enumerate と break を使って「最初の数行だけチラ見する（先頭の抽出）」という、データ分析の初手で絶対に行う処理です。

# （準備）大きなダミーデータファイルを作ります
with open("big_data.txt", "w") as f:
    for i in range(100):
        f.write("顧客ID_" + str(i) + "\n")

# ファイルオブジェクト自体が「イテレータ（次々取り出せるもの）」です！
with open("big_data.txt", "r") as f:
    for index, line in enumerate(f):
        print(index, "行目:", line.strip())
        
        # 100行全部見ると画面がいっぱいになるので、3行見たらやめる！
        if index == 2:
            print("--- 中略 ---")
            break
