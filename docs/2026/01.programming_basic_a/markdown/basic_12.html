第12回 Pythonのライブラリ・パッケージ（グラフ可視化）¶

集計したデータを**「誰が見ても一目でわかる美しいグラフ（可視化）」**にする方法を学びます。 数字の羅列だけでは見えなかった「カフェの売上の波」や「気温と客数の関係」が、グラフにすると魔法のように浮かび上がってきますよ。

グラフの種類（散布図、ヒートマップなど）がたくさん出てきますが、「これは売上の変化を見るためのグラフだな」と、目的とセットにして覚えていけば簡単です。 データ分析の楽しさを一番実感できる回ですので、一緒に楽しんでいきましょう！

🎯 到達目標¶

この授業が終わるころには、以下のことができるようになります。

  1. データ可視化の重要性 を理解し、目的に合ったグラフ（線、棒、散布図など）を選べる。

  2. matplotlib（マットプロットリブ） を使って、基本的なグラフを描画し、タイトルや色などの装飾ができる。

  3. seaborn（シーボーン） を使って、複雑なデータ（ヒストグラムやヒートマップ）をより簡単で美しく描画できる。

  4. 自分が作った分析グラフを 画像ファイルとして保存（出力） できる。

イントロダクション：なぜデータを「可視化」するのか？¶

データ分析において、「数字」だけで相手を説得するのは非常に困難です。 「先月のコーヒーの売上は、1週目が400杯、2週目が420杯、3週目が380杯で…」と言われるより、グラフを1枚見せた方が一瞬で伝わりますよね。

【データ可視化の効果（イメージ図）】

[ 📊 数字の羅列 ] 
 400, 420, 380, 500, 480... (よくわからない…)
       │
       ▼ (Pythonの魔法！)
[ 📈 美しいグラフ ]
       ╭○╮
      ╱  ╰─╮  (直感的に「週末に爆発的に売れている！」とわかる)
   ╭─╯     ╰─

2つの強力なライブラリ：matplotlib と seaborn¶

Pythonでグラフを描くための2大ツールを紹介します。

  • matplotlib（マットプロットリブ）: グラフ界の「職人さん」。真っ白な画用紙に、ゼロから線を引いたり色を塗ったりして、自由自在にグラフを描けます。

  • seaborn（シーボーン）: グラフ界の「オシャレなデザイナー」。matplotlibをベースに作られており、統計データを見栄え良く、少ないコードで描いてくれます。

この2つは「あだ名」をつけて読み込みます（plt と sns）。

# （準備）グラフを描くためのライブラリを読み込みます！
# ※Colabでは最初からインストールされているので、importするだけで使えます。

import matplotlib.pyplot as plt  # 画用紙とペンのセット（あだ名は plt）
import seaborn as sns            # おしゃれなデザイナー（あだ名は sns）
import pandas as pd              # 前回学んだ、表データを扱うツール
import numpy as np               # 前々回学んだ、計算ツール

# ※注意：標準のmatplotlibは「日本語」を表示しようとすると文字化け（□□□）してしまいます。
# Colabで簡単に日本語を表示できるおまじないライブラリを追加インストールします。
!pip install japanize-matplotlib
import japanize_matplotlib

%matplotlib inline

基本のグラフ作成と装飾 (matplotlib)¶

まずは基本の matplotlib を使って、目的に合わせた色々なグラフを描いてみましょう！ 使い方の基本は 「1. キャンバスに描く → 2. 装飾する → 3. 画面に見せる(plt.show())」 の3ステップです。

① 折れ線グラフ（時間の経過・変化を見たい時）¶

「1ヶ月の売上の推移」など、時間の流れによる変化を見るのに最適です。

  • plt.plot(X軸のデータ, Y軸のデータ)

import matplotlib.pyplot as plt
ls1 = [1, 4, 9, 16]
plt.plot(ls1)
plt.show()

折れ線グラフを複数表示させるには、plt.plot を繰り返します。

import matplotlib.pyplot as plt
ls1 = [1, 4, 9, 16]
ls2 = [8, 7, 6, 5]
plt.plot(ls1, label='1st plot')
plt.plot(ls2, label='2nd plot')
plt.show()

② 棒グラフ（量を比較したい時）¶

「コーヒーと紅茶とケーキ、どれが一番売れた？」など、大小を比べるのに使います。

  • plt.bar(X軸のデータ, Y軸のデータ)

棒グラフを表示させるには、plt.bar に水平座標、高さをリストで与えます。 この2つのリストの要素数は同じでなければなりません。 以下の例では、等間隔でグラフを表示させるため水平軸に整数列を使っています。

import matplotlib.pyplot as plt
x = [1, 2, 3, 4]
y = [10, 30, 40, 15]
plt.bar(x,y)
plt.show()

文字列をキー、整数を値とする辞書を棒グラフで可視化します。 さらに、水平軸にはキーをラベルとして表示されます。

import matplotlib.pyplot as plt
d = {'apple':10, 'banana':30, 'orange': 40, 'kiwi': 15}
x = [1,2,3,4]
plt.bar(x, d.values(), tick_label=list(d.keys()))
plt.show()

③ 散布図（2つの関係性・相関を見たい時）¶

「気温が高い日は、冷たい飲み物が売れるかな？」という関係性（相関）を点々で調べます。

  • plt.scatter(X軸のデータ, Y軸のデータ)

散布図を表示させるには、plt.scatter にそれぞれの点に対応する水平、垂直座標をリストで与えます。 この2つのリストの要素数は同じでなければなりません。

import matplotlib.pyplot as plt
x = [5, 10, 15, 10]
y = [10, 5, 10, 15]
plt.scatter(x,y)
plt.show()

グラフの装飾（タイトル、ラベル）¶

何も書いていないグラフは、何を表しているか分かりません。必ず名前をつけましょう。

# カフェの1週間の売上データ
days = ["月", "火", "水", "木", "金", "土", "日"]
sales = [1000, 2000, 3000, 4000, 2000, 5000, 10000]

# --- ① 線グラフの作成 ---
# マーカー(点)の形や、色(color)を指定できます
plt.plot(days, sales, marker="o", color="blue") 

# --- 装飾 ---
plt.title("1週間のカフェ売上推移") # グラフのタイトル
plt.xlabel("曜日")                   # X軸（横）のラベル
plt.ylabel("売上（杯）")             # Y軸（縦）のラベル
plt.grid(True)                       # 読みやすいように補助線（グリッド）を入れる

# --- 画面に表示！ ---
plt.show()

# ========================================================

# --- ② 棒グラフの作成 ---
items = ["コーヒー", "紅茶", "ケーキ"]
amounts = [500, 600, 400]

# 棒グラフ（bar）を描きます
plt.bar(items, amounts, color="orange")
plt.title("商品別の販売数")
plt.show()

複数図表のプロット¶

figureオブジェクトをまず生成します。figsizeで大きさを変更できます。

fig = plt.figure(figsize=(8,8))
# add_subplotでサブプロットを追加します。(2,2,1)はレイアウトを2x2にして4つのうちの1番目のサブプロットを選択しています。
ax1 = fig.add_subplot(2,2,1)
ax2 = fig.add_subplot(2,2,2)
ax3 = fig.add_subplot(2,2,3)
ax4 = fig.add_subplot(2,2,4)
ax1.plot([0,1,2,3],[0,1,2,3], '-', color='k')
ax2.bar([0,1,2,3],[0,1,2,3], color= 'green')
ax3.plot([0,1,2,3][::-1],[0,1,2,3], 'o', color= 'r')
ax4.plot([0,1,2,3][::-1],[0,1,2,3], color='orange')
plt.show()

これでからのサブプロット4つができました。 同様のことは、pltsubplotsメソッドを使ってもできます。

fig, axes = plt.subplots(2,2, figsize=(8,8))
# axesは二次元配列のようなインデックスつけることが出来ます。
axes[0,0].plot([0,1,2,3],[0,1,2,3], '-', color='k') 
axes[0,1].bar([0,1,2,3],[0,1,2,3], color= 'green')
axes[1,0].plot([0,1,2,3][::-1],[0,1,2,3], 'o', color= 'r')
axes[1,1].plot([0,1,2,3][::-1],[0,1,2,3], color='orange')
plt.show()

注釈

Note 2次元に配置された複数のsubplotsはflatten()を使うことで、１次元としてアクセスすることができるようになります

fig, axs = plt.subplots(2, 2)
axs = axs.flatten()
i=1
for ax in axs:
    ax.plot(i, 1, 'o', color = 'red')
    i += 1
    ax.set_xlim(0,len(axs)+1)
plt.tight_layout()
plt.show()

データ分布と相関の可視化 (seaborn)¶

ここからは、デザイナーである seaborn (sns) の出番です。pandasのデータフレームと非常に相性が良く、データ分析の現場で大活躍します。

注釈

参考：可視化で便利なライブラリーがあります

  • Bokeh 　matplotlibをベースにインターラクティブなデータ可視化などを可能にするライブラリ

  • seaborn 　matplotlibをベースに構築された見栄えの良い可視化などを可能にするライブラリ

④ ヒストグラム（データの散らばり具合・分布を見たい時）¶

「お客様の年齢層はどのあたりが多いかな？」というデータの「分布（ばらつき）」を見るグラフです。 棒グラフと似ていますが、横軸が「区間（10代、20代など）」になるのが特徴です。

  • sns.histplot(データ)

⑤ ヒートマップ（データ同士の相関やクロス集計を見たい時）¶

数字の大小を「色の濃淡」で表したグラフです。 「月曜日の午後は売上が少ないから青色、土曜のお昼は激混みだから赤色」のように、全体像を一瞬で把握するのに使います。

  • sns.heatmap(データ)

# --- ④ ヒストグラム ---
# お客様50人分の年齢データ（ダミー）を生成します
np.random.seed(0)
ages = np.random.randint(15, 65, 50) # 15歳〜65歳の間でランダムに50個

# seabornを使ってヒストグラムを描画（kde=True をつけると、なめらかな山の線も描いてくれます）
sns.histplot(ages, bins=10, kde=True, color="green")
plt.title("ご来店のお客様の年齢分布")
plt.xlabel("年齢")
plt.ylabel("人数")
plt.show()

# ========================================================

# --- ⑤ ヒートマップ ---
# 時間帯(行)と曜日(列)の混雑度データ（pandasのデータフレームを使います）
congestion_data = pd.DataFrame({
    "月曜": [20, 30, 50],
    "水曜": [10, 40, 30],
    "土曜": [60, 70, 80]
}, index=["午前", "お昼", "午後"])

print("【元の表データ】")
print(congestion_data)

print("\n【ヒートマップで可視化】")
# annot=True で四角の中に数字を表示、cmapで色のテーマを指定
sns.heatmap(congestion_data, annot=True, cmap="Reds")
plt.title("曜日・時間帯別の混雑度ヒートマップ")
plt.show()

グラフの画像ファイル出力（保存）¶

苦労して綺麗なグラフを作ったら、レポートやプレゼン資料に貼り付けたいですよね。 plt.show() で画面に出す直前に、plt.savefig("ファイル名.png") を書くことで、画像ファイルとして保存できます。

# グラフの保存
plt.plot(["A", "B", "C"], )
plt.title("保存用のグラフ")

# 保存（show() の前に書くのが鉄則です！）
plt.savefig("my_graph.png")
print("my_graph.png を保存しました！（左の📁フォルダから確認できます）")

# その後に画面に表示
plt.show()

練習問題 1（解答）

plot / title / xlabel / ylabel
plt.plot(x, y) で基本的な折れ線グラフを作成します。plt.title() や p
lt.xlabel() でグラフに情報を追加し、最後に plt.show() で画面に出力する
のが基本の流れです。

import matplotlib.pyplot as plt

x = [1, 2, 3, 4, 5]
y = [2, 5, 3, 8, 7]

# 折れ線グラフを描画
plt.plot(x, y)

# タイトルと軸ラベルの設定
plt.title("Monthly Data")
plt.xlabel("Month")
plt.ylabel("Sales")

# グラフの表示
plt.show()

  グリッド線（方眼紙の線）を表示させてください。

練習問題 2（解答）

scatter / color / marker / grid
散布図には plt.scatter() を使用します。color で色、marker で
点の形（"o", "*", "s" など）、s でマーカーの大きさをカスタマイズできます。
plt.grid(True) でグリッド線を引くと数値が読み取りやすくなります。

import matplotlib.pyplot as plt

x = [150, 160, 165, 170, 175, 180]
y = [45, 55, 60, 68, 70, 78]

# 散布図を描画（色: 赤, マーカー: 星型, サイズ: 100）
plt.scatter(x, y, color="red", marker="*", s=100)

# グリッド線の表示
plt.grid(True)

plt.xlabel("Height (cm)")
plt.ylabel("Weight (kg)")
plt.show()

以下の2グループのデータを使って、2本の折れ線グラフを同じグラフ上に重ねて描画してください。
* x = [1, 2, 3, 4, 5]
* y1 = [10, 15, 20, 25, 30]（A社の売上）
* y2 = [8, 18, 12, 28, 22]（B社の売上）
* どちらの線か分かるように凡例（legend）を表示させてください。
👉 解答例を見る（ここをクリックして展開）

練習問題 3（解答）

label と legend の連携
plt.plot() を複数回呼び出すことで、同じグラフ上に線を重ねて表示できます。
各 plot() に label="名称" を指定し、最後に plt.legend() を呼ぶことで
凡例が表示されます。

import matplotlib.pyplot as plt

x = [1, 2, 3, 4, 5]
y1 = [10, 15, 20, 25, 30]
y2 = [8, 18, 12, 28, 22]

# label 引数で凡例用の名前を指定する
plt.plot(x, y1, label="Company A", linestyle="--")  # 破線
plt.plot(x, y2, label="Company B", marker="o")  # 丸マーカー付き線

# 凡例を表示
plt.legend()

plt.show()

以下のランダムな点数データを使ってヒストグラム（度数分布図）を描画してください。
* scores = [65, 78, 88, 55, 92, 73, 85, 60, 75, 80, 95, 70, 82, 68, 90]

練習問題 4（解答）

hist と bins パラメータ
度数分布を表示するには plt.hist() を使います。
bins 引数で区切りの数（柱の数）を指定できます。edgecolor="black" を指定すると、
柱同士の境目がはっきりして見やすくなります。

import matplotlib.pyplot as plt

scores = [65, 78, 88, 55, 92, 73, 85, 60, 75, 80, 95, 70, 82, 68, 90]

# ヒストグラムを描画 (bins: 柱の数, edgecolor: 枠線の色)
plt.hist(scores, bins=5, color="skyblue", edgecolor="black")

練習問題 5（発展：サブプロットで画面分割）

1つの画面（Figure）を左右（1行2列）に分割し、それぞれの領域に別のグラフを描画してください。
* 左側の領域: x = [1, 2, 3], y = [1, 4, 9] の折れ線グラフ（タイトル: "Line Chart"）
* 右側の領域: categories = ["A", "B", "C"], values = [10, 25, 15] の棒グラフ
             （タイトル: "Bar Chart"）
👉 解答例を見る（ここをクリックして展開）

練習問題 5（解答）

plt.subplots による画面分割
複数のグラフを綺麗に並べるには plt.subplots(行数, 列数) を使うのが
オブジェクト指向描画スタイルの標準です。

分割された各領域（axes[0], axes[1]）に対して .plot() や .set_title() を
呼び出して描画します。

import matplotlib.pyplot as plt

# 1行2列のサブプロット（画面分割）を作成
fig, axes = plt.subplots(1, 2, figsize=(10, 4))

# 1. 左側のグラフ (axes[0])
axes[0].plot([1, 2, 3], [1, 4, 9], color="green")
axes[0].set_title("Line Chart")

# 2. 右側のグラフ (axes[1])
axes[1].bar(["A", "B", "C"], [10, 25, 15], color="orange")
axes[1].set_title("Bar Chart")

# レイアウトの自動調整（タイトルの重なりなどを防ぐ）
plt.tight_layout()
plt.show()

📚 第12回のまとめ¶

✨ 今日の重要ポイントまとめ¶

  • matplotlib (plt): 自由自在にグラフを描ける職人。plot(線), bar(棒), scatter(散布図) などを使い分ける。

  • seaborn (sns): 統計グラフをおしゃれに描くデザイナー。histplot(ヒストグラム) や heatmap(ヒートマップ) が得意。

  • 装飾の重要性: title, xlabel, ylabel で、誰が見てもわかるグラフにする。

  • 画像保存: plt.show() をする前に plt.savefig() を書くことで、グラフを画像ファイルとして保存できる。

❓ よくある質問と回答 (FAQ)¶

  • Q. ValueError: x and y must be the same size というエラーが出ました。

    • A. これもグラフ作成あるあるです！「X軸（横）のデータは5個あるのに、Y軸（縦）のデータは4個しかないよ」というエラーです。X軸とY軸のデータは必ずペアになっている必要があるので、リストの要素数を数えてみてください。

  • Q. グラフの日本語が「□□□」になってしまいます（文字化け）。

    • A. 本講義の冒頭で行った japanize-matplotlib のインストールとインポート（import japanize_matplotlib）を忘れていませんか？Colab環境ではこれがないと日本語が文字化けしてしまうので、新しいノートブックを作る時は必ずセットで書いておきましょう。
