イントロダクション：データ分析の重要性とプログラミングとは？¶

データ分析の重要性について¶

現代社会では、どんな仕事をするにしても「データ」が溢れています。例えば、皆さんがよく行く身近な「カフェ」を想像してみてください☕️。 「どの曜日にどのケーキが売れるのか？」「雨の日はコーヒーの売上がどうなるか？」といった情報を集めて分析することで、無駄を減らし、売上を伸ばすことができます。

【データ分析のプロセス】

[ 📝 データの収集 ] レジの売上データ（エクセルやCSV）
        │
        ▼
[ 💻 データの処理 ] Pythonを使って自動で計算・集計！
        │
        ▼
[ 📊 データの可視化 ] グラフにして直感的にわかりやすく！
        │
        ▼
[ 💡 アクション ] 「雨の日はホットドリンクの仕入れを増やそう！」

このように、勘や経験だけでなく、データに基づいて意思決定をすることが、現代のビジネスでは非常に重要です。Pythonは、この「データ処理」から「可視化」までを魔法のようにパパッとこなしてくれる強力なツールです

Google Colab¶

この授業では、皆さんのパソコンに何か難しいソフトをインストールする必要はありません。ブラウザ（Chromeなど）があれば動く Google Colaboratory（略してColab） を使います。

Colabは、Googleが提供する、開発者向けの無料のクラウドサービスです。 ブラウザ上でPythonのコードを記述・実行できるJupyter Notebook環境が提供されており、 特に機械学習やデータサイエンスの分野で広く利用されています。

Google Colabを利用するには、Googleアカウントが必要です。ログインした後に、以下のURLを開いてください。

  • Google Colabのページ

  • Google Colabを開く

    • Googleドライブのあるノートブックを開きます

  • Google Colabを新規作成する

    • Googleドライブの「マイドライブ」→ 「Colab Notebooks」の下にノートブックを新規作成します。

    • デフォルトでは「Untitled.ipynb」と言うファイル名になります

Google Colabのファイルを、「Colabノートブック」「ノートブック」等と呼びます。 ノートブックには ipynb という拡張子（エクステンション）が付きます。

Google Colabの特徴の主な特徴・できること¶

環境構築が不要:
Pythonの実行環境や、機械学習によく使われるNumPy、pandas、TensorFlowなどのライブラリがプリインストールされているため、面倒な環境構築なしにすぐにプログラミングを始めることができます。

無料でGPU/TPUが利用可能:
高度な機械学習やディープラーニングではGPU（Graphics Processing Unit）やTPU（Tensor Processing Unit）といった高性能な計算リソースが不可欠ですが、Colabではこれらを無料で利用できます（時間制限あり）。これにより、個人のPCスペックに左右されずに、重い計算を効率的に実行できます。 (有料版あり)

共同編集・共有が簡単:
Google ドライブにノートブックが保存されるため、他のユーザーと簡単に共有し、リアルタイムで共同編集することができます。教育現場やチームでの開発に非常に便利です。

対話型プログラミング: Jupyter Notebookベースであるため、コードをセルごとに記述・実行し、その場で結果を確認しながら開発を進めることができます。グラフや図表もノートブック内に直接表示されるため、データの傾向や分析結果を素早く把握できます。

AIアシスタント機能:
コードの生成、概念の説明、エラーの修正など、AIを活用した機能も提供されています。

Google Colabのメリット¶

手軽にPythonを始められる:
環境構築の手間がないため、プログラミング初心者でも気軽にPythonや機械学習を学び始めることができます。

コストがかからない:
無料で高性能な計算リソースを利用できるため、GPUなどを購入する費用を抑えられます。(有料版もあります)

共同作業がしやすい:
共有機能が充実しており、複数人でのプロジェクトや学習に適しています。

Google Colabのデメリット・注意点¶

ランタイムのリセット:
一定時間（90分や12時間など）操作がないと、実行環境（ランタイム）がリセットされ、メモリ上のデータや実行結果が消えてしまいます。長時間の学習を行う場合は注意が必要です。(有料版では緩和されます)

PCのファイルを直接扱いにくい:
ローカルのファイルを直接扱うには、Googleドライブへのアップロードやマウントが必要です。

有料版との機能差:
無料版でも十分な機能が提供されていますが、より高性能なGPUの利用、メモリ容量の増加、長時間実行などは有料版（Colab Proなど）で提供されます。

インターネット環境が必須:
クラウドサービスのため、インターネット接続がないと利用できません。

Google Colabの使用制限¶

「Google Colab」は基本的には無料で使えるが主に下記の制限がある

  • RAM：12GB

  • ディスク：CPU/TPC:最大107GB、GPU:最大68GB

  • 90分ルール : 何も操作せずに90分経つとリセット

  • 12時間ルール : インスタンスが起動してから12時間経つとリセット

有料版のGoogle Colab Proにすると、制限を緩和することができる

  • Colab Pro：月額1,179円

  • Colab Pro+：月額5,767円

  • Colab Enterprise：カスタム

Colaboratory (Colab) の使い方¶

Google Colabの起動¶

  1. Googleドライブを開きます。

    • Googleドライブ https://drive.google.com/

  2. Googleアカウントでログインした状態でGoogleドライブにアクセスすると次のような画面になります。
    ログインしてない場合はログインをしてください。
    (Googleアカウントをお持ちでない方は、新規にアカウントを作成してください)

  1. Google Colabを起動します

  1. コードセルもしくはテキストセルを追加し入力します

画面名称¶

セルには「コードセル」と「テキストセル」の2種類があります

  • コードセルにPythonのコードを書いて実行します。

  • テキストセル：Markdown記法で文章やコメントを入力します。Word等を同等に見出しをつけたり、画像を挿入したりすることが可能です

  • 青枠: ここをクリックすると逐次(ちくじ)空のコードセルまたはテキストセルが追加される

  • 赤枠： テキストセル

  • 緑枠： コードセル

コードセルの実行¶

ノートブックはセルから成り立っています。 主に次の二種類のセルを使います。

  • Codeセル（コードセル）： Pythonのコードが書かれたセルです。 Codeセルの左端には [ ] と表示されています。 Codeセルの中のコードを実行するには、 [ ] のところにマウスカーソルを移動してクリックします。 [ ] のところにマウスカーソルを移動すると、●の中に▷が表示されます。 これはプレイボタンを意味します。 プレイボタンを押すとコードが実行され、その結果がセルの下部に挿入されます。 （Shiftを押しながらEnterを押しても実行できます。）

  • Markdownセル（テキストセル）： 説明が書かれたセルです。 このセル自身はMarkdownセルです。

コードセルでPythonを実行する場合は、この実行マークをクリックする または セルを選択してから Shift+Enter します

  • セルの基本: Colabは「セル」という四角いブロックの集まりです。 テキストセル: 説明を書くためのブロックです。

  • コードセル: Pythonのプログラムを書いて実行するブロックです。

  • セルの実行: コードセルの左側にある「▶︎」ボタンを押すか、Shift + Enter を押すとプログラムが動きます！

下のコードセルを実行してみましょう！

# ここはコードセルです。「#」から始まる行は「コメント」と呼ばれ、プログラムには影響しません。
# メモ書きとして使います。

# カフェの売上を計算してみましょう！
coffee_price = 450  # コーヒー1杯の値段
sell_count = 10     # 売れた数

# 掛け算をして表示します
total_sales = coffee_price * sell_count
print("コーヒーの今日の売上は", total_sales, "円です！")

セルの編集¶

Codeセル上のプレイボタンでないところにマウスカーソルを移動しクリックすると、 Codeセルが選択され、文字カーソルが表示されて、セルの編集が可能になります。 Ctrlの付かない文字はそのまま挿入されます。

以下のような編集コマンドが使えます。

  • Ctrl+c: copy

  • Ctrl+x: cut

  • Ctrl+v: paste

  • Ctrl+z: undo

Codeセルが選択されているとき、Shift+Enter（もしくはShift+Return）を入力すると、 セルの中のコードが実行されて、次のセルが選択されます。

仮想環境のディレクトリ構造¶

セッションが多すぎますと表示される¶

Google Colabの実行ボタンを押すとセッションが多すぎますと表示されてしまう場合がある

その場合は、不要なセッションを閉じる必要がある

ダイアログの「セッションの管理」ボタンをクリックするか、「ランタイム」メニューをクリックし、「セッションの管理」を選択する

リストにある不要なノートブックを終了する

実行止まらないとき ＆ エラーが出た時¶

  • 実行が止まらない（ぐるぐる回り続けている）時：左上の「ランタイム」タブから「実行を中断」を押してください。

  • エラーが出た時：赤い文字で英語がたくさん出てくるとびっくりしますよね。でも大丈夫です！エラーは「ここがちょっとおかしいよ」というコンピュータからの優しいお知らせです。

    • 対処法: エラー文の一番下（SyntaxError など）をコピーして、生成AIやGoogle検索で調べてみましょう。「括弧を閉じ忘れてるよ」「全角スペースが混ざってるよ」といった原因がほとんどです。

  • Googleドライブから作成 Googleドライブの「新規」→「その他」から「Google Colaboratory」を選びます。（※メニューに出てこない場合は、「アプリを追加」から検索して追加してくださいね。）

  • 【重要】ランタイムが切れるとファイルが消える！ Colabは、Googleが無料で貸してくれている「クラウド上のパソコン（ランタイム）」で動いています。一定時間放置したり、接続を切ったりすると、アップロードしたファイルはリセットされて消えてしまいます。消えて困るファイルは、後で説明する「Google ドライブのマウント」という技を使って保存します。

その他の便利機能¶

  • セルの挿入: 画面上部の「+ コード」「+ テキスト」から追加できます。

  • ノートブックのダウンロード: 「ファイル」→「ダウンロード」から、.ipynb 形式で自分のPCに保存できます。

  • Google ドライブのマウント: 左側のフォルダアイコン📁を押し、「ドライブをマウント」のボタンを押すと、自分のGoogleドライブ内のファイルを読み書きできるようになります。

Markdown（マークダウン）とは何か？¶

今皆さんが読んでいるこの綺麗なテキスト、実は「Markdown」というルールで書かれています。 簡単な記号を使うだけで、文字を太くしたり、見出しを作ったりできます。

【Markdownの基本記法】

  • 見出し：文字の前に # をつける（# 大見出し, ## 中見出し）

  • 太字：文字を ** で囲む（**太字**）

  • リスト：行の先頭に - や * を置く

  • バックティック：`で囲むとコードっぽく表示される

Markdown（マークダウン）記法とは？¶

Markdown記法は、プレーンテキストで記述された文書を、構造化されたHTMLなどの形式に変換するための軽量マークアップ言語です。非常にシンプルで読みやすい記法でありながら、見出し、リスト、リンク、画像、コードブロックなど、一般的な文書に必要な要素を表現することができます。 Markdown記法は、技術文書の作成、ブログ記事の執筆、メモ、チャットなど、さまざまな場面で活用されています。

主な特徴は以下の通りです。

  • シンプルさ: 特殊なソフトウェアは不要で、テキストエディタで簡単に記述できます。

  • 可読性: プレーンテキストのままでも人間にとって読みやすいように設計されています。

  • 汎用性: Markdownで書かれたファイルは、様々なツールやプラットフォームでHTML、PDF、Wordなどの形式に変換できます。

  • 普及性: GitHub、Qiita、Slack、Jupyter Notebookなど、多くのWebサービスやアプリケーションで採用されています。

例：Markdownの基本的な書き方

  • 見出し:

    # 見出し1
## 見出し2
### 見出し3

  • 箇条書きリスト:

    - 項目1
- 項目2
  - サブ項目

  • 番号付きリスト:

    1. 項目A
2. 項目B

  • 強調（イタリック体と太字）:

    *イタリック体* または _イタリック体_
**太字** または __太字__

  • リンク:

    [Google](https://www.google.com/)

  • コードブロック:

    ```python
print("Hello, world!")

  • 画像:

    ![altテキスト](画像URL)

  • 引用:

    > これは引用です

MarkdownはJohn Gruber氏によって考案されたもので比較的シンプルなアイデアに基づいています。その為、多くの派生形や拡張機能があります。

Markdownの仕様¶

Markdownの公式仕様は、長年の間「正式な標準」が存在せず、複数の方言（GitHub Flavored Markdownなど）が存在しています．

標準的な仕様（CommonMark）¶

  • 名称：CommonMark（コモンマーク）

  • URL：https://commonmark.org/

  • 特徴：

    • Markdownを標準化しようとするプロジェクト

    • 明確な文法ルールとテストケースが定義されている

    • 多くのエディタやサービスでベースとして採用されている

    • 多くのMarkdownパーサー（MarkdownをHTMLなどに変換するプログラム）が準拠しています

GitHub Flavored Markdown（GFM）¶

  • 名称：GitHub Flavored Markdown

  • URL：https://github.github.com/gfm/

  • 特徴：

    • GitHubが独自に拡張したMarkdown仕様

    • CommonMarkをベースに、表（table）やチェックリスト、コードブロックの言語指定などの機能が追加されている

    • GitHubだけでなく、他の開発系ツールでも広く使われている

Original Markdown¶

  • 名称：Markdown: Syntax

  • URL：https://daringfireball.net/projects/markdown/ |

  • 特徴：

    • John Gruber氏が定義した最初の仕様

    • 公式サイト

    • 今では古典的

何を使えばいい？¶

  • 一般的な仕様を知りたい場合:

    • CommonMarkの仕様書を参照するのが最も適切です。

  • オリジナルのMarkdownについて知りたい場合:

    • John Gruber氏のMarkdown: Syntaxを参照します。

  • 特定のサービスやツールでのMarkdownの挙動を知りたい場合:

    • そのサービスやツールの公式ドキュメントを参照します。
