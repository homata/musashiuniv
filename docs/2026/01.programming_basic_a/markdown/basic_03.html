第3回 Pythonの基礎¶

「変数」や「関数」といった、少し数学っぽい言葉が出てきますが、構える必要は全くありません。
最初から全てを暗記しようとしなくて大丈夫です。「こういう書き方をするんだな」と考えるようにしてください

🎯 到達目標¶

  1. Pythonの基本ルール（インデント、コメントなど）を理解し、正しく書ける。

  2. 変数（データを入れる箱） と データ型（文字や数字の違い） を理解し、使い分けられる。

  3. 関数（自動計算の仕組み） を自作し、「print（画面に出す）」と「return（結果を返す）」の違いを説明できる。

  4. プログラム特有のエラーの読み方を知り、生成AIも活用しながら落ち着いて対処できる。

練習問題のGoogle Colab起動¶

  1. 上記の「Open In Colab」をクリックして、Google Colabを起動させてください

  2. [ファイル] → [ドライブにコピーを保存] を選択して、Googleドライブにコピーを保存してください

  3. 保存が成功すると，Googleドライブの「マイドライブ」 →「Colab Notebooks」にコピーしたファイルが保存されます。

  4. GoogleドライブにコピーしたGoogle ColabのNotebooksを開いてください

  5. 開いたGoogle ColabのNotebooksで作業をしてください

イントロダクション：Pythonを学ぶメリット¶

Pythonの概要と出来ること¶

Pythonは、世界中で最も人気のあるプログラミング言語の一つです。 AI（人工知能）の開発から、Webサイトの作成、そして**「データ分析」**まで、幅広い分野で活躍しています。

Pythonを学習するメリット¶

  1. 文法がシンプルで読み書きしやすい！ 英語を読むような感覚でコードが書けるため、初心者にもとても優しい言語です。

  2. データ分析の強力な味方（ライブラリ）が豊富！ エクセルでは処理しきれないような大量のデータ（数百万行の売上データなど）も、Pythonなら一瞬で集計・グラフ化できます。 これからの社会で「データから根拠を探る力」は、どんな職種でも最強の武器になります。

Pythonの種類について¶

実はPythonにはいくつかの「種類（実装や環境）」があります。

  • バージョン: 現在主流なのは「Python 3」です（古いPython 2はもう使われません）。

  • 環境/配布形態: 標準のPython（CPython）の他にも、データ分析に必要な道具が最初からセットになった「Anaconda（アナコンダ）」などがあります。

  • 👉 「Google Colab」は、データ分析に最適なPython3環境がすでに完璧に用意されています！

Hello World と Pythonの基本ルール¶

新しいプログラミング言語を学ぶとき、画面に「Hello World」と表示させるのが世界中のプログラマーの伝統です。
早速やってみましょう！

記念すべき最初のコード

print("Hello World!")

インデント（字下げ）とブロックを表す仕組み【超重要】¶

Pythonには「コードのまとまり（ブロック）」を表現するための、絶対に守らなければならないルールがあります。
それが**インデント（行の先頭の空白）**です。 他の言語では { } などの記号でまとめますが、Pythonは「見ための美しさ＝プログラムの構造」になります。

▼ 正しい例（インデントが揃っている）
スーパーに行く:
    りんごを買う   ← 4つの半角スペース（またはTabキー）で字下げ
    バナナを買う

▼ エラーになる例（インデントがバラバラ）
スーパーに行く:
りんごを買う       ← 字下げがない！コンピュータは「スーパーの中で買う」と認識できない
    バナナを買う

リテラルとオブジェクト¶

  • リテラル: プログラムの中に直接書き込まれた「データそのもの」のことです。（例：450 という数字や、"カフェ" という文字）

  • オブジェクト: Pythonの世界では、数字も文字もすべて「オブジェクト（モノ）」として扱われます。今は「データには色々な種類があるんだな」くらいの認識でOKです。

コメントと空行¶

  • # から始まる行はコメントと呼ばれ、プログラムとして実行されません。自分や他の人が読んだときの「メモ書き」としてどんどん使いましょう。

  • コードとコードの間の「空行」は、読みやすくするために自由に入れてOKです。

行の先頭のコメント

# これはコメント

行の途中のコメント

print("Hello World!")　　# これもコメント

「複数行単位」のコメントアウトは、'''（シングルクォート3つ）または"""（ダブルクォート3つ）で囲事でみます

'''
これはクラス、メソッドの機能の複数行による説明
変数の役割などを明記
'''

"""
同様にダブルクォートを使った複数行コメントも可能
クラス、メソッドの説明に利用
"""

変数（へんすう）の基礎¶

変数とは？¶

変数とは、データを入れておく**「名前（ラベル）のついた箱」**のことです。

 📦 箱（変数名: coffee_price）
 [  450  ]  ◀━ 中身（データ：リテラル）

数学の変数（x や y）とは少し違い、**「右側のデータを、左側の箱に入れる（代入する）」**という意味になります。 coffee_price = 450 （※「等しい」ではなく「入れる」です！）

データ型（箱の中身の種類）¶

箱に入れるデータには「種類（型）」があります。代表的な4つを覚えましょう！

データ型

意味

例

用途・特徴

int (整数)

小数点のない数字

450, -10

個数や金額の計算

float (実数)

小数点のある数字

1.1, 3.14

消費税率や平均値の計算

str (文字列)

文字（クォーテーションで囲む）

"コーヒー", 'A'

名前やメッセージ。計算不可

bool (真偽値)

正しいか、間違っているか

True, False

条件分岐（もし〜なら）で使用

 
# 変数とデータ型の確認をしてみましょう

item_name = "抹茶ラテ"  # str（文字列）: 記号(" ")で囲む必要があります！
price = 550             # int（整数）: 記号は不要です
tax_rate = 0.1          # float（実数）
is_hot = True           # bool（真偽値）: 最初のTやFは大文字です

print(item_name, "の値段は", price, "円です。")

# 型変換（キャスト）：データの種類を変換することもできます。
# 例えば、数字の 550 を、文字の "550" に変換するには str() を使います。
price_str = str(price)
print("文字列になった値段: " + price_str) # 文字同士なら + 記号で繋げられます！

変数と関数の基礎¶

関数（かんすう）とは？¶

関数とは、よく使う一連の処理をまとめた**「自動計算機（レシピ）」**のようなものです。
今まで使ってきた print() も、Pythonが最初から用意してくれている「組み込み関数」の一つです。

自分だけのオリジナルの関数を作るには、def（define：定義する）を使います。

[ 材料 (引数: ひきすう) ] 
       │
       ▼
┏━━━━━━━━━━━━━━━━━━━━┓
┃  関数 (自動計算機)  ┃ ◀━ 中で処理（計算）をする
┗━━━━━━━━━━━━━━━━━━━━┛
       │
       ▼
[ 完成品 (返値: return) ]

print と return の違い【重要】¶

ここ、多くの人が最初につまずくポイントです！

  • print (画面への表示): 計算結果を「画面に映し出して人間が見る」ためのもの。データとしては残りません。

  • return (返値 / 戻り値): 計算結果を「関数の外にデータとして返す」もの。返ってきたデータを別の変数に入れたり、次の計算に使ったりできます。

ローカル変数とグローバル変数（スコープ）¶

  • ローカル変数: 関数の中だけで使える「一時的な箱」。関数の外（キッチンから出た後）では消えてしまいます。

  • グローバル変数: プログラムのどこからでも使える「共通の箱」。

実際にコードを見てみましょう！

# 税込み価格を計算するオリジナル関数を定義（def）します！

def calc_tax(price):
    # ここからインデントを下げてブロックを作ります
    tax = 0.1  # taxは、この関数の中でしか使えないローカル変数です
    total = price * (1 + tax)
    
    # 計算結果（完成品）を関数の外に返します！(return)
    return total

# ------------------------------
# ここから関数の外（インデントなし）です

# 関数を呼び出して（材料として 400 を渡す）、結果を変数に入れます
coffee_total = calc_tax(400)
cake_total = calc_tax(500)

print("コーヒーの税込み価格は", coffee_total, "円です。")
print("ケーキの税込み価格は", cake_total, "円です。")

# （補足）関数の参照
# 括弧 () をつけずに関数名だけを変数に入れると、関数そのものに別名をつけることができます。
my_calculator = calc_tax
print("別名で計算:", my_calculator(1000))

📚 第3回のまとめ¶

✨ 今日の重要ポイントまとめ¶

  • インデント: Pythonは「見ための字下げ（空白）」でブロックを認識します。エラーが出たらまず行の先頭をチェック！

  • 変数とデータ型: 文字（str）や数字（int, float）は混ぜて計算できません。必要に応じて str() などで型変換しましょう。

  • 関数: def でオリジナルの処理をまとめることができます。

  • return と print: print はただの「表示」。後でデータとして使いたい時は return で「返す」！

❓ よくある質問と回答 (FAQ)¶

  • Q. TypeError: can only concatenate str (not "int") to str というエラーが出ました...

    • A. 文字列（str）と数字（int）を + でくっつけようとしていませんか？ 演習2のように、数字を str() で囲んで文字に変換してあげると解決しますよ。

  • Q. インデントは全角スペースでもいいですか？

    • A. 絶対にダメです！ 全角スペースはコンピュータにとって「謎の見えない文字」として扱われ、エラーの原因になります。必ず「半角スペース」か「Tabキー」を使ってください。

🌟 Colabで試すおすすめコード¶

今日学んだ関数を使って、自分だけの「BMI（肥満度）計算ツール」を作ってみましょう。体重と身長の数値を変えて実行してみてください。

# BMI（肥満度）を計算する関数です
def calculate_bmi(weight_kg, height_m):
    # BMI = 体重(kg) ÷ (身長(m) × 身長(m))
    bmi = weight_kg / (height_m * height_m)
    return bmi

# 自分のデータを入れてみましょう（身長はセンチではなくメートルです！）
my_weight = 60.0
my_height = 1.70

my_bmi = calculate_bmi(my_weight, my_height)
print("あなたのBMIは", my_bmi, "です！")
