第4回 数値演算と文字列¶

データ分析の現場で最もよく使う2つのデータ、「数値（数字）」と「文字列（テキスト）」の扱い方をマスターします。 「インデックス」や「スライス」など新しい概念が登場します。
特に「文字列の処理」は、アンケート結果などの文字データを分析しやすく綺麗にする（データクレンジング）ための必須スキルです。

🎯 到達目標¶

  1. 様々な数値演算子（割り算の余りなど）を使って、目的に合った計算ができる。

  2. モジュール（拡張機能）を読み込み、高度な数学関数を使えるようになる。

  3. 文字列のインデックスとスライスを理解し、文字データの一部を自由に切り取れる。

  4. 初心者が最も陥りやすい 「変数」と「文字列」の混同 を見分け、エラーを解決できる。

イントロダクション：データと変数の基礎¶

データ分析を行うためには、まず「データ（食材）」を変数（箱）に入れ、それを正しく処理する必要があります。

  • 数値（int, float）: 売上金額、顧客の年齢、気温など。「計算」するためのデータです。

  • 文字列（str）: 商品名、顧客の感想、店舗名など。「テキスト分析」や「分類」をするためのデータです。

Pythonは、この2つを厳密に区別します。数字の 450 は足し算ができますが、文字の "450" は「よん・ごー・ぜろ」という記号の集まりとして扱われるため、そのままでは計算できません。 今日はこの2つのデータを自由自在に操る魔法を学んでいきましょう！

演算子の優先順位と括弧、そして空白¶

数学と同じように、掛け算・割り算は、足し算・引き算より先に計算されます。 順番を変えたい時は ( ) 括弧を使います。 また、計算式を見やすくするために、記号の前後には**空白（半角スペース）**を入れるのが美しい書き方（コーディング規約）とされています。

# 簡単な算術計算と優先順位の確認
# 400円のコーヒーと300円のクッキーを買い、100円引きクーポンを使いました。

# 悪い例：読みにくい（空白がない）
total1=400+300-100

# 良い例：読みやすい（空白がある）
total2 = 400 + 300 - 100 

print("合計金額:", total2)

# 括弧を使った優先順位の変更
# 3人でカフェに行き、各自が400円と300円のものを頼みました
wrong_calc = 400 + 300 * 3    # 300*3が先に計算されてしまう（400 + 900 = 1300）
correct_calc = (400 + 300) * 3 # 括弧の中が先に計算される（700 * 3 = 2100）

print("間違った計算:", wrong_calc)
print("正しい計算:", correct_calc)

エラーに気をつけよう¶

プログラミング特有のエラーがあります。代表的なのが「ゼロ除算（0で割る）」です。 数学のルールとして0で割ることはできないため、Pythonでも ZeroDivisionError というエラーが出ます。データ分析で「来店者数0人」の日の平均売上を出そうとすると発生しやすいので注意しましょう。

数学関数（モジュールのインポート）¶

Pythonには、基本的な計算だけでなく、高度な数学の計算をするための「追加パック（モジュール）」が用意されています。これを使うには import（インポート：取り込む）という宣言をします。

モジュールの使用

# 数学関数が入っている「math（マス）」モジュールを取り込みます
import math

# 小数点以下を「切り上げ」る関数 math.ceil()
# 例：ポイント還元で 1.2 ポイントの時は 2 ポイントに切り上げる
points = math.ceil(1.2)
print("切り上げポイント:", points)

# 小数点以下を「切り捨て」る関数 math.floor()
price = math.floor(450.9)
print("切り捨て価格:", price)

文字列とインデックス¶

Pythonの世界では、文字列は「文字が順番に並んだ列車の車両」のように扱われます。 それぞれの文字には**「インデックス（番号）」**が振られていますが、

ここで最大の注意点！ コンピュータは「0」から数字を数え始めます！

【インデックスの図解】 「ＣＡＦＥ」という文字があった場合…

  先頭から数える ──▶   0    1    2    3
                    [ C ][ A ][ F ][ E ]
  後ろから数える ◀──  -4   -3   -2   -1

最初の「C」を取り出したければ、0番目を指定します。一番後ろの「E」は -1 で取り出せます。

文字列とスライス¶

文字の「一部を切り取る」ことをスライスと呼びます。
文字列[開始 : 終了] と書きますが、
**「終了の番号は含まれない（その手前まで）」**というルールがあります。

Pythonのスライス（slice）は、リストや文字列、タプルなどのシーケンス（配列）から、指定した範囲の要素を簡単に切り出す機能です

【スライスの図解】

  [ C ][ A ][ F ][ E ]
  0    1    2    3    4  (文字の隙間に番号があるイメージを持つと分かりやすいです)
  ↑         ↑
  ここから、ここまで（2は含まない） ＝ [0:2] ＝ "CA"

スライス式

word1 = 'hello'
word1[0] = 'H'
word1[-1]

a = 'Python' 
a[1:3]
a = (0, 1, 2, 3, 4) 
a[2:5]

a = 'Python' 
a[:3]
a = (0, 1, 2, 3, 4) 
a[2:]

まとめると文字列 hello の正負のインデックスは以下の表の関係になります。

インデックス h e l l o
0か正 0 1 2 3 4
負 -5 -4 -3 -2 -1

スライスを全て記述すると [ 開始位置 : 終了位置 : ステップ ] の形で指定します。

  • start（開始位置）: 取得を開始するインデックス（含める）。

  • stop（終了位置）: 取得を終了するインデックス（含めない）。

  • step（ステップ）: 何個ごとにとばして取得するか（省略可能）。

開始位置:終了位置:ステップは省略も可能です

最初から指定位置まで [:stop]

numbers[:4]

指定位置から最後まで [start:]

numbers[5:]

全体のコピー [:]

numbers[:]

マイナス（負の数）指定 [-位置:]
後ろから数えた位置を指定できます（一番後ろの要素が -1）

numbers[-3:]  # 後ろから3番目から最後まで

ステップ（飛ばし読み） [start : stop : step]

numbers[1:8:2]  # 2マスずつ進む（1つ飛ばし）
numbers[::2]    # リスト全体から偶数インデックスだけ取得

リストの逆順（反転） [::-1]
ステップに -1 を指定すると、要素を後ろから逆順に取得できます。

numbers[::-1]

取得したい部分文字列の先頭の文字のインデックスと最後の文字のインデックスに 1 を加えた値を指定します。
たとえば、ある文字列の2番目の文字から4番目までの文字の部分文字列を得るには次のようにします。

digits1='0123456789'
digits1[1:4]

文字列の先頭（すなわち、インデックスが 0 の文字）を指定する場合、次のように行えます。

digits1[0:3]

最初の 0 は省略しても同じ結果となります。

digits1[:3]

最後尾の文字のインデックスも、値を省略することもできます。

digits1[3:]
digits1[3:5]

負数を指定して、 文字列の最後の方から部分文字列を取得できます

digits1[-4:-1]

スライスでは3番目の値を指定することで、とびとびの文字を指定できます。
次のように digits1[3:9:2] と指定すると、インデックス 3 から2文字おきにインデックス 9 より小さい文字を並べた部分文字列を得ます。

digits1[3:9:2]

3番目の値に -1 を指定することもできます。これを使えば元の文字列の逆向きの文字列を得ることができます。

digits1[8:4:-1]

練習

shop_name = "ムサシ・カフェ"

# インデックス（1文字だけ取り出す）
# 0から数えるので、3番目は「シ」ではなく「・」になります！
print("0番目の文字:", shop_name[0])  
print("3番目の文字:", shop_name[3])  
print("最後の文字:", shop_name[-1]) 

# スライス（範囲を切り出す）
# 0番目から4番目の「手前（3番目）」まで切り出す
print("0から4番目の手前まで:", shop_name[0:4]) 

# 開始や終了を省略すると、「一番最初から」「一番最後まで」という意味になります
print("最初から3番目の手前まで:", shop_name[:3]) 
print("4番目から最後まで:", shop_name[4:])

空文字列（から・もじれつ）¶

文字が何も入っていない文字列 "" のことを空文字列と呼びます。データの中で「欠損（データがない）」状態を表す時や、文字を消去したい時によく使います。

シングルクォート（もしくはダブルクォート）で、何も囲まない場合、長さ 0 の文字列（空文字列（くうもじれつ）もしくは、空列（くうれつ））となります。 具体的には、下記のように使用します。

blank = ''

空文字列は、次のように、たとえば文字列中からある部分文字列を取り除くのに使用できます

price = '2,980円'
price.replace(',', '')

文字列のスライスにおいて、指定したインデックスの範囲に文字列が存在しない場合、 たとえば、最初に指定したインデックス x に対して、 2番目のインデックスの値に x 以下のインデックスの値を指定するとどうなるでしょうか？ （ただし、2つのインデックスは同じ符号を持つとし、スライスの3番目の値は用いないとします。） このような場合、結果は次のように空文字列となります（エラーが出たり、結果が None にはならないことに注意してください）。

digits1='0123456789'
print('空文字列1 = ', digits1[4:2])
print('空文字列2 = ', digits1[-1:-4])
print('空文字列3 = ', digits1[3:3])
print('空文字列ではない = ', digits1[3:-1])

文字列の連結とエスケープシーケンス¶

  • 連結: 文字列同士は + でくっつけることができます。

  • エスケープシーケンス: 改行などを表現するための特別な記号です。\n（バックスラッシュとn）と書くと、そこで文字が改行されます。Macの方は Option + ¥ で \ を打てます

# 文字列の連結
greeting = "こんにちは！"
customer = "山田さん"
print(greeting + customer) # こんにちは！山田さん

# エスケープシーケンス（\n で改行）
receipt = "コーヒー：400円\nケーキ：500円\n合計：900円"
print(receipt)

文字列の検索と比較¶

  • 検索: in を使うと、その文字が含まれているか（True/False）を判定できます。

  • 比較演算: == (等しい)、!= (等しくない) を使って文字列が一致するか調べます。

# 検索（in）
menu = "濃厚抹茶フラペチーノ"
print("「抹茶」は含まれている？:", "抹茶" in menu) 

# 比較（==）
password = "open"
print("パスワードは正しい？:", password == "open")

比較演算子、==, <, > などを用いて、2つの文字列を比較することもできます。

print('abc' == 'abc')
print('ab' == 'abc')

print('abc' != 'abc')
print('ab' != 'abc')

文字列の大小の比較は、いわゆる辞書式による比較で、文字列の最初の文字から順に比較して大小を決めます。 片方がもう片方を拡張したものであれば、拡張した方を大きいとします。

print('abc' <= 'abc')
print('abc' < 'abc')
print('abc' < 'abd')
print('ab' < 'abc')

文字列のメソッド（便利ツール）¶

文字列データには、自分自身を加工する便利なツール（メソッド）がくっついています。 文字列.メソッド名() の形で使います。

text = "  Cafe Musashi  "

# upper(): すべて大文字にする
print("大文字:", text.upper())

# replace(): 文字を置き換える（データクレンジングで超頻出！）
print("置換:", text.replace("Musashi", "Tokyo"))

# strip(): 前後の不要な空白を削除する
print("空白削除:[", text.strip(), "]")

🚨 初心者によくある誤解 — 「変数」と「文字列」の混乱 (超重要！)¶

初心者の皆さんが最初によくやってしまう、そしてパニックになりやすい間違いがこれです。

  • "coffee" ＝ クォーテーションで囲まれている。これは**「文字列（ただの文字）」**です。

  • coffee ＝ クォーテーションがない。これは**「変数（データが入った箱の名前）」**です。

drink = "コーヒー"  # 変数 drink に 文字列 "コーヒー" を入れた

print("drink")    # ← 画面には「drink」という文字がそのまま出る！
print(drink)      # ← 画面には箱の中身の「コーヒー」が出る！

エラー（NameError: name 'xxx' is not defined）が出た時は、「文字として書きたかったのに、クォーテーションを付け忘れて『変数』として扱われていないか？」を必ずチェックしてください！

負のインデックスを使うと末尾から数えられます。[-1] で最後の文字を指定できます。
[-1:] と書くと「最後の1文字から最後まで」という意味になります。

text = "Python"
print(text[-1:])  # または text[-1]

練習問題 2 （基礎：範囲指定）

文字列 text = "Hello World" から、"World" の部分だけを取り出してください。
👉 解答例を見る（ここをクリックして展開）

練習問題 2（解答）

"W" はインデックス 6 です。stop（終了位置）を省略して [6:] と書くことで、

text = "Hello World"
print(text[6:])  # または text[6:11]

練習問題 3 （応用：1文字飛ばし）

text = "A1B2C3D4E5"
print(text[0::2])  # または text[::2]

text = "strawberry"

練習問題 (スライス深掘り)¶

練習問題 1 （範囲の含み方）

文字列 text = "0123456789" があります。
text[2:6] を実行したとき、出力される文字列は何でしょうか？
（※インデックスの「終了位置」がどう扱われるかがポイントです）
👉 解答例を見る（ここをクリックして展開）

練習問題 1（解答）

スライスでは 開始 の位置（インデックス2 → "2"）は含まれますが、終了 の位置（インデックス6 → "6"）は
含まれません（その手前まで）。
そのため、インデックス 2, 3, 4, 5 の要素である "2345" が取り出されます。

text = "0123456789"
print(text[2:6])  # "2345"

正解："2345"

練習問題 2 （負のステップと開始・終了）

文字列 text = "ABCDEFG" があります。
text[5:1:-1] を実行したときに取得できる文字列は何でしょうか？
👉 解答例を見る（ここをクリックして展開）

練習問題 2（解答）

ステップがマイナス（-1）のときは、右から左（後ろから前） へ移動します。  
　開始: インデックス5 ("F")  
　終了: インデックス1 ("B") の手前（＝インデックス2 の "C" まで）  
したがって、F → E → D → C の順で取り出されます。  

text = "ABCDEFG"
print(text[5:1:-1])  # "FEDC"

正解："FEDC"

練習問題 3 （逆順での1文字飛ばし）

文字列 text = "123456789" があります。
スライスを使って、奇数を大きい順に並べた "97531" を取り出してください。
👉 解答例を見る（ここをクリックして展開）

練習問題 3（解答）

開始・終了を省略すると、文字列全体が対象になります。
ステップに -2 を指定することで、「末尾（"9"）から左に向かって2文字ずつ移動」します。
結果として "9", "7", "5", "3", "1" が順番に拾われます。

text = "123456789"
print(text[::-2])  # "97531"

練習問題 4 （範囲外のインデックス）

文字列 text = "Python" があります。
文字列の長さは6文字（インデックス 0〜5）ですが、あえて範囲を超える text[2:100] を実行するとどうなるでしょうか？
（A〜Cから選んでください）

A) エラー（IndexError）になる
B) "thon" が取得できる
C) None が返ってくる
👉 解答例を見る（ここをクリックして展開）

練習問題 4（解答）

通常、text[100] のように直接インデックスを指定すると IndexError になりますが、　　
スライス操作では自動的に文字列の末尾（または先頭）で調整されます。エラーにはならず、
安全に取れる範囲（インデックス2から最後まで）が返ってきます。

text = "Python"
print(text[2:100])  # "thon"

正解：B ("thon")

練習問題 5 （回文判定のロジック）

与えられた文字列が、上から読んでも下から読んでも同じ「回文（かいぶん）」かどうかを
判定する関数 is_palindrome(word) を作成してください。
スライスを活用して 1行 で True か False を返すように書いてみましょう。
👉 解答例を見る（ここをクリックして展開）

練習問題 5（解答）

word[::-1] で「元の文字列を反転した文字列」を作ることができます。  
元の文字列 word と反転した文字列を == で比較するだけで、1行で回文判定が完成します！

def is_palindrome(word):
    return word == word[::-1]

# テスト
print(is_palindrome("toyo"))  # False
print(is_palindrome("しんぶんし"))  # True

※ palindrome（パリンドローム）とは、前から読んでも後ろから読んでも同じになる言葉や数字のこと

📚 第4回のまとめ¶

計算と文字操作の基礎を学びました。どちらもデータ分析を行う上で避けては通れない、非常に強力な道具です。

✨ 今日の重要ポイントまとめ¶

  • 算術演算子: + - * / に加えて、商を出す // や、余りを出す % も便利！

  • インデックス: プログラミングの世界では**「0番目」から数え始める**のが鉄則。

  • スライス: [開始:終了] で切り出す時、終了の番号は含まれない点に注意。

  • 変数と文字列の違い: クォーテーション "" の付け忘れに注意！無いと「変数（箱）」だと勘違いされてエラーになります。

❓ よくある質問と回答 (FAQ)¶

  • Q. スライスで IndexError: string index out of range というエラーが出ました。

    • A. 文字列の長さよりも大きいインデックス（番号）を指定しようとしています。「CAFE」は4文字ですが、一番最後は「3番目」です。「4番目」を指定すると、列車がないためエラーになります。0から数えるルールを思い出してくださいね！

  • Q. 文字列に + 以外の掛け算などはできますか？

    • A. 実はできます！ "カフェ" * 3 とすると "カフェカフェカフェ" になります。ただし、引き算や割り算はできません（エラーになります）。
