第6回 条件分岐、ファイル入出力の基本¶

いよいよ**「プログラムに自分で判断させる力（条件分岐）」と、「自分のパソコンにある外部データを読み込む力（ファイル入出力）」**を身につけます。 この2つが使えるようになると、「数万行の売上データ（ファイル）を読み込んで、雨の日のデータ（条件）だけを抽出して計算する」といった、本格的なデータ分析の自動化ができるようになります。

🎯 到達目標¶

  1. if / elif / else 文 を使って、条件によって異なる処理を行うプログラムを作れる。

  2. 論理演算子 (and, or, not) や比較演算子を用いて、複雑な条件式を作れる。

  3. ファイル入出力 (with文) を使って、外部データの読み込みや書き込みができる。

  4. ファイル読み込み時の文字コード指定や、不要な改行文字の削除など、データ分析の下準備（前処理）ができる。

イントロダクション：プログラムに「判断」と「記憶」をさせよう¶

これまで私たちが書いてきたプログラムは、上から下へ「一直線」に進むだけでした。しかし、実際のカフェの業務やデータ分析では、条件によって対応を変える必要があります。

  • 条件分岐（if文）: 「もしお客様が会員なら、5%割引にする」「もし気温が30度以上なら、アイスコーヒーの売上としてカウントする」といった判断の分かれ道を作ります。

  • ファイル入出力: これまでは毎回コードの中にデータを直接書き込んでいましたが、現実のデータはExcelやテキストファイルとして存在します。それをPythonの世界に**「読み込み（インプット）」、分析結果をファイルとして「書き出す（アウトプット）」**方法を学びます。

条件分岐（if文）と論理・比較演算¶

if / elif / else による条件分岐¶

Pythonでは、if（もし〜なら）というキーワードを使って条件分岐を書きます。 ポイントは、第3回で学んだ**インデント（字下げ）**です！条件に当てはまった時だけ実行したい処理は、必ずインデントを下げて書きます。

【条件分岐のイメージ図】

          [スタート：お会計]
                  │
      ╭───── (if: 会員ですか？) ─────╮
   【Yes】                        【No】
      │                             │
 [ 5%割引！ ]              [ 割引なし（通常価格）]
      │                             │
      ╰─────────── v ───────────────╯
                  │
           [エンド：お支払い]

# 基本的な if / else 文
is_member = True  # 会員かどうか（True または False）
price = 1000

if is_member:
    # ここは is_member が True の時だけ実行されます
    print("会員様ですね。50円割引します！")
    price = price - 50
else:
    # それ以外の時（False の時）はここが実行されます
    print("一般のお客様ですね。通常価格です。")

print("お会計は", price, "円です。")

様々な条件（比較演算子）¶

数値の大小などを比べるための記号です。

  • A == B : AとBは等しい（※ = が2つなことに注意！1つは代入です）

  • A != B : AとBは等しくない

  • A > B : AはBより大きい

  • A >= B : AはB以上（含む）

3つ以上の分岐（elif）¶

「もし〜なら、そうでなくて〜なら、それ以外は」というように、複数の条件を繋ぐには elif (else if の略) を使います。

    print("夏日です。アイスコーヒーがよく売れそうです。")
else:
    print("涼しいです。ホットコーヒーの準備をしましょう。")

論理演算子（and, or, not）で条件を組み合わせる¶

データ分析では、「20代」かつ「女性」のデータを抽出したい！といった場面がよくあります。

  • A and B（かつ）: AもBも両方TrueならTrue

  • A or B（または）: AかBのどちらかがTrueならTrue

  • not A（〜ではない）: AがFalseならTrueになる（ひっくり返す）

真理値を返す関数、オブジェクト、None、条件として使われる他の値¶

  • 真理値を返す関数: is_member() のように、呼び出すと True か False を返す関数を作ることができます。

  • None（ノン）: 「データが空っぽ（何もない）」ことを表す特別なオブジェクトです。データ分析の欠損値処理などで活躍します。

ファイル入出力と文字列操作¶

ここからは、Pythonに外部のテキストファイルを読み込ませる方法です。

テキストファイルとバイナリファイル¶

テキストファイルとバイナリファイルは、「データを人間が直接読める形式で保存しているか、コンピュータが効率よく処理できる形式で保存しているか」という違いがあります。

一番大きな違いは「メモ帳などのテキストエディタで開いたときに、意味のある文字として読めるかどうか」です。

主な違いの比較¶

項目

テキストファイル

バイナリファイル

中身のデータ

文字コード（UTF-8など）で変換された「文字」

0と1のデータ（バイナリ）そのもの

メモ帳で開くと

読める（意味のある文章が表示される）

文字化けする（記号や乱数が並ぶ）

主な用途

ソースコード、設定ファイル、メモ

画像、音声、動画、実行ファイル（.exe）

データの構造

行ごとに「改行コード」が入る

決まったデータ構造（ヘッダー情報など）を持つ

主な拡張子

.txt, .py, .html, .json, .csv

.png, .jpg, .mp3, .mp4, .pdf, .exe

わかりやすいイメージ¶

テキストファイル¶

  • 人が読める文章

  • 文字データだけで構成されています。

  • メモ帳やVS Codeなどで開くだけで、誰でも内容を理解・編集できます。

バイナリファイル¶

  • コンピュータ用のデータ

  • 画像のピクセル情報や、音の波形データ、プログラムの実行命令などが効率的な配置で詰め込まれています。

  • 文字として表示できないため、メモ帳で無理やり開くと「文字化け（ぐちゃぐちゃの表示）」になります。専用のアプリ（画像閲覧ソフトや音楽プレイヤーなど）を使って読み込みます。

テキストファイル¶

ファイルとは？ ファイルのオープンとクローズ¶

パソコンの中にあるデータは、本棚の本のようなものです。 読むためには、**「開く（オープン）」し、読み終わったら「閉じる（クローズ）」**必要があります。閉じ忘れると、他のアプリがそのファイルを触れなくなったり、パソコンのメモリを無駄遣いしてしまいます（これが「編集中のファイルの動作」の問題です）。

open と with 文¶

昔は手動で f.close() と書いて閉じていましたが、今は**with 文という便利な書き方があります。これは「処理が終わったら自動でファイルを閉じてくれる自動ドア」**のようなものです。絶対に with 文を使いましょう！

【with文のイメージ図】

 🚪 [ 自動ドア (with open...) ] ──╮ 
 │                                │ インデントが下がっている間だけ、
 │  ファイルの中身を読み書きする    │ ファイルが開いた状態になる
 │                               │
 ╰── (インデントが終わると自動でドアが閉まる！)

ファイルの読み込み

with文を使ったファイルの読み込み

ファイルの読み書きにおける文字コード指定¶

ファイルを読み込む時、Pythonに「このファイルは UTF-8 という言語で書かれているよ」と教えてあげる必要があります。これを忘れると、文字化けやエラー（UnicodeDecodeError）の原因になります。

# （準備）Colabの仮想環境に、練習用のテキストファイルを作成します。
# 以下のコードを実行して、"sales_memo.txt" というファイルを作ってください。

sample_text = "コーヒー,450\nケーキ,500\n紅茶,400\n"
with open("sales_memo.txt", "w", encoding="utf-8") as f:
    f.write(sample_text)

print("練習用ファイルを作成しました！")

ファイルの読み込み（行の読み込み、全体の読み込み）¶

  • f.read() : ファイル全体を一気に1つの文字列として読み込みます。

  • f.readlines() : ファイルを1行ずつリストにして読み込みます。

ファイルを1行ずつ読む

改行文字の削除と文字列メソッド¶

ファイルを読み込むと、行の終わりに「目に見えない改行マーク (\n)」がくっついてきます。 データ分析ではこれが非常に邪魔になるため、第4回で学んだ文字列メソッド strip()（前後の空白や改行を消す）を使って掃除（データクレンジング）をするのが鉄則です！

# with文を使ったファイルの読み込み（"r" は読み込み専用という意味です）
with open("sales_memo.txt", "r", encoding="utf-8") as f:
    # readlines() で1行ずつリストにして読み込む
    lines = f.readlines()

print("▼ 読み込んだ生のデータ（改行記号 \\n がついている）")
print(lines)

print("\n▼ データクレンジング後")
# リストから最初の1行目（インデックス0）を取り出す
first_line = lines

# strip() メソッドで不要な改行記号を削除し、split(",") でリストに分割する！
clean_data = first_line.strip().split(",")
print(clean_data)

ファイルへの書き込み¶

新しくファイルを作ったり、結果を保存したりするには、モードを "w" (write: 上書き) または "a" (append: 追記) にして開きます。

テキストファイルの書き出し

f = open(ファイルパス, 'w', encoding='UTF-8')
    for i in range(0,100):
        f.write(str(i) + '¥n')  # <-- 改行も書き出す必要がある

close(f) # <-- close()を呼び出す必要がある

with文を使う場合

with open(ファイルパス, 'w', encoding='UTF-8') as f:
    for i in range(0,100):
        f.write(str(i) + '¥n') # <-- 改行も書き出す必要がある

# close()を呼ばなくてOK

"a" モード

# "a" モードで開いて、新しいデータを一番下に追加します
with open("sales_memo.txt", "a", encoding="utf-8") as f:
    f.write("抹茶ラテ,550\n") # \n（改行）を忘れずに入れる！

print("新しいメニューをファイルに書き込みました！")
# ※画面左側のフォルダアイコン📁を開くと、「sales_memo.txt」があるのが確認できます。

ファイルの読み書き with文を使って、出力先のファイルと読み込むファイルの両方を開く 入力ファイルを1行ずつ読み込み、'東京都'という文字列が含まれる場合は出力ファイルに書き出す

with open(出力ファイルのパス, 'w', encoding='UTF-8') as out_f:
    with open(入力ファイルのパス, 'r', encoding='UTF-8') as in_f:
        for line in in_f:
            if '東京都' in line:
                out_f.write(line)

Pythonでのテキストファイルとバイナリファイルの扱い方¶

Pythonなどのプログラミング言語でファイルを扱う際も、読み書きのモードを使い分けます。

# --- テキストファイルの読み込み ---
# 'r' (read) モードを使用。自動的に文字として読み込まれる
with open("example.txt", "r", encoding="utf-8") as f:
    text_content = f.read()
    print(text_content)  # "こんにちは" などの文字列が出力される


# --- バイナリファイルの読み込み ---
# 'rb' (read binary) モードを使用。生データのバイト列として読み込む
with open("sample_image.png", "rb") as f:
    binary_content = f.read()
    print(binary_content[:10])  # b'\x89PNG\r\n\x1a\n...' のようにバイト列が表示される

💡 ポイント CSV や JSON は数字やデータが入っていますが、テキストエディタで開いて読めるためテキストファイルに分類されます。一方で、Excel(.xlsx) や Word(.docx) は装飾情報や構造データが特殊な形式で圧縮されて入っているため、バイナリファイルです。

✨ 今日の重要ポイントまとめ¶

  • if / elif / else: インデントを使って、条件ごとに処理を分けることができる。

  • 比較演算子と論理演算子: ==, >=, and, or を使って、複雑な抽出条件を作る。

  • with open(): ファイルを読み書きする時は、閉じ忘れを防ぐ「自動ドア」の with 文を使う。

  • 文字コードと改行: 読み込む時は encoding="utf-8" を指定し、読み込んだ文字列は strip() で綺麗にする（データクレンジング）。

❓ よくある質問と回答 (FAQ)¶

  • Q. SyntaxError: expected ':' というエラーが出ました。

    • A. 文系学生がif文で一番よくやるミスです！ if や elif, else, そして with の行の最後には、必ずコロン（:）が必要です。コロンを忘れていないかチェックしてください。

  • Q. FileNotFoundError: [Errno 2] No such file or directory というエラーが出ました。

    • A. 「そんな名前のファイルは見つからないよ！」というエラーです。ファイル名のスペルミスがないか、あるいは「読み込む前に、ちゃんとファイルを作成（アップロード）しているか」を確認しましょう。Colabでは左側のフォルダアイコンから確認できます。

  • Q. Macで作ったファイルを読み込むとエラーになります…。

    • A. 文字コードの問題かもしれません。MacやWindowsによって標準の文字コードが違うことがあるため、open() の中に必ず encoding="utf-8" を入れるクセをつけておくと安心です。

🌟 Colabで試すおすすめコード¶

今日学んだことを全て組み合わせた「売上データの自動集計プログラム」です。 ファイルからデータを読み込み、コーヒーの売上だけを合算します。

# （準備）売上データファイルを作成します
with open("daily_sales.txt", "w", encoding="utf-8") as f:
    f.write("コーヒー,450\nケーキ,500\nコーヒー,450\n紅茶,400\n")

# コーヒーだけの売上合計を入れる箱
coffee_total = 0

# ファイルを読み込みます
with open("daily_sales.txt", "r", encoding="utf-8") as f:
    lines = f.readlines() # 1行ずつリストにする

# まだ学んでいませんが、次回詳しくやる for文（繰り返し）を使います！
for line in lines:
    clean_line = line.strip()       # 1. 改行などのゴミを消す
    data_list = clean_line.split(",") # 2. カンマで区切ってリストにする
    
    item_name = data_list # 商品名
    item_price = int(data_list) # 値段（計算したいので int で数値に変換！）
    
    # 3. もし商品名がコーヒーなら、合計に足す！
    if item_name == "コーヒー":
        coffee_total = coffee_total + item_price

print("本日のコーヒーの売上合計は", coffee_total, "円です！")
