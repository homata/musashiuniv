第5回 データ構造（数値、文字列、リスト、辞書）¶

前回までは「1つの箱（変数）に1つのデータ」を入れてきました。
でも、現実のデータ分析では、何千、何万というデータを扱います。
「カフェの1ヶ月分の売上」を記録するのに、変数を30個も作るのは大変ですよね。

そこで今日は、**「たくさんのデータを1つにまとめて管理する魔法の箱（データ構造）」**を学びます！
「リスト」「タプル」「辞書」「セット」と色々な名前が出てきますが、

それぞれ「レシート」「鍵付きの箱」「メニュー表」「重複なし名簿」と例えていくので、一緒に楽しく整理していきましょう。これが使えるようになると、プログラミングが一気に便利に、そして強力になります

🎯 到達目標¶

  1. リスト（list） を使って、たくさんのデータを順番に管理・操作できる。

  2. 辞書（dictionary） を使って、「商品名と価格」のようなペアのデータを管理できる。

  3. タプル（tuple）とセット（set） の特徴を理解し、目的に応じて使い分けられる。

  4. 「等しい（値が同じ）」と「同一（モノが同じ）」の違いなど、データ構造特有のエラーや落とし穴を回避できる。

リスト (list) ：データを順番に並べよう¶

リストは、データを一列に並べて管理する箱です。角括弧 [ ] を使います。

リストとインデックス・スライス¶

前回、文字列で「0番目から数える」ことを学びましたね。リストも全く同じです！

【リストの図解】

  インデックス:    0        1        2
  リスト(sales): [ 450,     500,     400 ]

# カフェの売上をリスト（配列）にまとめます
sales = 

# インデックス（番号）でデータを取り出す
print("最初の売上:", sales)

# リストに対する関数・演算子・メソッド
print("データの個数(len):", len(sales))
print("合計金額(sum):", sum(sales))
print("売上データの連結:", sales + ) # リスト同士は + で繋げます

リストを操作するメソッドなど（追加・削除・スライス）¶

リストは、後からデータを追加したり削除したりできます（これを「ミュータブル（変更可能）」と言います）。

  • 破壊的（インプレース）な操作: 元のリストそのものを書き換えてしまう操作。

  • 非破壊的な生成: 元のリストはそのままにして、新しいリストを作る操作（スライスなど）。

menu = ["コーヒー", "紅茶", "ケーキ"]

# 破壊的な操作（元のリストが変化します！）
menu.append("サンドイッチ")  # append: 最後に「追加」
print("追加後:", menu)

menu.remove("紅茶")          # remove: 指定したデータを「削除」
print("削除後:", menu)

# 非破壊的な操作（元のリストは変わりません）
sub_menu = menu[0:2]         # スライスで一部を切り出す
print("スライスした結果:", sub_menu)
print("元のリストはそのまま:", menu)

多重リスト¶

リストの中に、さらにリストを入れることができます（エクセルの表のようなイメージです）。 [行][列] のようにしてデータを取り出します。

リストと文字列の相互変換¶

データクレンジング（データの掃除）でよく使います。

  • 文字列.split(): 文字列を分割してリストにする。

  • 結合文字.join(リスト): リストの文字をくっつけて1つの文字列にする。

# 多重リスト（月曜と火曜の、午前・午後の客数）
visitors = [
   , # 月曜 [午前, 午後] (インデックス0)
     # 火曜 [午前, 午後] (インデックス1)
]
print("火曜の午後の客数:", visitors) # 1番目のリストの、1番目のデータ

# 文字とリストの変換
csv_data = "コーヒー,400,ケーキ,500"
data_list = csv_data.split(",") # カンマで分割！
print("リスト化:", data_list)

タプル (tuple) とイミュータブル (約10分)¶

タプルは、丸括弧 ( ) を使います。リストとそっくりですが、最大の決定的な違いがあります。 それは**「イミュータブル（変更不可能）」**であることです。一度作ったら、追加も削除も書き換えも絶対にできません！「絶対に間違えて書き換えたくない重要なデータ」を守るために使います。

多重代入¶

タプルは、複数の変数に一気にデータを入れる（多重代入）ときによく隠れて使われています。

オブジェクトの等価性(==)と同一性(is)¶

  • ==（等価性）: 箱の**「中身（値）」**が同じかどうか。

  • is（同一性）: 箱**「そのもの（メモリ上の場所）」**が同じかどうか。 データ分析では基本的に == を使えば大丈夫です。

# タプルの作成
tax_rate = (0.08, 0.10) # 軽減税率と標準税率（変わってはいけない値！）
print("標準税率:", tax_rate)

# エラーになります！（タプルは書き換えられないため、TypeErrorが出ます）
# tax_rate = 0.15 

# 多重代入（カンマで区切ると、実はタプルとして処理されています）
morning_sales, afternoon_sales = 12000, 15000
print("午後の売上:", afternoon_sales)

# 等価性と同一性の違い（リストやタプルの比較演算）
list_A =
list_B =
list_C = list_A

print("中身は同じ？(==):", list_A == list_B) # True (中身は同じ)
print("箱も同じ？(is):", list_A is list_B) # False (別の箱として作られた)
print("CはAと同じ箱？(is):", list_A is list_C) # True (同じ箱を指している)

辞書 (dictionary) ：名前（キー）でデータを管理¶

辞書は、波括弧 { } を使います。 リストが「番号」でデータを管理するのに対し、辞書は**「名前（キー）」と「値（バリュー）」をペア**にして管理します。カフェのメニュー表を想像してください！

【辞書の図解】

  [ キー (Key) ] ━▶ [ 値 (Value) ]
  "コーヒー"     ━▶   450
  "ケーキ"       ━▶   500

辞書の操作（メソッド）と、辞書とリストの組み合わせ¶

辞書は、キーを指定して値を取り出したり、新しいキーを作ってデータを追加したりできます。 また、リストの中に辞書を入れることで、複雑な顧客データなども綺麗に表現できます。

# 辞書の作成
menu_dict = {"コーヒー": 450, "ケーキ": 500}

# データの取り出し（番号ではなく、名前を使います！）
print("コーヒーの値段:", menu_dict["コーヒー"])

# データの追加と変更
menu_dict["紅茶"] = 400         # 新しいキーと値を追加
menu_dict["コーヒー"] = 480     # 既存のキーの値を変更（値上げ！）
print("変更後:", menu_dict)

# 辞書のメソッド（キーだけ、値だけを取り出す）
print("メニュー一覧:", menu_dict.keys())
print("価格一覧:", menu_dict.values())

# 辞書とリストの組み合わせ（顧客データの表現）
customers = [
    {"name": "山田", "age": 20},
    {"name": "佐藤", "age": 35}
]
print("2人目のお客様の名前:", customers["name"])

set（セット）の特徴と活用¶

セットも波括弧 { } を使いますが、辞書と違って「キーと値のペア」ではなく、単なるデータの集まりです。 最大の特徴は**「重複を許さない（同じデータは1つにまとめられる）」**ことです！

# アンケートで「好きな飲み物」を聞いた結果のリスト（重複があります）
survey_results = ["コーヒー", "紅茶", "コーヒー", "ジュース", "紅茶"]

# setに変換すると、重複が一瞬で消えます！（データ分析でよく使います）
unique_results = set(survey_results)
print("重複なしの回答:", unique_results)

for文による繰り返しとデータ構造¶

※この内容は第8回で詳しくやりますが、データ構造と相性が抜群なので少しだけ紹介します！

リストや辞書の中身を1つずつ取り出して処理したいとき、for という魔法の言葉を使います。 「箱（リスト）の中から、1つずつデータを取り出して、一時的な変数に入れる」という処理を全自動でやってくれます。

orders = ["コーヒー", "ケーキ", "紅茶"]

# for文による繰り返しとリスト・タプル（文字列も同じように1文字ずつ繰り返せます）
print("=== 注文の読み上げ開始 ===")
for item in orders:
    print(item, "が入りました！") # インデント（字下げ）を忘れずに！
print("=== 読み上げ終了 ===")

# for文によるリスト初期化の短縮記法（内包表記とも呼ばれます）
# 値段リストのすべての要素を税込み(1.1倍)にする、といった時に1行で書けます。
prices = 
tax_in_prices = [p * 1.1 for p in prices]
print("税込み価格リスト:", tax_in_prices)

📚 第5回のまとめ¶

✨ 今日の重要ポイントまとめ¶

  • リスト [ ]: 順番のあるデータの集まり。インデックスで取り出し、append で追加。（ミュータブル＝変更可能）

  • タプル ( ): 変更してはいけないデータの集まり。（イミュータブル＝変更不可能）

  • 辞書 { }: キー（名前）と値のペア。「名前」で検索できる強力なメニュー表。

  • セット { }: 重複を許さないデータの集まり。ユニークな（重複のない）データ数を知りたい時に便利。

❓ よくある質問と回答 (FAQ)¶

  • Q. TypeError: 'tuple' object does not support item assignment というエラーが出ました。

    • A. タプル（丸括弧 () で作ったデータ）の中身を、後から書き換えようとしていませんか？ タプルは「イミュータブル（変更不可能）」という頑固な性質を持っています。書き換えたい場合は、リスト [] を使うようにコードを修正しましょう！

  • Q. リストと辞書、どちらを使えばいいか迷います。

    • A. 「順番」に意味があるか、「名前（ラベル）」に意味があるかで決めます。例えば「1日目、2日目、3日目の気温」なら順番に並べるリストが便利です。「国語の点数、数学の点数」なら、数字だけ並べても後から分からなくなるので、科目名をキーにした辞書が便利です。

    {"item": "ケーキ", "price": 500},
    {"item": "コーヒー", "price": 450}
]

# 合計金額を入れる箱（最初は0円）
total_sales = 0

# for文で1つずつ注文を取り出して、値段を足していく
for order in daily_orders:
    total_sales = total_sales + order["price"]

print("本日の合計売上は", total_sales, "円です！")
