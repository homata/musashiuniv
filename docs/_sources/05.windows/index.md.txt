# Windows 特有の注意点
Windowsの設定を確認しておきましょう。

## 拡張子の表示

拡張子の表示 「ファイル名.txt」の .txt の部分を拡張子と呼び、ファイルの種類を表します。Windowsは初期設定でこれが隠れているので、エクスプローラーの「表示」タブから「ファイル名拡張子」にチェックを入れて表示させておきましょう。

### 圧縮ファイル（.zip）
圧縮ファイル（.zip） 複数のファイルをギュッとまとめたものです。使うときは必ず「右クリック」→「すべて展開」を選んでから使ってくださいね。展開せずに中身を触ろうとするとエラーになります。
