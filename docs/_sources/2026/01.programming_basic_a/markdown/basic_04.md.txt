### 算術演算子のまとめ
Pythonでは、電卓のように様々な計算ができます。よく使う記号（演算子）を表にまとめました。

| 演算子 | 意味 | コード例 | 結果 | データ分析での使い道 |
| :---: | :--- | :--- | :--- | :--- |

| `-` | 引き算 | `1000 - 450`| 550 | お釣りの計算、利益の計算 |

| `%` | 割り算の余り| `10 % 4` | 2 | 「余るケーキはいくつ？」、偶数・奇数の判定 |
| `**`| べき乗 | `2 ** 3` | 8 | 複利計算（2の3乗＝2×2×2） |

### 演算子の優先順位と括弧、そして空白
数学と同じように、掛け算・割り算は、足し算・引き算より先に計算されます。
順番を変えたい時は `( )` 括弧を使います。
また、計算式を見やすくするために、記号の前後には**空白（半角スペース）**を入れるのが美しい書き方（コーディング規約）とされています。

```
# 簡単な算術計算と優先順位の確認
# 400円のコーヒーと300円のクッキーを買い、100円引きクーポンを使いました。

# 悪い例：読みにくい（空白がない）
total1=400+300-100

# 良い例：読みやすい（空白がある）
total2 = 400 + 300 - 100 

print("合計金額:", total2)

# 括弧を使った優先順位の変更
# 3人でカフェに行き、各自が400円と300円のものを頼みました
wrong_calc = 400 + 300 * 3    # 300*3が先に計算されてしまう（400 + 900 = 1300）
correct_calc = (400 + 300) * 3 # 括弧の中が先に計算される（700 * 3 = 2100）

print("間違った計算:", wrong_calc)
print("正しい計算:", correct_calc)
```

### 文字列とインデックス

Pythonの世界では、文字列は「文字が順番に並んだ列車の車両」のように扱われます。
それぞれの文字には**「インデックス（番号）」**が振られていますが、ここで最大の注意点！
**コンピュータは「0」から数字を数え始めます！**

**【インデックスの図解】**
「ＣＡＦＥ」という文字があった場合…
```text
  先頭から数える ──▶   0    1    2    3
                    [ C ][ A ][ F ][ E ]
  後ろから数える ◀──  -4   -3   -2   -1
```
最初の「C」を取り出したければ、`0`番目を指定します。一番後ろの「E」は `-1` で取り出せます。

### 文字列とスライス

文字の「一部を切り取る」ことを**スライス**と呼びます。
`文字列[開始 : 終了]` と書きますが、**「終了の番号は含まれない（その手前まで）」**というルールがあります。

**【スライスの図解】**
```text
  [ C ][ A ][ F ][ E ]
  0    1    2    3    4  (文字の隙間に番号があるイメージを持つと分かりやすいです)
  ↑         ↑
  ここから、ここまで（2は含まない） ＝ [0:2] ＝ "CA"
```

Pythonのスライス（slice）は、リストや文字列、タプルなどのシーケンス（配列）から、指定した範囲の要素を簡単に切り出す機能です

```
word1 = 'hello'
word1[0] = 'H'
word1[-1]
```

まとめると文字列 `hello` の正負のインデックスは以下の表の関係になります。  

|インデックス|h|e|l|l|o|
|-|--|--|--|--|--|
|0か正|0|1|2|3|4|
|負|-5|-4|-3|-2|-1|


スライスを全て記述すると [開始位置:終了位置:ステップ] の形で指定します。  

* start（開始位置）: 取得を開始するインデックス（含める）。
* stop（終了位置）: 取得を終了するインデックス（含めない）。
* step（ステップ）: 何個ごとにとばして取得するか（省略可能）。

開始位置:終了位置:ステップは省略も可能です

最初から指定位置まで [:stop]
```
numbers[:4]
```
指定位置から最後まで [start:]
```
numbers[5:]
```
全体のコピー [:]
```
numbers[:]
```

マイナス（負の数）指定 [-位置:]  
後ろから数えた位置を指定できます（一番後ろの要素が -1）
```
numbers[-3:]  # 後ろから3番目から最後まで
```

ステップ（飛ばし読み） [start:stop:step]
```
numbers[1:8:2]  # 2マスずつ進む（1つ飛ばし）
numbers[::2]    # リスト全体から偶数インデックスだけ取得
```

リストの逆順（反転） [::-1]  
ステップに -1 を指定すると、要素を後ろから逆順に取得できます。
```
numbers[::-1]
```

取得したい部分文字列の先頭の文字のインデックスと最後の文字のインデックスに 1 を加えた値を指定します。  
 たとえば、ある文字列の2番目の文字から4番目までの文字の部分文字列を得るには次のようにします。
```
digits1='0123456789'
digits1[1:4]
```

文字列の先頭（すなわち、インデックスが 0 の文字）を指定する場合、次のように行えます。
```
digits1[0:3]
```

最初の 0 は省略しても同じ結果となります。
```
digits1[:3]
```

最後尾の文字のインデックスも、値を省略することもできます。
```
digits1[3:]
digits1[3:5]
```

スライスにおいても負数を指定して、 文字列の最後の方から部分文字列を取得できます
```
digits1[-4:-1]
```

スライスでは3番目の値を指定することで、とびとびの文字を指定できます。  
次のように digits1[3:9:2] と指定すると、インデックス 3 から2文字おきにインデックス 9 より小さい文字を並べた部分文字列を得ます。
```
digits1[3:9:2]
```

3番目の値に -1 を指定することもできます。これを使えば元の文字列の逆向きの文字列を得ることができます。
```
digits1[8:4:-1]
```

まとめて記述
```
shop_name = "ムサシ・カフェ"

# インデックス（1文字だけ取り出す）
# 0から数えるので、3番目は「・」ではなく「カ」になります！
print("0番目の文字:", shop_name)  
print("3番目の文字:", shop_name)  
print("最後の文字:", shop_name[-1]) 

# スライス（範囲を切り出す）
# 0番目から4番目の「手前（3番目）」まで切り出す
print("0から4番目の手前まで:", shop_name[0:4]) 

# 開始や終了を省略すると、「一番最初から」「一番最後まで」という意味になります
print("最初から3番目の手前まで:", shop_name[:3]) 
print("4番目から最後まで:", shop_name[4:])
```

### 空文字列（から・もじれつ）
文字が何も入っていない文字列 `""` のことを空文字列と呼びます。データの中で「欠損（データがない）」状態を表す時や、文字を消去したい時によく使います。

シングルクォート（もしくはダブルクォート）で、何も囲まない場合、長さ 0 の文字列（空文字列（くうもじれつ）もしくは、空列（くうれつ））となります。 具体的には、下記のように使用します。

```
blank = ''
```

空文字列は、次のように、たとえば文字列中からある部分文字列を取り除くのに使用できます
```
price = '2,980円'
price.replace(',', '')
```

文字列のスライスにおいて、指定したインデックスの範囲に文字列が存在しない場合、 たとえば、最初に指定したインデックス x に対して、 2番目のインデックスの値に x 以下のインデックスの値を指定するとどうなるでしょうか？ （ただし、2つのインデックスは同じ符号を持つとし、スライスの3番目の値は用いないとします。） このような場合、結果は次のように空文字列となります（エラーが出たり、結果が None にはならないことに注意してください）。

```
digits1='0123456789'
print('空文字列1 = ', digits1[4:2])
print('空文字列2 = ', digits1[-1:-4])
print('空文字列3 = ', digits1[3:3])
print('空文字列ではない = ', digits1[3:-1])
```

### 文字列の連結とエスケープシーケンス
*   **連結**: 文字列同士は `+` でくっつけることができます。
*   **エスケープシーケンス**: 改行などを表現するための特別な記号です。`\n`（バックスラッシュとn）と書くと、そこで文字が改行されます。Macの方は `Option + ¥` で `\` を打てます

```
# 文字列の連結
greeting = "こんにちは！"
customer = "山田さん"
print(greeting + customer) # こんにちは！山田さん

# エスケープシーケンス（\n で改行）
receipt = "コーヒー：400円\nケーキ：500円\n合計：900円"
print(receipt)
```

### 文字列の検索と比較
*   **検索**: `in` を使うと、その文字が含まれているか（True/False）を判定できます。
*   **比較演算**: `==` (等しい)、`!=` (等しくない) を使って文字列が一致するか調べます。

```
# 検索（in）
menu = "濃厚抹茶フラペチーノ"
print("「抹茶」は含まれている？:", "抹茶" in menu) 

# 比較（==）
password = "open"
print("パスワードは正しい？:", password == "open")
```

比較演算子、==, <, > などを用いて、2つの文字列を比較することもできます。

```
print('abc' == 'abc')
print('ab' == 'abc')
```

```
print('abc' != 'abc')
print('ab' != 'abc')
```

文字列の大小の比較は、いわゆる辞書式による比較で、文字列の最初の文字から順に比較して大小を決めます。 片方がもう片方を拡張したものであれば、拡張した方を大きいとします。

```
print('abc' <= 'abc')
print('abc' < 'abc')
print('abc' < 'abd')
print('ab' < 'abc')
```

### 文字列のメソッド（便利ツール）
文字列データには、自分自身を加工する便利なツール（メソッド）がくっついています。
`文字列.メソッド名()` の形で使います。

```
text = "  Cafe Musashi  "

# upper(): すべて大文字にする
print("大文字:", text.upper())

# replace(): 文字を置き換える（データクレンジングで超頻出！）
print("置換:", text.replace("Musashi", "Tokyo"))

# strip(): 前後の不要な空白を削除する
print("空白削除:[", text.strip(), "]")
```

### 🚨 初心者によくある誤解 — 「変数」と「文字列」の混乱 (超重要！)
初心者の皆さんが最初によくやってしまう、そしてパニックになりやすい間違いがこれです。

*   `"coffee"` ＝ クォーテーションで囲まれている。これは**「文字列（ただの文字）」**です。
*   `coffee` ＝ クォーテーションがない。これは**「変数（データが入った箱の名前）」**です。

```python
drink = "コーヒー"  # 変数 drink に 文字列 "コーヒー" を入れた

print("drink")    # ← 画面には「drink」という文字がそのまま出る！
print(drink)      # ← 画面には箱の中身の「コーヒー」が出る！
```
エラー（`NameError: name 'xxx' is not defined`）が出た時は、「文字として書きたかったのに、クォーテーションを付け忘れて『変数』として扱われていないか？」を必ずチェックしてください！

### ❓ よくある質問と回答 (FAQ)
*   **Q. スライスで `IndexError: string index out of range` というエラーが出ました。**
    *   **A.** 文字列の長さよりも大きいインデックス（番号）を指定しようとしています。「CAFE」は4文字ですが、一番最後は「3番目」です。「4番目」を指定すると、列車がないためエラーになります。0から数えるルールを思い出してくださいね！
*   **Q. 文字列に `+` 以外の掛け算などはできますか？**
    *   **A.** 実はできます！ `"カフェ" * 3` とすると `"カフェカフェカフェ"` になります。ただし、引き算や割り算はできません（エラーになります）。
