「先月のコーヒーの売上は、1週目が400杯、2週目が420杯、3週目が380杯で…」と言われるより、グラフを1枚見せた方が一瞬で伝わりますよね。

**【データ可視化の効果（イメージ図）】**
```text
[ 📊 数字の羅列 ] 
 400, 420, 380, 500, 480... (よくわからない…)
       │
       ▼ (Pythonの魔法！)
[ 📈 美しいグラフ ]
       ╭○╮
      ╱  ╰─╮  (直感的に「週末に爆発的に売れている！」とわかる)
   ╭─╯     ╰─
```

## 基本のグラフ作成と装飾 (matplotlib) 

まずは基本の `matplotlib` を使って、目的に合わせた色々なグラフを描いてみましょう！
使い方の基本は **「1. キャンバスに描く → 2. 装飾する → 3. 画面に見せる(`plt.show()`)」** の3ステップです。

### ① 線グラフ（時間の経過・変化を見たい時）
「1ヶ月の売上の推移」など、時間の流れによる変化を見るのに最適です。
*   `plt.plot(X軸のデータ, Y軸のデータ)`

### ② 棒グラフ（量を比較したい時）
「コーヒーと紅茶とケーキ、どれが一番売れた？」など、大小を比べるのに使います。
*   `plt.bar(X軸のデータ, Y軸のデータ)`

### ③ 散布図（2つの関係性・相関を見たい時）
「気温が高い日は、冷たい飲み物が売れるかな？」という関係性（相関）を点々で調べます。
*   `plt.scatter(X軸のデータ, Y軸のデータ)`

### グラフの装飾（タイトル、ラベル）
何も書いていないグラフは、何を表しているか分かりません。必ず名前をつけましょう。

```
# カフェの1週間の売上データ
days = ["月", "火", "水", "木", "金", "土", "日"]

# --- ① 線グラフの作成 ---
# マーカー(点)の形や、色(color)を指定できます
plt.plot(days, sales, marker="o", color="blue") 

# --- 装飾 ---
plt.title("1週間のカフェ売上推移") # グラフのタイトル

plt.ylabel("売上（杯）")             # Y軸（縦）のラベル
plt.grid(True)                       # 読みやすいように補助線（グリッド）を入れる

# --- 画面に表示！ ---
plt.show()

# ========================================================
```

## データ分布と相関の可視化 (seaborn) 

ここからは、デザイナーである `seaborn` (sns) の出番です。pandasのデータフレームと非常に相性が良く、データ分析の現場で大活躍します。

### ④ ヒストグラム（データの散らばり具合・分布を見たい時）
「お客様の年齢層はどのあたりが多いかな？」というデータの「分布（ばらつき）」を見るグラフです。
棒グラフと似ていますが、横軸が「区間（10代、20代など）」になるのが特徴です。
*   `sns.histplot(データ)`

### ⑤ ヒートマップ（データ同士の相関やクロス集計を見たい時）
数字の大小を「色の濃淡」で表したグラフです。
「月曜日の午後は売上が少ないから青色、土曜のお昼は激混みだから赤色」のように、全体像を一瞬で把握するのに使います。
*   `sns.heatmap(データ)`

```
# --- ④ ヒストグラム ---
# お客様50人分の年齢データ（ダミー）を生成します
np.random.seed(0)
ages = np.random.randint(15, 65, 50) # 15歳〜65歳の間でランダムに50個

# seabornを使ってヒストグラムを描画（kde=True をつけると、なめらかな山の線も描いてくれます）
sns.histplot(ages, bins=10, kde=True, color="green")
plt.title("ご来店のお客様の年齢分布")
plt.xlabel("年齢")
plt.ylabel("人数")
plt.show()

# ========================================================

# --- ⑤ ヒートマップ ---
# 時間帯(行)と曜日(列)の混雑度データ（pandasのデータフレームを使います）
congestion_data = pd.DataFrame({
    "月曜":,
    "水曜":,
    "土曜":
}, index=["午前", "お昼", "午後"])

print("【元の表データ】")
print(congestion_data)

print("\n【ヒートマップで可視化】")
# annot=True で四角の中に数字を表示、cmapで色のテーマを指定
sns.heatmap(congestion_data, annot=True, cmap="Reds")
plt.title("曜日・時間帯別の混雑度ヒートマップ")
plt.show()
```

## グラフの画像ファイル出力（保存）

苦労して綺麗なグラフを作ったら、レポートやプレゼン資料に貼り付けたいですよね。
`plt.show()` で画面に出す**直前**に、`plt.savefig("ファイル名.png")` を書くことで、画像ファイルとして保存できます。

```
# グラフの保存
plt.plot(["A", "B", "C"], )
plt.title("保存用のグラフ")

# 保存（show() の前に書くのが鉄則です！）
plt.savefig("my_graph.png")
print("my_graph.png を保存しました！（左の📁フォルダから確認できます）")

# その後に画面に表示
plt.show()
```

## 📚 第12回のまとめ

### ✨ 今日の重要ポイントまとめ
*   **matplotlib (plt)**: 自由自在にグラフを描ける職人。`plot`(線), `bar`(棒), `scatter`(散布図) などを使い分ける。
*   **seaborn (sns)**: 統計グラフをおしゃれに描くデザイナー。`histplot`(ヒストグラム) や `heatmap`(ヒートマップ) が得意。
*   **装飾の重要性**: `title`, `xlabel`, `ylabel` で、誰が見てもわかるグラフにする。
*   **画像保存**: `plt.show()` をする前に `plt.savefig()` を書くことで、グラフを画像ファイルとして保存できる。

### ❓ よくある質問と回答 (FAQ)
*   **Q. `ValueError: x and y must be the same size` というエラーが出ました。**
    *   **A.** これもグラフ作成あるあるです！「X軸（横）のデータは5個あるのに、Y軸（縦）のデータは4個しかないよ」というエラーです。X軸とY軸のデータは必ずペアになっている必要があるので、リストの要素数を数えてみてください。
*   **Q. グラフの日本語が「□□□」になってしまいます（文字化け）。**
    *   **A.** 本講義の冒頭で行った `japanize-matplotlib` のインストールとインポート（`import japanize_matplotlib`）を忘れていませんか？Colab環境ではこれがないと日本語が文字化けしてしまうので、新しいノートブックを作る時は必ずセットで書いておきましょう。
