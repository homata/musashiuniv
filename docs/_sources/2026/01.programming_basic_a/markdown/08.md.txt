## 8.3 while文と制御の流れを変える魔法 (約10分)

### while文による繰り返し
`for` 文が「回数や個数が決まっている」時に使うのに対し、**`while` 文は「条件を満たしている間はずっと繰り返す」**時に使います。

🚨 **【初心者の落とし穴：無限ループ】**
while文で一番多いエラー（バグ）が、条件が一生Falseにならずに永遠に処理が止まらなくなる「無限ループ」です。もしコードを実行して星マーク `[*]` がずっと消えなかったら、左上の停止ボタン（■）を押して強制終了してください！

### break と continue と pass
*   **`break`**: 繰り返しを「強制終了（店じまい）」します。
*   **`continue`**: 今の処理だけスキップして、「次のお客様（次のループ）」へ進みます。
*   **`pass`**: 「とりあえず何もしない」という目印です。後でコードを書く予定の場所に置きます。

### for文とwhile文における else
Python特有の機能として、ループが**「breakされずに最後まで無事に完走した時だけ実行される else」**を書くことができます。

### 制御構造とreturn文
関数（def）の中で `return` が実行されると、その時点でfor文やwhile文もすべて強制終了して結果を返します。

```

<!-- コードセル -->
# while文 と break, continue の働き
stock = 3 # 在庫

while stock > 0:
    print("いらっしゃいませ！在庫は残り", stock, "個です。")
    stock = stock - 1
    
    if stock == 1:
        print("残り1個なので、特別なお客様用にとっておきます！（スキップ）")
        continue # ここで下の処理を飛ばして、次のループの先頭に戻る
        
    if stock == 0:
        print("売り切れました！本日は閉店します。（強制終了）")
        break # ループを完全に抜け出す

# ループの else（無事に完走したかどうかの確認）
for i in range(3):
    print("処理中...", i)
    # ここに break があると、下の else は実行されません
else:
    print("ループがエラーや中断なく、無事に最後まで完了しました！")

## 8.4 イテラブルとイテレータ（繰り返しの裏側） (約10分)

ここは少しだけ高度な、Pythonの裏側の仕組みのお話です。「for文ってどうして中身を順番に取り出せるの？」という疑問の答えです。

*   **イテラブル (Iterable)**: 「順番に取り出せる箱」のこと。（例：リスト、文字列、辞書）
*   **イテレータ (Iterator)**: 「現在地を覚えていて、次を取り出してくれる人」のこと。
※ **「イテラブルはイテレータではない」** というのが重要です。箱そのものは動けません。

**【仕組み（for文の正体）】**
1. for文はまず、対象のイテラブルに `iter()` という関数を使って、イテレータ（取り出し担当の人）を生み出します。
2. 次に、`next()` という関数を使って「次ちょうだい！」と要求します。
3. 中身がなくなる（StopIterationエラーが出る）まで、それを自動で繰り返しているのがfor文の正体です。

**ファイルオブジェクトもイテレータ**であり、`enumerate` も実はイテレータを返しています。

```

<!-- コードセル -->
# イテラブルとイテレータの違いを体験してみましょう！
my_list = ["コーヒー", "紅茶", "ケーキ"] # これはイテラブル（箱）です

# iter() で、この箱専用の「取り出し係（イテレータ）」を作ります
my_iterator = iter(my_list)

# next() を呼ぶたびに、現在地を記憶しながら1つずつ出してくれます
print("1回目:", next(my_iterator))
print("2回目:", next(my_iterator))
print("3回目:", next(my_iterator))
# 4回目を呼ぶと、空っぽなので StopIteration というエラーが出ます！

## 8.5 内包表記（リストや辞書を美しく作る） (約10分)

データ分析では、「古いリストに処理をして、新しいリストを作る」ことが頻繁にあります。
これを1行でスッキリ書けるのが**「内包表記（ないほうひょうき）」**です。少し暗号みたいに見えますが、慣れると手放せなくなりますよ！

### リスト内包表記
`[ 計算式 for 変数 in イテラブル ]` という書き方をします。

### 条件付き内包表記
`[ 計算式 for 変数 in イテラブル if 条件 ]` と書くと、条件に合ったものだけを抽出できます！

### セット・辞書内包表記 / ジェネレータ式
カッコを `{ }` に変えるとセットや辞書が作れます。丸カッコ `( )` にすると、メモリを節約できる「ジェネレータ式（イテレータの一種）」というものが作れます。

```

<!-- コードセル -->
# 通常のfor文で税込み価格のリストを作る場合
prices = 
tax_in_prices = []
for p in prices:
    tax_in_prices.append(p * 1.1)
print("通常のfor文:", tax_in_prices)

# 🌟 リスト内包表記を使うと、これがたった1行で書けます！
# 読み方：「pricesの中の p を一つずつ取り出し、p * 1.1 をした結果をリストにまとめる」
tax_in_prices_fast = [p * 1.1 for p in prices]
print("リスト内包表記:", tax_in_prices_fast)

# 条件付き内包表記（200円以上のものだけ税込みにする）
expensive_only = [p * 1.1 for p in prices if p >= 200]
print("条件付き（200円以上）:", expensive_only)

# 辞書内包表記の例（メニュー名をキー、値段を値にする）
menu_names = ["コーヒー", "紅茶", "ケーキ"]
# zip は2つのリストを同時に取り出す便利ツールです
menu_dict = {name: price for name, price in zip(menu_names, prices)}
print("辞書内包表記:", menu_dict)
