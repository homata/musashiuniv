Streamlit
---
Streamlitは、データ分析や機械学習のスクリプトを、わずか数行のPythonコードでインタラクティブなWebアプリケーションに変換できるオープンソースのPythonライブラリです。

* [Streamlit](https://streamlit.io/)
* [API reference](https://docs.streamlit.io/develop/api-reference)


* [ゼロから学ぶStreamlit - 基礎 -](https://zenn.dev/torakm/books/4d412cd445249c)
* [【保存版】Streamlitのよく使う構文一覧](https://qiita.com/shuji_asatsuma0251/items/e83b188d90afd27ab664)

### 💡 主な特徴
* Pythonのみで開発可能: HTML、CSS、JavaScriptなどのフロントエンド知識がなくても、UI（ユーザーインターフェース）を構築できます。
* データ同期と高速デプロイ: コードを書き換えて保存するだけで、Webブラウザ上のアプリ画面が即座に自動更新されます。
* 主要なライブラリと連携: NumPy、Pandas、Matplotlib、Plotly、Scikit-learn、TensorFlowなどのデータサイエンス工具と簡単に統合できます。
* ウィジェットの充実: ボタン、スライダー、テキスト入力、ファイルのアップロードなどのUIコンポーネントが標準で用意されています。

### 🛠️ クイックスタート

インストール
```
$ pip install streamlit
```

簡単なコードの作成 (app.py)
```python
import streamlit as st

st.title('こんにちは、Streamlit！')
name = st.text_input('あなたの名前を入力してください:')
if name:
    st.write(f'{name}さん、ようこそ！')
```

simple_streamlit_app.py
``` python
import numpy as np
import pandas as pd
import streamlit as st
 
df = pd.DataFrame( np.random.randn(10, 4), columns=['a', 'b', 'c','d'] )
 
st.title("Simple Streamlit App")
 
st.write("📈　Line-Chart")
st.line_chart(df)
 
if st.checkbox('👓 Show DataFrame (with highlight_max)'):
    st.table(df.style.highlight_max(axis=0))
```


アプリの起動
```
$ streamlit run app.py
```

アプリに AIモデル（LLMなど）を組み込みたい
----

Google Colabの無料T4 GPUを活用して、オープンソースの軽量LLM（Llama 3.1 8BやGemma 2 9Bなど）をStreamlitアプリに組み込むのが最もおすすめです。
Colab上でLLMを動かす場合、通常のPythonコードと同じように呼び出すとStreamlitの画面がフリーズしてしまいます。そのため、threading（マルチスレッド）を使ってバックグラウンドでLLMを動かし、生成されたテキストをリアルタイムに画面に流し込む（ストリーミング出力）のが鉄則です。
以下に、Google Colab上でLLMチャットボットを動かす完全な手順とコードをまとめました。

------------------------------

## 1. 必要なライブラリのインストール
GPUで高速にLLMを動かすための transformers と、高速化ライブラリ bitsandbytes（4bit量子化用）をインストールします。

```python
!pip install streamlit -q
!pip install transformers accelerate bitsandbytes -q
!npm install -g localtunnel
```

* streamlit（Webアプリ開発フレームワーク）
    * 役割: Pythonコードだけで、HTMLやJavaScriptを書くことなく、美しいWebアプリケーション（UI画面）を爆速で構築できるライブラリです。
    * なぜ必要か？: ユーザーが文字を入力するチャット欄、キャラクターを選ぶサイドバー、パラメータを調整するスライダーなどの「画面の見た目と動き」をすべてこのモジュールが担当しています。
    * 後ろの -q は？: quiet（静かに）の略です。インストール時の膨大なログ（進捗バーなど）を非表示にして、Colabの画面をスッキリさせるためにつけています。

* transformers / accelerate / bitsandbytes（AIモデルの動作・高速化セット）
    * これらは、Google ColabのGPUを使ってオープンソースのLLM（AI）を動かすための三種の神器です。
    * transformers:
        * 役割: AI開発企業Hugging Face社が提供する、世界標準のLLM動作用ライブラリです。
        * なぜ必要か？: インターネット上からAIモデル（今回は llm-jp-3）を自動でダウンロードし、テキストをAIが理解できる数字に変換したり（トークナイザー）、AIに文字を生成させたりする核心部分を担っています。
    * accelerate:
        * 役割: AIモデルの読み込みや、GPU（グラフィックボード）へのデータ割り振りを自動で最適化・高速化してくれるライブラリです。
        * なぜ必要か？: device_map="auto" という設定をコード内で使うために必須で、これがあるとColabの限られたGPUメモリへ効率よくモデルを配置してくれます。
    * bitsandbytes:
        * 役割: AIモデルを「量子化（コンパクト化）」するための超重要ライブラリです。
        * なぜ必要か？: 本来なら膨大なメモリが必要なLLMを「4bit量子化（データの軽量化）」という技術で1/4以下のサイズに圧縮します。これがあるおかげで、無料版のGoogle Colabでもメモリ不足（OOMエラー）で強制終了することなくLLMがサクサク動きます。



※Colabのメニュー「ランタイム」＞「ランタイムのタイプを変更」で、T4 GPUが選択されていることを確認してください。

## 2. LLM組み込み型 Streamlitコードの書き込み
以下のコードをColabのセルに貼り付けて実行し、app.py を作成します。
今回は日本語が非常に得意で軽量な llm-jp/llm-jp-3-1.8b-instruct（18億パラメータ・4bit量子化）を使用します。無料版Colabのメモリでも高速・安全に動作します。

先ほどのアプリコードの冒頭に書かれている import 文について、それぞれのライブラリや機能が「チャットアプリ内で具体的に何をしているのか」を分かりやすく解説します。

#### 1. import streamlit as st

* 役割: Webアプリの画面を作る streamlit を、コード内で扱いやすいように st という短い名前で呼び出せるようにしています。
* アプリ内での仕事:
* st.title() で画面に大きなタイトルを表示する。
   * st.sidebar.slider() でサイドバーに調整スライダーを置く。
   * st.chat_input() でユーザーが文字を入力するチャット欄を作る。 [1, 2] 

#### 2. import torch

* 役割: Facebook（現Meta）が開発した、AIやディープラーニングの計算を高速に行うための世界的なライブラリ「PyTorch（パイトーチ）」を読み込んでいます。
* アプリ内での仕事:
* Google Colabの高性能なGPU（グラフィックボード）を使ってAIの計算をさせるために、データをGPU用の形式（torch.bfloat16 など）に指定する役目を担っています。 [3] 

#### 3. from transformers import ...
Hugging Face社の transformers ライブラリから、LLM（人工知能）の制御に必須となる4つの特殊な道具をピンポイントで取り出しています。

* AutoTokenizer（オート・トークナイザー）:
    * 役割: 人間が書いた「言葉（テキスト）」を、AIが理解できる「数字の列（トークン）」に変換したり、逆にAIが返してきた数字を人間の言葉に戻したりする翻訳機です。
* AutoModelForCausalLM（オート・モデル・フォー・コーザル・エルエム）:
    * 役割: 「文章の続きを予測して生成するAIモデル（文章生成LLM）」を読み込むためのベースとなる仕組みです。今回使用した llm-jp-3 本体を動かしています。
* BitsAndBytesConfig（ビッツ・アンド・バイツ・コンフィグ）:
    * 役割: AIモデルのデータを「4bit」という超軽量なサイズにギュッと圧縮（量子化）するための設定を作る道具です。これを使って無料版Colabのメモリ不足を防いでいます。
* TextIteratorStreamer（テキスト・イテレータ・ストリーマー）:
    * 役割: AIが生成した文章を、完成を待たずに「できた文字から順番に1文字ずつリアルタイムで画面に流し込む（ストリーミング表示）」ための特殊なパイプラインです。ChatGPTのように文字がサラサラと出てくる表現はこれで作られています。 [4] 

#### 4. from threading import Thread

* 役割: Pythonで「マルチスレッド（複数の処理を同時に並行して行う仕組み）」を使うための標準ライブラリから、スレッドを作成する Thread を読み込んでいます。
* アプリ内での仕事:
* これが画面フリーズを防ぐ最大のカギです。
   * 普通にAIに長文を考えさせると、AIが考え終わるまでStreamlitの画面全体がピタッと固まって動かなくなってしまいます。
   * そこで Thread を使い、「AIが文章を考える仕事（裏方）」と「Streamlitが画面を描き換える仕事（表舞台）」を完全に２つのルートに分離させ、同時並行で処理させています。

------------------------------

この短い import の中に、「画面を作る」「AIを動かす」「メモリを削る」「文字を流す」「フリーズを防ぐ」 というアプリの根幹となるすべての技術が詰まっています。

もし、この中で「量子化（4bit）って具体的にどういう仕組み？」「マルチスレッドがないとどうなるの？」など、さらに深く知りたい仕組みがあれば何でも教えてくださいね！


```python
%%writefile app.py
import streamlit as st
import torch
from transformers import AutoTokenizer, AutoModelForCausalLM, BitsAndBytesConfig, TextIteratorStreamer
from threading import Thread

st.title("🤖 Colab LLM チャットボット")

# 1. モデルとトークナイザーの読み込み（初回のみ実行）

@st.cache_resource
def load_model():
    model_id = "llm-jp/llm-jp-3-1.8b-instruct"
    
    # 4bit量子化でメモリを節約
    bnb_config = BitsAndBytesConfig(
        load_in_4bit=True,
        bnb_4bit_quant_type="nf4",
        bnb_4bit_compute_dtype=torch.bfloat16
    )
    
    tokenizer = AutoTokenizer.from_pretrained(model_id)
    model = AutoModelForCausalLM.from_pretrained(
        model_id,
        quantization_config=bnb_config,
        device_map="auto"
    )
    return tokenizer, model

with st.spinner("LLMモデルを読み込み中...（初回は数分かかります）"):
    tokenizer, model = load_model()

# 履歴の初期化
if "messages" not in st.session_state:
    st.session_state.messages = []

# 過去のチャット履歴を表示
for message in st.session_state.messages:
    with st.chat_message(message["role"]):
        st.markdown(message["content"])

# ユーザー入力の受付
if prompt := st.chat_input("AIにメッセージを送る"):
    st.session_state.messages.append({"role": "user", "content": prompt})
    with st.chat_message("user"):
        st.markdown(prompt)

    # AIの返答処理
    with st.chat_message("assistant"):
        response_placeholder = st.empty()
        
        # LLM用のプロンプトフォーマット（llm-jpの指示形式）
        full_prompt = f"{prompt}\n### 回答:\n"
        inputs = tokenizer(full_prompt, return_tensors="pt").to("cuda")
        
        # ストリーミング出力の設定
        streamer = TextIteratorStreamer(tokenizer, timeout=10.0, skip_prompt=True, skip_special_tokens=True)
        
        # 推論設定
        generate_kwargs = dict(
            **inputs,
            streamer=streamer,
            max_new_tokens=256,
            do_sample=True,
            temperature=0.7,
            top_p=0.9,
            repetition_penalty=1.2
        )
        
        # 別スレッドでLLMの生成を実行（画面フリーズ防止）
        thread = Thread(target=model.generate, kwargs=generate_kwargs)
        thread.start()
        
        # 生成されたテキストをリアルタイムに画面へ表示
        full_response = ""
        for new_text in streamer:
            full_response += new_text
            response_placeholder.markdown(full_response + "▌")
            
        response_placeholder.markdown(full_response)
        
    st.session_state.messages.append({"role": "assistant", "content": full_response})
```

## LLMへのキャラクター指示のコツ
今回使用する llm-jp-3 などの Instructモデル（指示追従モデル）にキャラクターを演じさせるには、プロンプトの冒頭に 「あなたは〇〇です。必ず✕✕という口調で話してください。」 という明確な指示（システム設定）を与えるのが最も効果的です。

Instructモデル（指示追従モデル）とは、ユーザーの指示（プロンプト）に対して、意図通りに正確なタスクを実行するよう調整されたAIモデルのことです。

一般的な大規模言語モデル（LLM）は「次に続く言葉」を予測する仕組みですが、Instructモデルは「指示に応じる」訓練を受けています。

LLM-jp-3は、日本のオープンLLM開発プロジェクト「LLM-jp（Large Language Model Japan）」が開発した、最新のオープンな大型言語モデルシリーズです
LLM-jpとは、日本語に強い大規模言語モデル（LLM）の研究開発と成果公開を進める、日本発のプロジェクトおよび研究者コミュニティの名称です。国立情報学研究所（NII）などが主導し、産官学の多くの研究者や技術者が参加しています。

* [LLM-jp](https://llm-jp.nii.ac.jp/)

### プロジェクトの特徴
* 国産オープンLLM: 日本語の自然な対話や指示応答に優れ、商用利用も可能なモデルを開発・公開しています。
* 高い透明性: 学習データや構築の仕組みをオープンにしており、研究や開発に活用しやすいのが特徴です。
* 最新モデル: 2026年4月に公開された「LLM-jp-4」シリーズでは、約12兆トークンもの膨大なデータを用いて学習が行われました。

%%writefile app.py
import streamlit as st
import torch
from transformers import AutoTokenizer, AutoModelForCausalLM, BitsAndBytesConfig, TextIteratorStreamer
from threading import Thread

st.title("🤖 カスタムペルソナ AIチャット")

# 1. モデルとトークナイザーの読み込み（初回のみ）
@st.cache_resource
def load_model():
    model_id = "llm-jp/llm-jp-3-1.8b-instruct"
    bnb_config = BitsAndBytesConfig(
        load_in_4bit=True,
        bnb_4bit_quant_type="nf4",
        bnb_4bit_compute_dtype=torch.bfloat16
    )
    tokenizer = AutoTokenizer.from_pretrained(model_id)
    model = AutoModelForCausalLM.from_pretrained(
        model_id,
        quantization_config=bnb_config,
        device_map="auto"
    )
    return tokenizer, model

with st.spinner("LLMモデルを読み込み中..."):
    tokenizer, model = load_model()

# 2. サイドバーでキャラクター設定（ペルソナ）を選択
st.sidebar.title("🎭 キャラクター設定")
character = st.sidebar.selectbox(
    "AIのキャラクターを選んでください:",
    ["標準的なAIアシスタント", "ツンデレな女の子", "コテコテの関西弁おじさん", "語尾が『ニャ』の猫ロボット", "自由に入力する"]
)

# ペルソナに応じたシステムプロンプト（指示文）の定義
if character == "標準的なAIアシスタント":
    system_prompt = "あなたは親切で丁寧なAIアシスタントです。敬語で分かりやすく回答してください。"
elif character == "ツンデレな女の子":
    system_prompt = "あなたはツンデレな女の子です。最初は少し冷たい態度（『べ、別にアンタのために答えるわけじゃないんだからね！』など）を取りつつも、最終的には優しく丁寧に質問に答えてください。"
elif character == "コテコテの関西弁おじさん":
    system_prompt = "あなたは大阪生まれ大阪育ちのおじさんです。親しみやすいコテコテの関西弁（『〜やがな』『〜やで』など）を使い、ユーモアを交えて回答してください。"
elif character == "語尾が『ニャ』の猫ロボット":
    system_prompt = "あなたは可愛い猫型ロボットです。全ての文末に必ず『〜ニャ』または『〜ニャン』をつけて、愛らしく回答してください。"
else:
    # ユーザーが自由にペルソナを入力できるフォーム
    system_prompt = st.sidebar.text_area("自由に入力:", "あなたは〇〇です。✕✕の口調で話してください。")

# キャラクターが変更されたらチャット履歴をクリアする（状態維持のため）
if "current_char" not in st.session_state:
    st.session_state.current_char = character

if st.session_state.current_char != character:
    st.session_state.messages = []
    st.session_state.current_char = character
    st.toast(f"キャラクターを【{character}】に変更し、会話をリセットしました！")

# 履歴の初期化
if "messages" not in st.session_state:
    st.session_state.messages = []

# 過去のチャット履歴を表示（保存されたアバターを使用）
for message in st.session_state.messages:
    with st.chat_message(message["role"]):
        st.markdown(message["content"])

# ユーザー入力の受付
if prompt := st.chat_input("AIに話しかけてみよう"):
    st.session_state.messages.append({"role": "user", "content": prompt})
    with st.chat_message("user"):
        st.markdown(prompt)

    # AIの返答処理
    with st.chat_message("assistant"):
        response_placeholder = st.empty()
        
        # システムプロンプト（設定）とユーザーの質問をLLMの指示フォーマットに結合
        full_prompt = f"設定: {system_prompt}\n\n質問: {prompt}\n### 回答:\n"
        inputs = tokenizer(full_prompt, return_tensors="pt").to("cuda")
        
        # ストリーミング出力の設定
        streamer = TextIteratorStreamer(tokenizer, timeout=10.0, skip_prompt=True, skip_special_tokens=True)
        
        generate_kwargs = dict(
            **inputs,
            streamer=streamer,
            max_new_tokens=300, # キャラクター表現のために少し長めに設定
            do_sample=True,
            temperature=0.8,    # キャラクターの表現力を高めるために少し高めに設定
            top_p=0.9,
            repetition_penalty=1.2
        )
        
        # 別スレッドでLLMを実行
        thread = Thread(target=model.generate, kwargs=generate_kwargs)
        thread.start()
        
        full_response = ""
        for new_text in streamer:
            full_response += new_text
            response_placeholder.markdown(full_response + "▌")
            
        response_placeholder.markdown(full_response)
        
    st.session_state.messages.append({"role": "assistant", "content": full_response})

### マジックコマンド

```
%%writefile
!pip install aaa
```

Google Colabでは、Pythonコードだけでなく、ファイル操作やパッケージのインストール、Linuxコマンドの実行も簡単に行えるよう、これらの「マジックコマンド」が用意されています。

### ! の意味
! はLinuxのシェルコマンド（ターミナルのコマンド）を実行するという意味です。


### %% の意味

%% は**セルマジック（Cell Magic）**と呼ばれる機能です。
セル全体に対して特別な処理を行います。

#### 
| 記法 | 名前 | 対象 |
| :--- | :---- | :---- |
| %    | ラインマジック（Line Magic） | 1行だけ |
| %%   | セルマジック（Cell Magic）   |	セル全体 |

よく使うセルマジック
| コマンド                  | 説明                  |
| --------------------- | ------------------- |
| `%%writefile file.py` | セルの内容をファイルへ保存       |
| `%%time`              | セル全体の実行時間を表示        |
| `%%timeit`            | 実行時間を複数回測定して平均を表示   |
| `%%bash`              | セル全体をBashスクリプトとして実行 |
| `%%html`              | HTMLとして表示           |
| `%%javascript`        | JavaScriptとして実行     |


まとめ
! … シェル（Linux）のコマンドを実行する
```
!pip install numpy
!ls
!python sample.py
```

% … 1行だけに適用するマジックコマンド
```
%time
```

%% … セル全体に適用するマジックコマンド
```
%%writefile sample.py
%%time
%%bash
```
