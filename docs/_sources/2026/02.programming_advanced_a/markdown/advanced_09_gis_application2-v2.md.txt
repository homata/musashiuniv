### 9.1.1 なぜPythonだけでGoogle Mapsのような動く地図が作れるのか？

### 9.1.2 folium と leafmap：どちらを使うべき？

本講義では、実務のGISプロジェクトで双璧をなす2つの動的ライブラリを扱います。それぞれのキャラクターを整理しておきましょう。

```text
  [ 🗺️ 動的地図ライブラリの双璧 ]
   ├── ① folium (老舗・安定・シンプル) ────▶ 日本語の情報が最も多く、マーカーを数件立てるような
   │                                          防災マップ・店舗マップの基本に最適。
   │
   └── ② leafmap (次世代・多機能・爆速) ──▶ データフレームとの親和性が極めて高く、数万行のデータや
                                              人工衛星画像、Streamlitアプリへの埋め込みに最強。
```

*   **`folium`** は、2010年代から愛されている大ベストセラーライブラリです。シンプルなピン立てやサークル描画、エリアの塗り分けに強く、エラーが起きた際もネットで調べれば1秒で解決策が見つかる「絶対的な安心感」があります。
*   **`leafmap`** は、2020年代に開発された新鋭ライブラリです。実は内部で `folium` や `ipyleaflet` という別の地図エンジンを使い分けて動いています。Pandasのデータフレームから一撃でピンを立てる関数（`add_gdf` や `add_points_from_xy`）を持っており、**「コードの記述量がfoliumの半分以下で済む」**という特徴があります。

本日はまず、動的マッピングの論理的構造が一番よく理解できる「王道」の `folium` から学んでいきましょう！

### 9.2.2 複数店舗をforループで「一撃全自動マッピング」する
実務では、登録されている店舗や避難所は1件や2件ではありません。何百、何千という店舗の緯度経度を、1行ずつ手作業で `folium.Marker` と書いていたら日が暮れてしまいます。

そこで、第3回・第4回で学んだ **Pandasのループ処理 `for idx, row in df.iterrows():`** と合体させます！
データフレームに登録されている全行を自動で走査し、それぞれの行にある「緯度」「経度」「店舗名」を抜き出して、地図オブジェクトに次々とピンを突き刺していくプロの技術を実装しましょう。

**【全自動ループマッピングの処理構造】**
```text
  [ 📋 Pandasデータフレーム ]
   ├── 0行目: 江古田店 [35.737, 139.671] ──(ループ1)──▶ folium.Marker([35.737, 139.671]).add_to(map)
   ├── 1行目: 桜台店   [35.738, 139.663] ──(ループ2)──▶ folium.Marker([35.738, 139.663]).add_to(map)
   └── 2行目: 練馬店   [35.735, 139.654] ──(ループ3)──▶ folium.Marker([35.735, 139.654]).add_to(map)
```

実際に、以下のコードを実行して「複数店舗の自動プロット」を体感してください。

```python
import pandas as pd
import folium

# 1. 3つの店舗を表すデータフレームを作成（実務ではCSVやオープンデータになります）
df_shops = pd.DataFrame({
    \"店舗名\": [\"江古田店\", \"桜台店\", \"練馬店\"],
    \"緯度\": [35.7370, 35.7380, 35.7350],
    \"経度\": [139.6710, 139.6630, 139.6540],
    \"店舗タイプ\": [\"本店\", \"支店\", \"支店\"],
    \"1日平均売上\": [150000, 80000, 95000]
})

# 2. 練馬区周辺を中心に据えたベースマップを生成
map_nerima = folium.Map(location=[35.736, 139.663], zoom_start=14)

# 3. iterrows() で1行ずつ店舗データを取り出してループ処理
for index, row in df_shops.iterrows():
    # 緯度・経度を row から抽出
    lat = row[\"緯度\"]
    lng = row[\"経度\"]
    name = row[\"店舗名\"]
    sales = row[\"1日平均売上\"]
    
    # 💡 応用：本店なら「赤色」、支店なら「青色」にピンの色を自動で分ける！
    if row[\"店舗タイプ\"] == \"本店\":
        color_choice = \"red\"
    else:
        color_choice = \"blue\"
    
    # ピンを生成して地図（map_nerima）に追加
    folium.Marker(
        location=[lat, lng],
        popup=f\"{name} (日次売上: {sales:,}円)\",
        icon=folium.Icon(color=color_choice, icon=\"shopping-cart\", prefix=\"fa\")
    ).add_to(map_nerima)

# 地図を表示
map_nerima
```
見事に、店舗タイプに応じて自動でピンの色が塗り分けられ、アイコンが可愛い「ショッピングカート」になった地図が表示されたはずです。

### 9.2.3 ポップアップをオシャレにする：HTMLタグの埋め込み
通常、ピンをクリックした時に出る吹き出し（`popup`）には単なる「テキスト（文字）」を渡しますが、実はfoliumの `popup` の中身は **HTMLコードがそのまま動作します**。
つまり、改行（`<br>`）や太字（`<b>`）、文字色の変更、さらには「写真（`<img>`）」や「ホームページへのリンク（`<a>`）」まで自由にレイアウトできるのです。

```python
# HTMLタグを使った豪華なポップアップの作成例
html_content = \"\"\"
<div style="font-family: 'Hiragino Kaku Gothic Pro', sans-serif; width: 200px;">
    <h4 style="color: #2e7d32; margin-bottom: 5px;">☕ 江古田の森カフェ</h4>
    <p style="margin: 0; font-size: 12px; color: #555;"><b>おすすめ:</b> 有機栽培コーヒー</p>
    <p style="margin: 0; font-size: 12px; color: #555;"><b>平均予算:</b> 600円〜</p>
    <hr style="margin: 8px 0; border: 0; border-top: 1px solid #ccc;">
    <a href="https://www.musashi.ac.jp" target="_blank" style="font-size: 11px; color: #1565c0; text-decoration: none;">👉 公式サイトを見る</a>
</div>
\"\"\"

# 地図を作成
map_html = folium.Map(location=[35.737, 139.671], zoom_start=16)

# HTMLをfoliumが読み込めるようにラップ（包む）してマーカーに追加
folium.Marker(
    location=[35.737, 139.671],
    popup=folium.Popup(html_content, max_width=250), # max_widthで吹き出しの最大幅を指定
    icon=folium.Icon(color=\"green\", icon=\"leaf\", prefix=\"fa\")
).add_to(map_html)

map_html
```
ピンをクリックした際、まるで本物のグルメアプリのようなリッチで美しい吹き出しが表示されたでしょうか？
これだけで、あなたの作る地図アプリの品質がプロレベルに跳ね上がります。

## 9.3 階級区分図（コーロプレス図）と動的ダッシュボード連携（約25分）

### 9.3.1 階級区分図（コーロプレス図）のデータ構造
エリアマーケティングや行政のデータポータルで最も多用されるのが、地域ごとの数値データの大きさを「塗りつぶしの色の濃淡」で表す**階級区分図（コーロプレス図）**です。

これをプログラムで実現するためには、以下の**全く異なる2つのデータ**をメモリ上で寸分の狂いもなく合致させる必要があります。

1.  **地図の形データ（境界ポリゴン：GeoJSONやShapefile）**
    *   市区町村などの「境界線（多角形）」を定義したデータ。
    *   内部には、それぞれの区画を特定するための「区コード」や「区名」というキー情報が含まれています。
2.  **統計数値データ（売上や人口：PandasのDataFrame）**
    *   「練馬区：売上200万円」「杉並区：売上150万円」のように、エリア名と数値が記録された通常の表。

**【データ結合（key_on）の仕組み】**
```text
  [ 🗺️ GeoJSON側：地図データ ]               [ 📊 Pandas側：売上表 ]
  "features": [                              df_sales =
    { "properties": { "name": "練馬区" } }  ──▶  "区名": ["練馬区", "杉並区", "豊島区"]
                                 │               "売上": [ 250,    180,    300 ]
                                 ▼
                     🔑 紐付けるキーが完全一致！
                       (これを key_on で指定)
```

foliumでこれを描画する際は、**`folium.Choropleth`** オブジェクトを使用します。
最大のコツは、GeoJSONデータ内のどこにキー（「区名」など）があるかを示す **`key_on`** という引数の書き方です。
JSONは階層構造（辞書の入れ子）になっているため、`key_on="feature.properties.name"` のように「点（ドット）」で階層を辿ってキーを指定します。

```python
# 階級区分図の記述イメージ（授業用解説コード）
import folium

# m_choropleth = folium.Map(location=[35.73, 139.70], zoom_start=12)

# folium.Choropleth(
#     geo_data=tokyo_geojson,          # 1. 境界線ポリゴンデータ
#     data=df_sales_by_district,       # 2. Pandasの数値データ
#     columns=["区名", "総売上金額"],    # 3. Pandas側の [キーの列名, 色にする数値の列名]
#     key_on="feature.properties.name",# 4. GeoJSON側のキー（propertiesの中のnameキー）
```

### 9.3.2 🚀 Webアプリ（Streamlit）への地図の埋め込み

第5回・第6回で私たちは、サイドバーで条件を絞り込める「売上ダッシュボードアプリ」を作りました。
なんと、そのオシャレなアプリの中に、**本日作成した「動くデジタルマップ」を丸ごと埋め込む**ことができます！

これを実現するために、Streamlit専用の拡張ライブラリである **`streamlit-folium`** を使用します。

```python
# （Streamlitアプリのコード内での記述方法：解説）
import streamlit as st
import folium
from streamlit_folium import st_folium # 埋め込み用の関数をインポート

st.title("🗺️ リアルタイムハザードマップアプリ")

# 1. いつも通り folium で地図を作る
m = folium.Map(location=[35.73, 139.67], zoom_start=15)
folium.Marker([35.7368, 139.6705], popup="避難所A").add_to(m)

# 2. st_folium(地図オブジェクト) と書くだけで、Streamlitのメイン画面に地図が埋め込まれます！
st_data = st_folium(m, width=700, height=500)
```
これにより、ユーザーがサイドバーで「新宿店」を選ぶと、Pandasがその位置情報を切り出してfoliumに渡し、画面中央の地図が「新宿店周辺にズームして自動でピンが立ち直る」という、**本物の最先端エリアマーケティングシステムがわずか数十行で構築可能**になります。
