## 7.1 GIS（地理空間情報システム）とは？（地図の「レイヤー構造」） (約20分)

### 地図は「パンケーキの重ね合わせ」である
GISとは、**「地球上にあるあらゆるモノや出来事の位置情報を、コンピュータ上で重ね合わせて分析・視覚化するシステム」**です。
一番大事な概念は、地図を複数の**「レイヤー（層）」**に切り分けて管理するということです。

パンケーキに例えてみましょう！
*   一番下のパンケーキ：**「地形・道路（土台）」**
*   その上のホイップクリーム：**「店舗の位置（点データ）」**
*   その上のイチゴ：**「ハザードマップの浸水想定エリア（面データ）」**
*   その上のシロップ：**「時間帯別の人流・人混みのデータ（動的なデータ）」**

これらを綺麗に重ね合わせることで、「川の近くの、人混みが多い場所に、新しくカフェを出店するとどうなるか？」といった複雑な分析が、コンピュータ上で一瞬でできるようになります。

**【GISのレイヤー構造（イメージ図）】**
```text
  [ レイヤー 4 ]   🍒 店舗の位置（点データ：Point）
         │
  [ レイヤー 3 ]   🛣️ 道路や鉄道路線（線データ：LineString）
         │
  [ レイヤー 2 ]   🟩 行政区画や浸水エリア（面データ：Polygon）
         │
  [ レイヤー 1 ]   🗺️ 背景の白地図（ベースマップ）
  ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  【ガッチャンコ！】 ＝ 1枚の便利な「防災マップ」や「ビジネス出店分析マップ」の完成！
```

## 7.2 地球をどうやって平らにする？（座標系と投影法の罠） (約20分)

ここが、地理空間データを扱う上で文系学生が最も「うっ…」となる理論パートです。
しかし、**数式は一切使いません！** イメージで理解しましょう。

### 1. 地理座標系（丸い地球を角度で表す：経緯度）
地球は丸い（楕円体）です。この丸い地球のどこにいるかを、「赤道からの角度（**緯度：Latitude**）」と「イギリスの旧グリニッジ天文台からの角度（**経緯：Longitude**）」で表す方法を**地理座標系**と呼びます。
世界共通で最も使われているのが **「WGS84」** という世界測地系です。皆さんのスマホのGPSもこれを使っています。

### 2. 投影座標系（丸い地球を無理やり平らにする：平面）
しかし、丸い地球のままでは「ここから駅まで何メートル？」という距離の計算が非常に難しくなります。また、世界地図をノートに平らに描く必要もあります。
そこで、丸い地球を**「無理やり引っ張って平らな紙に投影（印刷）」**したものを**投影座標系**と呼びます。

みかんを想像してください。
丸いみかんの皮を、破かずに机の上に「完全な平らな四角形」として広げることはできますか？ できませんよね。どうしてもどこかが伸びたり、破れたりします。

**【投影のイメージ（みかんの皮）】**
```text
      丸いみかん（地球）             平面に広げた皮（世界地図）
         ╭━━━━━╮                     ┌───────────────┐
        ┃   ●   ┃   ──投影(flatten)─▶ │   ●   (歪み)   │
         ╰━━━━━╯                     └───────────────┘
      「角度は正確！」                「距離や面積が引き伸ばされる！」
```

このように、地球を平らにするときには、必ず**「面積」「距離」「角度」のどれかが犠牲（歪む）**になります。
*   世界地図でおなじみの「メルカトル図法」は、角度は正しいですが、北極や南極に近いグリーンランドが異常に巨大に描かれる（面積が歪む）ことで有名です。
*   日本国内の狭い範囲をメートル単位で正確に計算したい時は、日本を19の地域に細かく分割した**「平面直角座標系（JGD2011）」**という特別な平面座標系を使います。

## 7.3 地理空間データの代表的なファイル形式 (約20分)

地図データは、通常のExcelファイル（.xlsx）とは異なる特別な形式で保存されています。実務で出会う代表的な3つの形式を覚えましょう。

1.  **Shapefile（シェープファイル：.shp）**：
    *   GIS界の「超定番（長老）」。古い歴史があり、世界中のほぼ全てのGISソフトで開けます。
    *   最大の欠点は、ファイルが「.shp」「.shx」「.dbf」など**最低3つ以上の異なるファイルがセットで存在しないと動かない**という点です。どれか1つでも欠けるとエラーになります。
2.  **GeoJSON（ジオジェイソン：.geojson）**：
    *   Webやプログラミングの世界における「現代の主役」。
    *   中身はただの「テキストファイル（JSON形式）」なので、Pythonで非常に扱いやすく、Webブラウザで地図を動かす際にも多用されます。
3.  **KML/KMZ（ケーエムエル：.kml）**：
    *   「Google Earth」や「Google Maps」のマイマップでおなじみの形式。
    *   一般の人でも扱いやすく、位置情報とデザイン情報（ピンの色など）を一緒に保存できます。

### 世界地図のデータを読み込んで描画してみる
GeoPandasには、最初から練習用の「世界地図データ（世界各国の境界線ポリゴン）」が内蔵されています。これを読み込んでみましょう！

```python
# GeoPandas内蔵の低解像度の世界地図データを読み込む
world = gpd.read_file(gpd.datasets.get_path('naturalearth_lowres'))

# データフレームの中身を表示してみる（通常のPandasの表と見比べてみましょう）
print("--- 世界地図データのデータフレーム（DataFrame） ---")

```

通常のPandasと全く同じように見えますが、一番右端に **`geometry`（ジオメトリ）** という列がありますね！
ここに `POLYGON`（多角形：国境線で囲まれた面）などの位置情報がぎっしり詰まっています。

この `world` に対して、`.plot()` メソッドを呼び出すだけで、GeoPandasが裏側で座標を計算し、一瞬で世界地図を描画してくれます！

```python
# 世界地図のプロット
fig, ax = plt.subplots(figsize=(12, 6))
world.plot(ax=ax, color='lightgreen', edgecolor='white')

# グラフの装飾
plt.title("GeoPandasで描く最初の世界地図")
plt.xlabel("経度 (Longitude)")
plt.ylabel("緯度 (Latitude)")
plt.grid(True, linestyle='--', alpha=0.5)
plt.show()
```

### 特定のエリアだけを切り出す（Pandasの知識の応用）
基礎クラスで学んだ「条件抽出」をそのまま使うことができます！
例えば、`continent`（大陸名）が `"Asia"`（アジア）の国だけを抽出して地図にしてみましょう。

```python
# アジア大陸の国だけを抽出
asia = world[world["continent"] == "Asia"]

# アジア地図のプロット
fig, ax = plt.subplots(figsize=(10, 6))
asia.plot(ax=ax, color='skyblue', edgecolor='darkblue')

plt.title("アジア大陸の国々")
plt.show()
```

### ✨ 今日の重要ポイントまとめ
*   **レイヤー構造**: 地図は「点・線・面」などの異なるレイヤー（パンケーキ）が重なってできている。
*   **地理座標系と投影座標系**: 丸い地球を角度で表す「地理座標系（GPSなど）」と、みかんの皮のように平らにして距離を計る「投影座標系（メートル）」がある。
*   **データ形式**: 3つのファイルがセットで動く「Shapefile」と、テキストで扱いやすい現代の主役「GeoJSON」がある。
*   **GeoPandas (gpd)**: 表データの中に `geometry`（位置情報）の列を持つ、Pythonの最強地図操作ツール。

### ❓ よくある質問と回答 (FAQ)
*   **Q. `Point` を作るときに、`Point(緯度, 経度)` と書いたらエラー（または全く違う場所）になりました。**
    *   **A.** これがGISの世界で**全人類が1度は絶対にやる最大の罠**です！
        日常の会話では「緯度・経度」と言いますが、数学のグラフを思い出してください。
        横軸（X軸）＝経度（東経140度など）、縦軸（Y軸）＝緯度（北緯35度など）です。
        プログラムやGeoPandasの内部では、座標を `(X, Y)` で処理するため、**必ず `Point(経度, 緯度)` の順番で指定するルール**になっています。逆になると南極の近くや宇宙空間に店舗が飛んでしまいますので注意してください！

*   **Q. 地図をプロットした時、日本がやたら横に引き伸ばされて見えるのですが、直せますか？**
    *   **A.** 鋭い観察眼です！それは WGS84 という「緯度経度（角度）」のままで、平らな画面に無理やり四角形で投影しているためです（緯度が高い地域ほど横に引き伸ばされます）。
        これを直す（歪みを抑える）には、座標参照系（CRS）を適切な投影座標系に変換（プロジェクション変換）する必要があります。これについては、次回の「地理空間データの活用1」で詳しく解説します！
