## 9.1 動的地図ライブラリ（folium と leafmap）とは？ (約25分)

### 地図に「命（インタラクティブ）」を吹き込む
これまでは、グラフ（画像ファイル）を保存して提出するだけでした。
しかし、Webの時代における地図は「動く」のが当たり前です。

*   ドラッグ（掴んで）で、世界中を冒険（移動）できる。
*   マウスホイールで、ストリートレベルまでズームイン（拡大）できる。
*   アイコンをクリックすると、「本日のケーキ情報」がポップアップする。

このような動的地図は、裏側では「JavaScript（Leaflet.jsなど）」という難しいWeb用言語で書かれています。
しかし、今日の私たちが使う **`folium`** や **`leafmap`** を使えば、**JavaScriptの知識は一切不要！Pythonコードから動的Web地図を自動生成**してくれます。

**【動的マップの仕組み（イメージ図）】**
```text
  [ Pythonコード ] ──▶  [ folium / leafmap ] ──▶ [ Web地図（HTML/JS） ]
  (緯度経度を指定)       「裏側で難しいJSに自動変換」   「Colabの画面でグリグリ動く！」
```

### どっちを使うべき？
*   **`folium`**: 老舗の定番。日本語の解説記事が最も多く、シンプルなピン立てに最適です。
*   **`leafmap`**: 現代の最新ツール。Google Earth Engineなどの超高度な衛星画像分析や、データ分析用の高機能ダッシュボードが一瞬で作れる次世代ライブラリです。

まずは定番の `folium` を使って基本を学びましょう！

## 9.2 地図の表示とピン（Marker）の設置 (約20分)

まずは、武蔵大学周辺の地図をColab上に1枚描いてみましょう！
必要なのは、中心にしたい場所の**「[緯度, 経度]」**だけです。

```python
# （準備）動的マップ用のライブラリをインポート
import folium

# 1. 地図オブジェクトを作成する
# location=[緯度, 経度]、zoom_start=ズームレベル（大きいほど拡大）を指定します。
m = folium.Map(location=[35.737, 139.670], zoom_start=15) # 武蔵大学周辺

# 2. 地図を表示する（変数名を書くだけ！）
m
```
実行すると、Colabの実行結果の中に、本物の動く地図が現れたはずです！ドラッグして動かしたり、ズームイン・アウトしてみてください。

### 地図の上にピン（Marker）を立てる
次に、武蔵大学の位置に赤いピンを立てて、クリックしたら「武蔵大学にようこそ！」と吹き出し（ポップアップ）が出るようにしてみましょう。

```python
# 地図を新しく作ります
m_with_marker = folium.Map(location=[35.737, 139.670], zoom_start=15)

# ピン（Marker）を作成し、地図（m_with_marker）に「追加(.add_to)」します
folium.Marker(
    location=[35.7368, 139.6705], # 武蔵大学の経緯度
    popup="武蔵大学にようこそ！",     # クリックした時の吹き出し文字
    icon=folium.Icon(color="red", icon="info-sign") # 赤色のインフォマーク
).add_to(m_with_marker)

m_with_marker
```

### ✨ 今日の重要ポイントまとめ
*   **動的マップ（folium/leafmap）**: 画像ではなく、拡大縮小・ドラッグ・クリックができるインタラクティブなWeb地図。Pythonだけで自動生成可能。
*   **Marker と Popup**: 特定の位置にピンを立て、クリック時にテキストウィンドウ（ポップアップ）を出す基本機能。
*   **データフレームとの連携**: Pandasのループ（`iterrows()`）や if文 と組み合わせることで、何百件のデータでも自動で地図にプロットし、条件ごとに色分け（赤や青など）を自動化できる。
*   **コーロプレス図**: 地域の境界線データ(GeoJSON)とPandas(CSV)を合体させ、数値に応じてエリアを色の濃淡で自動塗り分けする統計地図。

### ❓ よくある質問と回答 (FAQ)
*   **Q. `leafmap` の最大の強みは何ですか？**
    *   **A.** leafmapは、foliumよりもさらに「大規模なデータ分析」や「衛星画像」を扱うのが得意です。例えば、ワンクリックで世界中の森林減少の歴史的変化をアニメーション（GIF）で表示したり、NASAが公開している最新の標高データや人工衛星からの地表温度データを直接地図の上に重ね合わせて描画したりできます。
        将来、卒業論文やビジネスで「地球規模の環境データ」や「都市計画」を扱いたいときは、ぜひ `leafmap` を使ってみてください。

*   **Q. 作成した folium の地図を、他の人に共有したり、ホームページに埋め込むことはできますか？**
    *   **A.** はい、とても簡単にできます！
        地図オブジェクト（`m`）に対して **`m.save("my_map.html")`** というコードを実行すると、Colab上にHTMLファイルが書き出されます。
        このHTMLファイルをダブルクリックすると、ブラウザ上でPythonなしでそのまま動く地図が開きます。これをサーバーにアップロードすれば、誰でも見られるオリジナルWEB防災マップの完成です！
