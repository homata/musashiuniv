## 1. イントロダクション：データ分析の重要性とプログラミングとは？ (約15分)

### 1.0 データ分析の重要性について
現代社会では、どんな仕事をするにしても「データ」が溢れています。例えば、皆さんがよく行く身近な「カフェ」を想像してみてください☕️。
「どの曜日にどのケーキが売れるのか？」「雨の日はコーヒーの売上がどうなるか？」といった情報を集めて分析することで、無駄を減らし、売上を伸ばすことができます。

**【データ分析のプロセス】**
```text
[ 📝 データの収集 ] レジの売上データ（エクセルやCSV）
        │
        ▼
[ 💻 データの処理 ] Pythonを使って自動で計算・集計！
        │
        ▼
[ 📊 データの可視化 ] グラフにして直感的にわかりやすく！
        │
        ▼
[ 💡 アクション ] 「雨の日はホットドリンクの仕入れを増やそう！」
```
このように、**勘や経験だけでなく、データに基づいて意思決定をすること**が、現代のビジネスでは非常に重要です。Pythonは、この「データ処理」から「可視化」までを魔法のようにパパッとこなしてくれる強力なツールなのです！

ちなみに、この授業では**生成AI（ChatGPTなど）を使ってコードを作成・学習することも大歓迎**です。AIを上手に使いこなしながら、「どうしてこういうコードになるのかな？」と考える力を養っていきましょう。

## 1.1 Python入門前の基礎知識 (約15分)

プログラミングを始める前に、パソコンの基礎知識を確認しましょう。「そんなの知ってるよ」という方も、おさらいのつもりで聞いてくださいね。

### MacとWindowsの「キーボード・入力」の違い
教室を見渡すと、Macの人もWindowsの人もいますね。実は、キーボードの入力で一番つまずきやすいポイントがあります。

* **バック・スラッシュ（\）と円マーク（¥）問題【最重要】**
  プログラミングでは `\`（バックスラッシュ）をよく使います。
  * **Windows**: `¥` キーを押すと、画面上は `\` と表示されることがあります（環境によって `¥` のままのこともありますが、プログラミング上は同じ意味として扱われることが多いです）。
  * **Mac**: `Option` キーを押しながら `¥` キーを押すと `\` が入力できます。これ、テストに出るくらい重要です！
* **バックティック（`）の打ち方**
  後で使う「Markdown」でよく使います。
  * **Windows**: `Shift` + `@`
  * **Mac**: `Shift` + `@` (JISキーボードの場合)
* **ショートカットキー**
  * コピー：Windowsは `Ctrl + C`、Macは `Command + C`
  * 貼り付け：Windowsは `Ctrl + V`、Macは `Command + V`

### パソコンの裏側を知る
| 用語 | わかりやすい例え | 説明 |
| :--- | :--- | :--- |
| **ファイルパス (Path)** | 🏠 家の住所 | ファイルがパソコンの中の「どこ」にあるかを示す住所です。（例：`C:\Users\Documents\data.csv`） |
| **文字コード** | 🗣️ 言語（日本語、英語など） | コンピュータが文字を理解するためのルール。最近は世界共通の **UTF-8** が主流ですが、古いエクセルなどは **Shift-JIS** になっていることがあり、これが原因で「文字化け（謎の記号になる現象）」が起こります。 |
| **ファイルの保存** | 🗃️ 机から引き出しへ | 作業中のデータは「メモリ（作業机）」にあります。電源を切ると消えてしまうので、「ハードディスク（引き出し）」に片付けるのが保存です。 |

## 1.2 Google Colabの環境構築 (約10分)

この授業では、皆さんのパソコンに何か難しいソフトをインストールする必要はありません。ブラウザ（Chromeなど）があれば動く **Google Colaboratory（略してColab）** を使います。

* **Googleドライブから作成**
  Googleドライブの「新規」→「その他」から「Google Colaboratory」を選びます。（※メニューに出てこない場合は、「アプリを追加」から検索して追加してくださいね。）
* **【重要】ランタイムが切れるとファイルが消える！**
  Colabは、Googleが無料で貸してくれている「クラウド上のパソコン（ランタイム）」で動いています。一定時間放置したり、接続を切ったりすると、**アップロードしたファイルはリセットされて消えてしまいます**。消えて困るファイルは、後で説明する「Google ドライブのマウント」という技を使って保存します。

## 1.3 Colaboratory (Colab) の使い方 (約20分)

さあ、実際にColabを使ってみましょう！

1. **セルの基本**: Colabは「セル」という四角いブロックの集まりです。
   * **テキストセル**: 今皆さんが読んでいる、説明を書くためのブロックです。
   * **コードセル**: Pythonのプログラムを書いて実行するブロックです。
2. **セルの実行**: コードセルの左側にある「▶︎」ボタンを押すか、`Shift + Enter` を押すとプログラムが動きます！

早速、下のコードセルを実行してみましょう！
```

<!-- コードセル -->
# ここはコードセルです。「#」から始まる行は「コメント」と呼ばれ、プログラムには影響しません。
# メモ書きとして使います。

# カフェの売上を計算してみましょう！
coffee_price = 450  # コーヒー1杯の値段
sell_count = 10     # 売れた数

# 掛け算をして表示します
total_sales = coffee_price * sell_count
print("コーヒーの今日の売上は", total_sales, "円です！")

<!-- Markdownセル -->
### 実行止まらないとき ＆ エラーが出た時
* **実行が止まらない（ぐるぐる回り続けている）時**：左上の「ランタイム」タブから「実行を中断」を押してください。
* **エラーが出た時**：赤い文字で英語がたくさん出てくるとびっくりしますよね。でも大丈夫です！エラーは「ここがちょっとおかしいよ」というコンピュータからの優しいお知らせです。
  * **対処法**: エラー文の一番下（`SyntaxError` など）をコピーして、生成AIやGoogle検索で調べてみましょう。「括弧を閉じ忘れてるよ」「全角スペースが混ざってるよ」といった原因がほとんどです。

### その他の便利機能
* **セルの挿入**: 画面上部の「+ コード」「+ テキスト」から追加できます。
* **ノートブックのダウンロード**: 「ファイル」→「ダウンロード」から、`.ipynb` 形式で自分のPCに保存できます。
* **Google ドライブのマウント**: 左側のフォルダアイコン📁を押し、「ドライブをマウント」のボタンを押すと、自分のGoogleドライブ内のファイルを読み書きできるようになります。

## 1.4 MacOS 特有の注意点 (約5分)
Macユーザーの方は、ファイルを共有する際に気をつけたいことがあります。
* **隠しファイル（__MACOSX や .DS_Store）**
  Macは裏側でこっそり見えないファイルを作ります。Windowsの人にファイルを送ると「謎のゴミファイルが入ってる！」と言われることがありますが、そういうものなので気にしなくて大丈夫です。

## 1.5 Windows 特有の注意点 (約5分)
Windowsユーザーの方も、設定を確認しておきましょう。
* **拡張子の表示**
  「ファイル名.txt」の `.txt` の部分を拡張子と呼び、ファイルの種類を表します。Windowsは初期設定でこれが隠れているので、エクスプローラーの「表示」タブから「ファイル名拡張子」にチェックを入れて表示させておきましょう。
* **圧縮ファイル（.zip）**
  複数のファイルをギュッとまとめたものです。使うときは必ず「右クリック」→「すべて展開」を選んでから使ってくださいね。展開せずに中身を触ろうとするとエラーになります。

## 1.6 Markdown（マークダウン）とは何か？ (約10分)

今皆さんが読んでいるこの綺麗なテキスト、実は「Markdown」というルールで書かれています。
簡単な記号を使うだけで、文字を太くしたり、見出しを作ったりできます。

**【Markdownの基本記法】**
* 見出し：文字の前に `#` をつける（`# 大見出し`, `## 中見出し`）
* 太字：文字を `**` で囲む（`**太字**`）
* リスト：行の先頭に `-` や `*` を置く
* バックティック：`` ` ``で囲むとコードっぽく表示される

### ❓ よくある質問と回答 (FAQ)
*   **Q. コードを実行しても、ずっとぐるぐる回って終わりません。**
    *   **A.** 左上の「ランタイム」メニューから「実行を中断」を押して強制終了させてください。

    *   **A.** 素晴らしい気づきです！実は `\` は特殊な記号（エスケープシーケンス）として扱われるため、文の終わりに単独で置くとエラーになります。本講義では「\を打てること」の確認用でしたが、今後の授業で詳しく説明しますね。
