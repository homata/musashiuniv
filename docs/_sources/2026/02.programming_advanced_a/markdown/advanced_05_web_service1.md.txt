## 5.2 Google Colab上でStreamlitを動かす魔法（環境構築） (約25分)

通常、Streamlitは自分のパソコン（ローカル環境）の黒い画面（ターミナル）で起動します。
しかし、この授業では誰もが同じ環境で学べるよう **Google Colab** を使っています。Colabは「Googleのクラウド上にあるパソコン」なので、そこで動かしたWebアプリを、手元のパソコンやスマホのブラウザで見るためには、**一時的な通り道（トンネル）**を作ってあげる必要があります。

このトンネリングツールとして **localtunnel（ローカルトンネル）** という無料の仕組みを使います。
まずは、Colabのセルに以下の「おまじない」を貼り付けて、環境を構築しましょう！

```python
# ------------------------------------------------------------------
# ステップ 1: 必要なライブラリのインストール（Colabのセルで実行してください）
# ------------------------------------------------------------------
!pip install -q streamlit
!npm install -g localtunnel
```

### 【超重要】ColabでStreamlitを起動する「3つの手順」

Colab上でアプリを開発する時は、以下のセットを常に使います。

#### 手順A: アプリのソースコードを書き出す（`%%writefile`）
セルの1行目に `%%writefile app.py` と書くと、そのセルの中身がそのまま `app.py` という名前のPythonファイルとしてColabの中に保存されます。

```python
%%writefile app.py
# ここにStreamlitのコードを書きます
import streamlit as st

st.title("Musashi Cafe アプリ ☕")
st.write("プログラミング応用Aの授業で作成したWebアプリです！")
```

#### 手順B: トンネルの鍵（あなたのIPアドレス）を確認する
localtunnelを使って外部からアプリにアクセスする際、セキュリティ確認のために「Colabの仮想パソコンのIPアドレス（4つの数字）」を求められます。以下のコマンドを実行して、出てきた数字をメモ（コピー）しておきましょう。

```python
# あなたのColab環境のIPアドレスを表示します（パスワードのようなものです）
!wget -qO- ipv4.icanhazip.com
```

#### 手順C: アプリをバックグラウンドで起動し、トンネルを開通する！
以下のコマンドを実行すると、Streamlitが裏側（バックグラウンド）で起動し、localtunnelが世界中からアクセスできる一時的なURLを発行してくれます。

```python
# Streamlitを裏で起動
!streamlit run app.py &>/dev/null &

# ポート8501番（Streamlitの標準ポート）を外部に公開する
!npx localtunnel --port 8501
```

*   **使い方**: 
    1. 上のセルを実行すると、`url: https://xxxx.loca.lt` というリンクが表示されます。
    2. そのリンクをクリックすると、「Tunnel Password」という入力画面が開きます。
    3. そこに **手順Bで確認したIPアドレス（例：34.125.12.34）** を貼り付けて「Submit」ボタンを押します。
    4. 画面が切り替わり、あなたが作った「Musashi Cafe アプリ」が表示されます！

## 5.3 Streamlitの基本操作とウィジェット (約25分)

無事にアプリが起動したら、今度はアプリの中身を豪華にしていきましょう！
Streamlitは、ユーザーがボタンを押したりスライダーを動かしたりするたびに、**「コードが上から下まで自動的に再実行され、画面が即座に書き換わる」**という超画期的な仕組み（リアクティブ・フレームワーク）を持っています。

代表的なコマンドとウィジェット（入力部品）を体験してみましょう。

```python
%%writefile app.py
import streamlit as st

# ==========================================
# 1. テキスト・見出しの表示
# ==========================================
st.title("カフェ自動レジアプリ ☕")
st.header("お会計シミュレーター")
st.write("商品の選択と数量を入力すると、自動でお会計を計算します。")

# ==========================================
# 2. セレクトボックス（ドロップダウンメニュー）
# ==========================================
# st.selectbox("案内メッセージ", 選択肢のリスト)
# ユーザーが選んだ値が、そのまま変数 selected_item に入ります！
selected_item = st.selectbox(
    "ご注文の商品を選んでください:",
    ["コーヒー (450円)", "紅茶 (400円)", "チョコレートケーキ (550円)"]
)

# 商品名と価格の切り分け処理
if "コーヒー" in selected_item:
    price = 450
elif "紅茶" in selected_item:
    price = 400
else:
    price = 550

# ==========================================
# 3. スライダー（数値の調整）
# ==========================================
# st.slider("案内メッセージ", 最小値, 最大値, 初期値)
quantity = st.slider("数量を選んでください:", 1, 10, 1)

# ==========================================
# 4. ボタン（実行のトリガー）
# ==========================================
# st.button("ボタンの文字") は、ボタンが押された瞬間だけ True になります！
if st.button("お会計を計算する"):
    total = price * quantity
    st.success(f"計算が完了しました！") # 緑色の綺麗なボックスで表示します
    st.write(f"ご注文: {selected_item} × {quantity}個")
    st.metric(label="合計金額 (税込)", value=f"{total} 円") # プロっぽい数値インジケータ
```

### 💡 開発を10倍楽にする「常時リロード（Always Rerun）」
1. localtunnelで開いたWebアプリ画面の右上に「**︙**（設定メニュー）」があります。
2. そこをクリックし、**「Settings」➡「Run on save」**にチェックを入れます。
3. これにより、Colab側で `app.py` のセルを実行（ファイルを上書き保存）するだけで、**ブラウザのタブを手動でリロードしなくても、Webアプリ画面が自動で一瞬で最新に更新される**ようになります。非常に快適に開発ができるので、ぜひ設定しましょう！

```python
elif "カフェラテ" in drink:
    price = 450
else:
    price = 500

is_takeout = st.checkbox("テイクアウト（お持ち帰り）ですか？ (税率8%になります)")

# テイクアウト判定
if is_takeout:
    tax_rate = 1.08
else:
    tax_rate = 1.10

quantity = st.slider("数量を選択してください:", 1, 10, 1)

if st.button("注文を確定する"):
    total_bill = int(price * quantity * tax_rate)
    
    st.success("ご注文ありがとうございます！")
    st.write(f"内訳: {drink} × {quantity}個 (税率: {tax_rate*100:.0f}%)")
    st.metric(label="ご請求金額 (税込)", value=f"{total_bill} 円")
```

## ❓ よくある質問と回答 (FAQ)
*   **Q. localtunnelのURLを開いたら「Friendly Reminder...」という青い警告画面が出て、アプリが表示されません。**
    *   **A.** 大丈夫です、それはlocaltunnelの仕様です。画面中央にある **「Click to Submit」** または **「Visit Site」** というボタンをクリックすれば、作成したアプリ画面に問題なく進むことができます。
*   **Q. コードを書き換えてセルを実行したのに、Webアプリ側の画面が変わりません。**
    *   **A.** アプリ画面の右上にある「︙」メニューから、**「Always Rerun（常時リロード）」**が有効になっているか確認してください。もし無効になっている場合は、手動でWebブラウザの再読み込みボタン（F5キーなど）を押すか、Colab側で Streamlit の起動セルを再度実行し直してみてください。
*   **Q. localtunnelへのアクセス時に「Tunnel xxxx not found」やエラーが出ます。**
    *   **A.** Google Colabのネットワーク状況により、時折トンネル接続が切断されることがあります。その場合は、Colabの実行セルの停止（■）ボタンを押し、`!streamlit run app.py &` から始まる起動セルをもう一度実行して、新しいURLを発行してみてください。

今日学んだ Streamlit は、実は **Pandasの表データや、Matplotlib/Seabornのグラフを画面に一発で表示する機能** も持っています！
以下のコードを Colab に貼り付け、Webアプリの画面がどう進化するか覗いてみましょう。

```python
%%writefile app.py
import streamlit as st
import pandas as pd
import numpy as np
import matplotlib.pyplot as plt

st.title("📊 カフェ売上ダッシュボード 📊")

# 模擬データ（1週間分の売上）
data = pd.DataFrame({
    "曜日": ["月", "火", "水", "木", "金", "土", "日"],
    "売上額 (千円)": [45, 52, 48, 60, 75, 110, 120]
})

# 1. データの表をそのままアプリ上に表示！
st.subheader("曜日別売上表")
st.dataframe(data) # インタラクティブなスプレッドシートとして表示されます

# 2. グラフをアプリ上にプロット！
st.subheader("売上推移グラフ")
fig, ax = plt.subplots()
ax.bar(data["曜日"], data["売上額 (千円)"], color="skyblue")
st.pyplot(fig) # 描画した matplotlib のグラフを一発でWeb画面に埋め込み！
```
